build the skill · Alexa Developer Console (free)

Create a custom skill → point it here

  1. developer.amazon.com/alexa/console/ask → Create Skill → Custom → Provision your own.
  2. Invocation name: my sovereign
  3. Add an Intent named AskIntent with one slot query of type AMAZON.SearchQuery, and a sample utterance: {query} (and ask about {query}).
  4. Endpoint → HTTPS: paste: 
    https://os.meok.ai/api/alexa
    SSL cert option: “My development endpoint has a certificate from a trusted CA.”
  5. Save + Build Model → Test. Say: “Alexa, ask my Sovereign what governs a bank.”
how it works

Same mind, spoken aloud

The endpoint parses Alexa's LaunchRequest / IntentRequest, passes your words to the Sovereign (/api/chat, care-floored + governed, medium OWEM tier), and returns Alexa-format speech. It's the same character you meet in Claude, on the web, on Siri — just through Echo.

Honest: unlike the Siri Shortcut (60-second, no account), Alexa requires creating a skill in the Developer Console (free, ~5 min) because Amazon has no personal-shortcut equivalent — but the hard part (an endpoint that speaks ASK) is done and live. Publishing the skill publicly needs Amazon certification; for yourself, the dev skill works immediately. Same Sovereign everywhere: Claude/MCP · any website · Siri · Council.
