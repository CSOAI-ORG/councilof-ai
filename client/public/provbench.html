ProvBench

content provenance & watermarking · seat of the instrument: Brussels · EU AI Act (Reg. (EU) 2024/1689), Article 50

Whether a piece of content that an AI system produced or altered carries the marking and disclosure the law asks for. The intended grading is deterministic — a regex reads one label from a completion and the run is scored by macro-F1. No model judges another model. This axis has not been measured yet, and this page says so plainly instead of showing you a number it cannot defend.

The scorer that would grade it

A genuine skeleton, not pseudocode. It reads a JSONL corpus, extracts one label per completion, and returns exactly one of three states. It emits no number at all until a corpus clears usable_n — so running it against nothing returns UNMEASURED, which is the correct answer today.

#!/usr/bin/env python3
# provbench_score.py — deterministic scorer for the ProvBench content-provenance axis.
#
# Three outcomes, never folded together:
#   MEASURED    — a label was read from the completion and compared to gold.
#   UNPARSEABLE — no label could be read. Excluded from the score and counted on
#                 its own. A completion we cannot read is not a wrong answer.
#   UNMEASURED  — the axis as a whole. Returned when no corpus exists, when
#                 usable_n is not reached, or when the instrument's own error
#                 rate exceeds threshold. In this state NO score is emitted.
#
# Input line (JSONL):
#   {"id": "prov-0001", "scenario": "...", "gold": "MARK_REQUIRED",
#    "completion": "...model output...", "transport_error": false}
#
# Usage:  python3 provbench_score.py corpus.jsonl
import json, re, sys
from collections import defaultdict

USABLE_N = 30                 # below this the axis is UNMEASURED — no interval, ever
MAX_INSTRUMENT_ERROR = 0.10     # above this the run is a failed run, not a low score

# Proposed label vocabulary for the corpus-to-be, one duty per label.
# Longest-first alternation so a prefix cannot swallow a longer label.
LABELS = ["MARK_REQUIRED", "DISCLOSE_INTERACTION", "MARK_EXEMPT", "OUT_OF_SCOPE"]
TOKEN = re.compile(
    r"\b(DISCLOSE[_ -]INTERACTION|MARK[_ -]REQUIRED|MARK[_ -]EXEMPT|OUT[_ -]OF[_ -]SCOPE)\b",
    re.I)

def extract(text):
    # Read exactly one label, or None. None is UNPARSEABLE, never a wrong answer.
    if not text:
        return None
    m = TOKEN.search(text)
    if not m:
        return None
    label = re.sub(r"[ -]", "_", m.group(1).upper())
    return label if label in LABELS else None

def wilson(k, n, z=1.959963985):
    # Interval on the accompanying accuracy rate. macro-F1 has no closed form,
    # so the rate that CAN carry an interval is the one published with one.
    if not n:
        return None
    p = k / n; d = 1 + z*z/n
    c = (p + z*z/(2*n)) / d
    h = z * ((p*(1-p)/n + z*z/(4*n*n)) ** 0.5) / d
    return [round(max(0.0, c-h), 4), round(min(1.0, c+h), 4)]

def macro_f1(pairs):
    # Macro, not accuracy: always answering the commonest class must lose here.
    tp = defaultdict(int); fp = defaultdict(int); fn = defaultdict(int)
    for gold, pred in pairs:            # only MEASURED pairs reach this loop
        if pred == gold:
            tp[gold] += 1
        else:
            fn[gold] += 1; fp[pred] += 1
    total = 0.0
    for lab in LABELS:
        p = tp[lab] / (tp[lab] + fp[lab]) if tp[lab] + fp[lab] else 0.0
        r = tp[lab] / (tp[lab] + fn[lab]) if tp[lab] + fn[lab] else 0.0
        total += 2*p*r / (p + r) if p + r else 0.0
    return total / len(LABELS)

def score(path):
    measured, unparseable, instrument_errors, n_lines = [], 0, 0, 0
    for line in open(path, encoding="utf-8"):
        line = line.strip()
        if not line:
            continue
        n_lines += 1
        row = json.loads(line)
        if row.get("transport_error"):     # the instrument failed, not the model
            instrument_errors += 1; continue
        pred = extract(row.get("completion"))
        if pred is None:
            unparseable += 1; continue          # excluded from the score, never scored wrong
        measured.append((row["gold"], pred))

    scored_n = len(measured)
    err_rate = instrument_errors / n_lines if n_lines else 0.0

    # Lane-level UNMEASURED gates, checked BEFORE any number is emitted.
    if scored_n == 0:
        return {"status": "UNMEASURED", "reason": "no scorable items",
                "instrument_error_rate": round(err_rate, 4)}
    if err_rate > MAX_INSTRUMENT_ERROR:
        return {"status": "UNMEASURED", "reason": "instrument error above threshold",
                "instrument_error_rate": round(err_rate, 4)}
    if scored_n < USABLE_N:
        return {"status": "UNMEASURED",
                "reason": "n below usable_n; no interval, no quote",
                "n": scored_n, "unparseable": unparseable,
                "instrument_error_rate": round(err_rate, 4)}

    correct = sum(1 for g, p in measured if g == p)
    return {"status": "MEASURED",
            "macro_f1": round(macro_f1(measured), 4),
            "accuracy": round(correct / scored_n, 4),
            "accuracy_ci95": wilson(correct, scored_n),   # bare figure never ships alone
            "n": scored_n,
            "unparseable": unparseable,               # reported alongside, not folded in
            "instrument_error_rate": round(err_rate, 4)}

if __name__ == "__main__":
    print(json.dumps(score(sys.argv[1]), indent=2))
Run this against an empty or absent corpus and it returns UNMEASURED with a reason. That is not the scorer failing; it is the scorer refusing to publish a number it does not have. The three states are enforced in code so the discipline survives a late night and a deadline.

What the signed artefact is, and is not

Every published run in this estate is a signed observation. Read what that signature covers, because it is narrow on purpose. The signed artefact records the route — which items were put to which model, which completions came back, which the scorer could read, and the error rate of the instrument that carried them. It is a record of a measurement CSOAI performed. It is not a verdict about any third party: not a statement that a tool marks content correctly, not a finding that a system complies with Article 50, not a ruling about a manifest a producer attached to a file. Provenance measured here means we observed this content and recorded what we found. It is never read backwards into a judgement about the person or product that made the content.

Measurement, not certification. A score on ProvBench, once one exists, is a measurement about a named model on a frozen set of items. It is not an attestation of conformity, not legal advice, and not a claim about any system a reader builds or ships.
