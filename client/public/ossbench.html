OSSBench

openness · seat of the instrument: Brussels · EU AI Act (Reg. 2024/1689), Art 53(2)

Open-source general-purpose AI model obligations. The question OSSBench would put to a model: given a described GPAI model release, does the free-and-open-source carve-out apply, and which obligations survive it? Nothing has been measured yet. This page says so plainly and shows exactly what measuring it would take — it publishes no score, because there is none.

Statutory anchor

The carve-out for open-source general-purpose AI models is Regulation (EU) 2024/1689 (the EU AI Act), Article 53(2): the technical-documentation obligations of Article 53(1)(a) and (b) do not apply to a GPAI model released under a free and open-source licence — unless the model is one with systemic risk. Two provisions bound that carve-out and OSSBench would test each of them:
· Article 53(1)(c) and (d) — the copyright-compliance policy and the public summary of training content bind regardless of an open-source licence; openness does not switch them off.
· Article 51 — a GPAI model classified as posing systemic risk (Art 51(1); Art 51(2) sets the training-compute presumption) does not get the open-source carve-out at all.
· Article 2(12) — at the AI-system layer, free-and-open-source AI systems are outside the Regulation unless they are high-risk, or fall under Article 5 or Article 50.
Instrument confirmed to the article. This page anchors only to provisions whose text and numbering it is certain of; where it is not certain it says "to be sourced" rather than guess. Nothing here is legal advice.

What it would take to measure it

OSSBench moves out of UNMEASURED only when every one of these is in place. None of them is yet.

  • 1. A labelled corpus of n ≥ 30 GPAI-release scenarios — each describing a release (licence terms, weights/parameter availability, systemic-risk status) and carrying a gold label sourced to a specific provision of Reg. 2024/1689, not to a vibe.
  • 2. A held-out, frozen split the scorer never sees during design, so the grader cannot be tuned to the answer key.
  • 3. A deterministic scorer — a regex reads the label, macro-F1 grades it. No model judges another model's answer.
  • 4. Scored per item, with the three-outcome rule below enforced: a MEASURED item, an UNPARSEABLE answer, or an UNMEASURED transport failure — the last two never fold into a zero.
  • 5. The instrument's own error reported alongside the score — the harness error rate and the unreadable rate printed next to any figure, so a broken run is visible as a broken run and not as a low model.
  • 6. Only at n ≥ 30 does a confidence interval get published. Below it the lane stays marked not-quotable, including for us.

The scorer — what would grade it

A genuine skeleton, not pseudocode. It runs the moment a corpus exists; today it prints UNMEASURED and exits, because there is no corpus to read. Macro-F1 is the metric — accuracy would reward always answering the commonest class, which is useless when the whole point is separating a carve-out from an obligation.

#!/usr/bin/env python3
# ossbench_score.py — deterministic scorer for OSSBench.
# Field: open-source GPAI model obligations · anchor: Reg. (EU) 2024/1689, Art 53(2).
#
# THREE OUTCOMES, never two. Each item resolves to exactly one of:
#   MEASURED    — an answer parsed to a label and was compared to gold.
#   UNPARSEABLE — an answer arrived but no label could be read from it.
#                 Reported, excluded from the score, NEVER counted as wrong.
#   UNMEASURED  — no answer arrived (harness/transport error), or no corpus
#                 exists at all. Instrument error, not model error — never a 0.
import json, re, sys, pathlib

USABLE_N = 30
LABELS = ["EXEMPT_OSS", "FULL_OBLIGATIONS", "SYSTEMIC_RISK", "OUT_OF_SCOPE"]
# EXEMPT_OSS       — free/open-source GPAI, no systemic risk: exempt from Art 53(1)(a),(b);
#                    copyright policy + training summary (Art 53(1)(c),(d)) still bind.
# FULL_OBLIGATIONS — licence not genuinely free/open (weights withheld, use restricted):
#                    the Art 53(2) carve-out does not attach; full Art 53(1) applies.
# SYSTEMIC_RISK    — GPAI with systemic risk (Art 51): carve-out unavailable; Art 55 binds.
# OUT_OF_SCOPE     — free/open-source AI system, not GPAI, not high-risk/Art 5/Art 50:
#                    outside the Regulation per Art 2(12).

# Longest-first alternation so FULL_OBLIGATIONS / SYSTEMIC_RISK cannot be swallowed
# by a prefix, and space / underscore / hyphen all read the same label.
TOKEN = re.compile(
    r"\b(FULL[ _-]OBLIGATIONS|SYSTEMIC[ _-]RISK|OUT[ _-]OF[ _-]SCOPE|EXEMPT[ _-]OSS)\b",
    re.IGNORECASE)

def extract(text):
    # Returns a canonical label, or None if the answer cannot be read.
    if not text:
        return None
    m = TOKEN.search(text)
    if not m:
        return None
    c = m.group(1).upper().replace("-", "_").replace(" ", "_")
    return c if c in LABELS else None

def macro_f1(pairs):
    # pairs is a list of (gold, pred) over MEASURED items only.
    tp = {l: 0 for l in LABELS}; fp = dict(tp); fn = dict(tp)
    for g, pr in pairs:
        if pr == g: tp[g] += 1
        else: fn[g] += 1; fp[pr] = fp.get(pr, 0) + 1
    total = 0.0
    for l in LABELS:
        p = tp[l] / (tp[l] + fp[l]) if tp[l] + fp[l] else 0.0
        r = tp[l] / (tp[l] + fn[l]) if tp[l] + fn[l] else 0.0
        total += 2 * p * r / (p + r) if p + r else 0.0
    return total / len(LABELS)

def main():
    corpus = pathlib.Path(sys.argv[1]) if len(sys.argv) > 1 else pathlib.Path("ossbench.jsonl")
    answers = pathlib.Path(sys.argv[2]) if len(sys.argv) > 2 else None

    # No corpus → the lane is UNMEASURED. Print it and stop. Do not invent a run.
    if not corpus.exists() or answers is None or not answers.exists():
        print("OSSBench: UNMEASURED — no corpus / no answers. No score is defined.")
        return

    gold = {j["id"]: j["gold"] for j in map(json.loads, corpus.open())}
    ans  = {j["id"]: j for j in map(json.loads, answers.open())}

    measured, unparseable, unmeasured = [], 0, 0
    for _id, g in gold.items():
        a = ans.get(_id)
        if a is None or a.get("error"):
            unmeasured += 1            # transport / harness failure — NOT a wrong answer
            continue
        pred = extract(a.get("answer"))
        if pred is None:
            unparseable += 1          # answer unreadable — excluded, NOT scored as wrong
            continue
        measured.append((g, pred))

    n = len(measured)
    err_rate = unmeasured / max(1, len(gold))
    if n == 0:
        print(f"OSSBench: UNMEASURED — 0 items scored; instrument error on {err_rate:.0%}.")
        return

    f1 = macro_f1(measured)
    # The instrument's own error prints NEXT TO the score, every time.
    print(f"OSSBench: n={n}  macro-F1={f1:.4f}  "
          f"unparseable={unparseable}  instrument_error={err_rate:.0%}")
    if n < USABLE_N:
        print(f"  not quotable: n={n} < usable_n={USABLE_N}; no interval published.")

if __name__ == "__main__":
    main()

What the signed artefact is — and is not

Provenance chain: anchor (Reg. 2024/1689, Art 53(2)) → corpus item → model answer → regex label read → macro-F1 → signed run record. When a run exists, the thing CSOAI signs is the route and the observation — these items, this model, this answer, graded by this rule, with the instrument's error printed beside the score. The signature attests that the measurement happened as recorded. It is never a verdict about the third-party model, never a statement that a model or its release complies with the EU AI Act, and never a certificate of anything. This is measurement, not certification. Until the corpus is built, there is no run and nothing to sign.

Measurement, not certification. CSOAI is not a certification body, does not certify, and is neither accredited nor applying for accreditation. It issues measurements and attestations, never certificates of conformity. Nothing on this page is a statement of conformity with any regulation, and it is not legal advice.
OSSBench is UNMEASURED: no corpus, no score, no n, no interval. An answer that cannot be read is reported as UNPARSEABLE and excluded from the score, never counted as wrong. A run whose instrument error rate exceeds threshold is reported as a failed run, never as a low score. No interval is published on any axis below usable_n = 30 — including by us.
