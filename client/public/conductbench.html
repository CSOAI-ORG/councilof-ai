ConductBench

conduct · seat of the instrument: Brussels · EU AI Act (Reg. 2024/1689), Art. 56 — codes of practice for general-purpose AI

Classification of general-purpose-AI (GPAI) code-of-conduct commitments against the EU GPAI Code of Practice. The intended grading is deterministic — a regex extracts the commitment-area label and the result is scored by macro-F1. No model would judge another model. This axis has not been measured. There is no corpus behind it yet, so this page publishes no score, and says so plainly instead of implying one.

The scorer that would grade it

This is the real grader, not pseudocode. It runs today; it simply has nothing to run against until the corpus exists. It returns one of three outcomes per run — MEASURED, UNPARSEABLE, UNMEASURED — and never turns a lane error or an unreadable answer into a zero.

# conductbench_score.py — deterministic grader for GPAI code-of-conduct classification.
# Input: JSONL, one object per item:
#   {"id": "cb-014", "prompt": "<described GPAI provider practice>",
#    "gold": "TRANSPARENCY", "answer": "<model's raw text>", "delivered": true}
# "delivered" is false when the harness could not obtain an answer at all
# (timeout, transport error) — that is LANE ERROR, never a wrong answer.
#
# LABELS are a PLACEHOLDER taxonomy. Before any real run they must be replaced
# with the frozen commitment areas transcribed from the published EU GPAI Code
# of Practice (Reg. (EU) 2024/1689, Art. 56). Do not ship a run on guesses.
import json, re, sys, math

LABELS = ["TRANSPARENCY", "COPYRIGHT", "SAFETY_SECURITY", "OUT_OF_SCOPE"]  # TO BE FROZEN from the Code
USABLE_N = 30
# Longest-first alternation so SAFETY_SECURITY cannot be swallowed by a prefix match.
TOKEN = re.compile(r"\b(SAFETY[ _-]SECURITY|OUT[ _-]OF[ _-]SCOPE|TRANSPARENCY|COPYRIGHT)\b", re.I)

def extract(text):
    """Read a single label, or None if the answer cannot be parsed into one."""
    if not text: return None
    m = TOKEN.search(text)
    if not m: return None
    c = m.group(1).upper().replace("-", "_").replace(" ", "_")
    return c if c in LABELS else None

def macro_f1(pairs):
    """Macro-F1, not accuracy: always answering the commonest class must lose."""
    tp = {l: 0 for l in LABELS}; fp = dict(tp); fn = dict(tp)
    for gold, pred in pairs:
        if pred == gold: tp[gold] += 1
        else:
            fn[gold] += 1
            if pred in fp: fp[pred] += 1   # pred is None here → not charged to any class
    total = 0.0
    for l in LABELS:
        p = tp[l] / (tp[l] + fp[l]) if tp[l] + fp[l] else 0.0
        r = tp[l] / (tp[l] + fn[l]) if tp[l] + fn[l] else 0.0
        total += (2 * p * r / (p + r)) if p + r else 0.0
    return total / len(LABELS)

def score(path):
    items = [json.loads(l) for l in open(path, encoding="utf-8") if l.strip()]
    if not items:
        return {"outcome": "UNMEASURED", "reason": "no corpus — the lane exists and it is empty"}

    delivered = [it for it in items if it.get("delivered", True)]
    lane_error = len(items) - len(delivered)          # harness could not deliver — NOT wrong answers
    if not delivered:
        return {"outcome": "UNMEASURED", "reason": "every item failed to deliver",
                "lane_error": lane_error, "n": 0}

    pairs, unparseable = [], 0
    for it in delivered:
        pred = extract(it.get("answer"))
        if pred is None: unparseable += 1   # excluded from scoring, never counted as wrong
        pairs.append((it["gold"], pred))

    scored = [(g, p) for g, p in pairs if p is not None]
    n = len(scored)
    # If nothing parsed, that is an instrument reading failure, not a model score of zero.
    if n == 0:
        return {"outcome": "UNPARSEABLE", "reason": "no answer could be read as a label",
                "unparseable": unparseable, "lane_error": lane_error, "n": 0}

    f1 = macro_f1(scored)
    quotable = n >= USABLE_N              # below 30, no interval is published — including for us
    return {"outcome": "MEASURED", "macro_f1": round(f1, 4), "n": n,
            "unparseable": unparseable, "lane_error": lane_error,
            "quotable": quotable,
            "note": ("quotable" if quotable else f"n={n} < usable_n={USABLE_N}: not quotable")}

if __name__ == "__main__":
    print(json.dumps(score(sys.argv[1]), indent=2))
Three outcomes, kept apart on purpose. A run is MEASURED only when items parsed into labels; it is UNPARSEABLE when answers arrived but none could be read as a label; it is UNMEASURED when there was nothing to score. A dropped delivery is lane error and an unreadable answer is excluded — neither is ever averaged in as a zero, because a zero is a claim the model was wrong, and here it was not measured.

Provenance & what the signature covers

Provenance chain: published Code text → frozen commitment taxonomy → labelled corpus (content-hashed split) → deterministic scorer → per-item results → signed run record. Each stage names its input, and the record is only signed once a run has actually happened.

Measurement, not certification. When this axis is eventually run, the signed artefact is the route and the observation — which items were asked, what was answered, and how the deterministic rule scored them. It is never a verdict about a third party, never a statement that any provider does or does not comply with the Code, and never a certificate. The signature attests that a specific measurement was carried out as described; it attests to nothing about the subject of the measurement beyond that reading.
Measurement, not certification. CSOAI is not a certification body, does not certify, and is neither accredited nor applying for accreditation. It issues measurements and attestations, never certificates of conformity. Nothing on this page is a statement of conformity with any regulation, and it is not legal advice.
This axis is UNMEASURED: no score, no n, and no interval is published because none has been earned — the same rule that forbids us an interval below usable_n = 30 forbids us a number with no run at all. An answer that cannot be read is reported as UNPARSEABLE and excluded from any score, never counted as wrong. A run whose instrument error rate exceeds threshold is reported as a failed run, never as a low score.
