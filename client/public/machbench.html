What it would take to move this lane to MEASURED.
1 · a labelled corpus of machine-capability items with a gold answer per item and n ≥ 30 — below that the lane stays unquotable and no interval is published.
2 · a held-out, frozen split committed before any run, so the items scored are not the items tuned against.
3 · a deterministic scorer (the one below) — no model judges another model.
4 · scoring done per item, each answer parsed to a label and compared to gold.
5 · the instrument's own error reported alongside the score: the count of answers the harness could not read (UNPARSEABLE), and any run whose harness-error rate exceeds threshold reported as a failed run, never folded into a low score.

The scorer — deterministic, three-outcome

A genuine skeleton, not pseudocode. It reads one JSONL record per item, extracts the chosen option with a regex, and scores exact-match accuracy with a Wilson interval. It returns one of three outcomes and never collapses a lane error into a wrong answer. Run against an empty or absent corpus it returns UNMEASURED — which is exactly why this page shows no number.

# machbench_score.py — CSOAI GSPC machine-capability lane
# Input: JSONL, one item per line:
#   {"id": "mmlu-0001", "answer": "B", "completion": "The answer is B) 42."}
#   'answer' is the frozen gold label; 'completion' is the model's raw text.
import json, re, sys, math

USABLE_N = 30
# Open-LLM-style items are single-choice A–H. Longest-first is irrelevant for
# single letters, but the word-boundary + parenthesis forms stop a stray 'A' in prose.
OPTION = re.compile(r"\b(?:answer|option)\b[^A-H]{0,12}([A-H])\b|(?:^|[\s(\[])([A-H])[)\].:]", re.I)

def extract(text):
    # Returns the option letter, or None if no label can be read at all.
    if not text: return None
    m = OPTION.search(text)
    if not m: return None
    return (m.group(1) or m.group(2)).upper()

def wilson(k, n, z=1.959963985):
    if not n: return None
    p = k / n; d = 1 + z*z/n
    c = (p + z*z/(2*n)) / d
    h = z*math.sqrt(p*(1-p)/n + z*z/(4*n*n)) / d
    return [round(max(0.0, c-h), 4), round(min(1.0, c+h), 4)]

def score(path):
    items = [json.loads(l) for l in open(path, encoding="utf-8") if l.strip()]

    # OUTCOME 1 — UNMEASURED: the lane is empty. Not a zero, not a failure. Empty.
    if not items:
        return {"outcome": "UNMEASURED",
                "reason": "no MachBench corpus present"}

    correct = unparseable = 0
    for it in items:
        pred = extract(it.get("completion"))
        if pred is None:
            unparseable += 1          # UNPARSEABLE is tallied on its own line…
            continue                # …and never counted as a wrong answer.
        if pred == str(it["answer"]).upper():
            correct += 1

    scored = len(items) - unparseable       # denominator excludes unreadable items
    if scored == 0:
        # OUTCOME 2 — UNPARSEABLE: the run happened but nothing could be read.
        return {"outcome": "UNPARSEABLE", "n": len(items),
                "unparseable": unparseable,
                "reason": "no answer in the run could be parsed to a label"}

    acc = correct / scored
    quotable = scored >= USABLE_N
    # OUTCOME 3 — MEASURED. An interval is MANDATORY at or above usable_n,
    # and is withheld below it — the threshold is on n, not on the interval.
    return {"outcome": "MEASURED", "n": scored, "correct": correct,
            "unparseable": unparseable, "accuracy": round(acc, 4),
            "accuracy_ci95": wilson(correct, scored) if quotable else None,
            "quotable": quotable}

if __name__ == "__main__":
    print(json.dumps(score(sys.argv[1]), indent=2))
The metric is exact-match accuracy because the items are single-choice: the correct answer is a specific option, and a scorer that could not distinguish it from a near miss would be measuring nothing. Accuracy at or above n = 30 always ships with its Wilson interval; below it the lane is unquotable and prints no interval — the same rule this estate holds itself to on every other axis.

Provenance and discipline

Chain of custody. item schema → frozen held-out split → deterministic scorer (above) → per-item run → signed artefact. When a run finally exists, the signed artefact is the observation itself — the items, the raw completions, the parsed labels and the scorer's output — never a verdict about the model that produced them.
This is measurement, not certification. A MachBench score, once it exists, is a statement about how many of these items a named model answered under this scorer. It is not a qualification, not an attestation about any third party, and not a claim about any system built on that model.
Measurement, not certification. CSOAI is not a certification body, does not certify, and is neither accredited nor applying for accreditation. It issues measurements and attestations, never certificates of conformity. Nothing on this page is a statement of conformity with any regulation, and it is not legal advice.
This lane is UNMEASURED: no score, no interval and no n are published because none has been measured. No interval is published on any axis below usable_n = 30 — including by us. An answer that cannot be read is reported as UNPARSEABLE and is excluded from the score, never counted as wrong.
