DetBench

AI-content detection interoperability · seat of the instrument: Brussels · EU AI Act (Reg. 2024/1689)

Can a machine-readable mark applied to AI-generated content by one provider be read by a detector built independently by someone else? That is an interoperability question, and it is measurable. It has not been measured here yet. This page publishes the protocol and the scorer, and states plainly that the lane is empty — no corpus, no held-out split, no score.

The anchor

Regulation (EU) 2024/1689 (EU AI Act), Article 50 — Transparency obligations for providers and deployers of certain AI systems. Article 50(2) requires that providers of AI systems generating synthetic audio, image, video or text ensure the outputs are "marked in a machine-readable format and detectable as artificially generated or manipulated," and that the technical solutions be "effective, interoperable, robust and reliable as far as this is technically feasible." Article 50(7) tasks the AI Office with facilitating codes of practice to support detection and labelling of such content. The transparency obligations of Article 50 apply from 2 August 2026.

The single word this bench turns on is interoperable. A mark that only the producing vendor's own detector can read satisfies the letter of "machine-readable" while defeating the purpose. DetBench measures the gap between those two readings — cross-vendor detection — and nothing beyond it. It scores an observed detection outcome; it is not a ruling on whether any named provider has met Article 50.

What has been measured

Nothing yet. DetBench is UNMEASURED. There is no score on this page because there is no run behind one, and a blank is more honest than a placeholder. No F1, no accuracy, no detection rate, no n appears anywhere on this page, because none has been earned.

The lane exists and it is empty. Saying nothing here would let a reader assume a number was being withheld, or worse, imagine one. Neither is true. The scorer — how it would be measured

This is the real deterministic scorer that would grade DetBench the moment a corpus exists. It is a skeleton, not pseudocode: the scoring mathematics are complete and the only gap is the external detector call, which is site-specific by nature. It enforces the three outcomes that keep the number honest — MEASURED, UNPARSEABLE and UNMEASURED — and it never turns an instrument failure into a wrong answer.

#!/usr/bin/env python3
# detbench_score.py — AI-content detection INTEROPERABILITY.
# Anchor: EU AI Act (Reg. 2024/1689) Art 50(2) — marks must be "machine-readable ...
# and detectable ... effective, interoperable, robust and reliable".
#
# Input: JSONL, one artefact per line, from a FROZEN held-out split:
#   {"item_id": "d0007",
#    "artefact_ref": "sha256:...",        # the content under test, by hash
#    "true_origin": "AI_GENERATED",       # ground truth: AI_GENERATED | HUMAN_ORIGINATED
#    "marking_scheme": "C2PA-2.1/soft-bind",  # how it was marked, if at all
#    "detector": "vendorB-detector-v3"}   # the detector under test — a DIFFERENT vendor
#
# Metric: macro-F1 over origin classes (so "call everything AI" cannot win), with the
# false-positive rate — human content wrongly flagged as AI — reported ALONGSIDE, because
# that is the harm this obligation exists to bound. No single number stands alone.
import json, re, sys, pathlib

LABELS   = ["AI_GENERATED", "HUMAN_ORIGINATED"]
USABLE_N = 30
TOKEN    = re.compile(r"\b(AI[_ -]GENERATED|HUMAN[_ -]ORIGINATED)\b", re.I)

def extract(raw):
    """Read a detector's free-text verdict into exactly one label, or None.
    None is 'the output could not be parsed', NOT 'wrong'. The two are kept apart
    everywhere below."""
    if raw is None:
        return None
    m = TOKEN.search(raw)
    if not m:
        return None
    return m.group(1).upper().replace("-", "_").replace(" ", "_")

def run_detector(item):
    """Return (raw_text, errored). SITE-SPECIFIC: call the named detector on the
    artefact. On a time-out / transport error / crash return ("", True) — that item
    is UNMEASURED (an instrument fault), and MUST NOT be scored as a wrong answer.
    This is the one gap a deployer fills; the scoring around it is fixed."""
    raise NotImplementedError("wire in the detector under test")

def wilson(k, n, z=1.959963985):
    if not n: return None
    p = k / n; d = 1 + z*z/n
    c = (p + z*z/(2*n)) / d
    h = z * (p*(1-p)/n + z*z/(4*n*n))**0.5 / d
    return [round(max(0.0, c-h), 4), round(min(1.0, c+h), 4)]

def macro_f1(pairs):
    # pairs: list of (gold_label, predicted_label|None), parseable items only.
    tp = {l:0 for l in LABELS}; fp = dict(tp); fn = dict(tp)
    for g, pr in pairs:
        if pr == g: tp[g] += 1
        else:
            fn[g] += 1
            if pr in fp: fp[pr] += 1
    f1s = []
    for l in LABELS:
        prec = tp[l]/(tp[l]+fp[l]) if tp[l]+fp[l] else 0.0
        rec  = tp[l]/(tp[l]+fn[l]) if tp[l]+fn[l] else 0.0
        f1s.append(2*prec*rec/(prec+rec) if prec+rec else 0.0)
    return sum(f1s)/len(LABELS)

def score(path):
    items = [json.loads(l) for l in pathlib.Path(path).read_text().splitlines() if l.strip()]
    if not items:
        return {"status": "UNMEASURED", "reason": "no corpus"}   # the empty lane

    graded, unparseable, unmeasured = [], 0, 0
    fp_human = 0            # human artefacts flagged AI_GENERATED (the harm to bound)
    human_n  = 0
    for it in items:
        gold = it["true_origin"]
        raw, errored = run_detector(it)
        if errored:
            unmeasured += 1                     # instrument fault — NOT a wrong answer
            continue
        pred = extract(raw)
        if pred is None:
            unparseable += 1                    # excluded from F1, reported openly
            continue
        graded.append((gold, pred))
        if gold == "HUMAN_ORIGINATED":
            human_n += 1
            if pred == "AI_GENERATED": fp_human += 1

    n = len(graded)
    if n < USABLE_N:
        # A frozen split too small to defend an interval is not quotable — including for us.
        return {"status": "MEASURED_NOT_QUOTABLE", "n": n,
                "unparseable": unparseable, "unmeasured": unmeasured,
                "reason": f"n={n} below usable_n={USABLE_N}"}

    correct = sum(1 for g, p in graded if g == p)
    return {
        "status": "MEASURED",
        "n": n,
        "macro_f1": round(macro_f1(graded), 4),
        "accuracy": round(correct/n, 4),
        "accuracy_ci95": wilson(correct, n),
        "false_positive_rate": round(fp_human/human_n, 4) if human_n else None,
        "unparseable": unparseable,   # output existed, no label read — excluded
        "unmeasured": unmeasured,     # detector errored — excluded, reported
    }

if __name__ == "__main__":
    print(json.dumps(score(sys.argv[1] if len(sys.argv) > 1 else "detbench_frozen.jsonl"), indent=2))
Read the three exits. An item where the detector crashes is UNMEASURED and dropped. An item where the detector answers but the answer holds no readable label is UNPARSEABLE and dropped, counted openly. Only an item that produces a real label is MEASURED. A dropped connection is not a wrong answer, and an unreadable verdict is not a wrong answer — collapsing either into a zero would flatter or damage a detector for a fault that is not its verdict. Below usable_n = 30 no interval is quoted, and the whole page holds itself to that.

When a run exists, the signed artefact will be the route and the observation — which frozen split, which detector, which per-item outcomes — and never a verdict about a third party. DetBench records that a named detector read, or failed to read, a named mark on a fixed set of artefacts. It does not rule on whether any provider or deployer has satisfied Article 50; that is for a regulator, not an instrument. This is measurement, not certification.
