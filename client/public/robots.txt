# Content signals. Retained from the previous file — these were correct.
#
# Per the Content-Signal specification: if a signal is `yes` you may collect content for
# that use; if `no` you may not; if a signal is absent, permission is neither granted nor
# restricted by this mechanism.
#
#   search   — building a search index and returning links and short excerpts.
#              Does not include AI-generated search summaries.
#   ai-input — inputting content into AI models at request time: RAG, grounding,
#              generative search answers.
#   ai-train — training or fine-tuning AI models.
#   use      — how AI systems may consume the content: immediate, reference, or full.
#
# THE `ai-train=no` SIGNAL IS AN EXPRESS RESERVATION OF RIGHTS under Article 4(3) of
# Directive (EU) 2019/790 and is intended to have that legal effect. It is deliberate and
# should not be removed without a decision to license training use.
#
# `ai-input` is set to `yes`. This is the change of substance in this file. This estate
# publishes measurements so that they are read, cited and checked; an answer engine
# grounding a response in a CSOAI measurement is the intended use, and it is a different
# act from training on it. Reserving training while permitting grounding is a coherent
# position and is exactly the one the site's copy describes.
# ---------------------------------------------------------------------------

User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=no, use=reference
Disallow: /.backups/
Disallow: /_backup/
Disallow: /api/
Disallow: /*?*utm_
Allow: /
