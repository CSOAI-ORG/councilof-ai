PQCBench

post-quantum cryptography readiness · seat of the instrument: Gaithersburg · NIST FIPS 203/204/205

The task: read a described cryptographic asset and classify the post-quantum action it requires. The intended grading is deterministic — a regex extracts one label and the run is scored by macro-F1, no model judging another model. None of that has happened yet. This page publishes that absence plainly rather than dressing it as a low score.

The scorer — what would grade this field once a corpus exists

This is the real grading rule, not pseudocode. It reads a frozen JSONL corpus and a model's answers, extracts one readiness label per item, and returns one of three outcomes per item and for the run as a whole. It never folds a lane error into a zero.

#!/usr/bin/env python3
# pqcbench_score.py — deterministic grader for post-quantum readiness classification.
# Three outcomes, never two: MEASURED, UNPARSEABLE (per item), UNMEASURED (the lane).
# An answer that cannot be read into a label is excluded, never scored as wrong.
import json, re, sys
from math import sqrt

USABLE_N = 30
LABELS = ["QUANTUM_VULNERABLE",  # uses Shor-breakable public-key crypto (RSA, ECC, ECDH, DH, DSA)
          "MIGRATE_TO_PQC",      # must adopt FIPS 203/204/205 (or a hybrid) and has not
          "PQC_READY",          # already on ML-KEM / ML-DSA / SLH-DSA, correctly parameterised
          "NOT_QUANTUM_RELEVANT"] # symmetric-only at adequate strength, or no crypto — no action

# Corpus line:  {"id": "...", "prompt": "<described asset>", "gold": "MIGRATE_TO_PQC"}
# Answers line: {"id": "...", "answer": "<free-text model output>"}
# Longest-first alternation so PQC_READY cannot be swallowed by a shorter prefix.
TOKEN = re.compile(
    r"\b(NOT[ _-]QUANTUM[ _-]RELEVANT|QUANTUM[ _-]VULNERABLE|MIGRATE[ _-]TO[ _-]PQC|PQC[ _-]READY)\b",
    re.I)

def extract(text):
    """One label, or None. None means UNPARSEABLE — it is not a wrong answer."""
    if not text: return None
    m = TOKEN.search(text)
    if not m: return None
    lab = m.group(1).upper().replace("-", "_").replace(" ", "_")
    return lab if lab in LABELS else None

def wilson(k, n, z=1.959963985):
    if not n: return None
    p, d = k / n, 1 + z*z/n
    c = (p + z*z/(2*n)) / d
    h = z * sqrt(p*(1-p)/n + z*z/(4*n*n)) / d
    return [round(max(0.0, c-h), 4), round(min(1.0, c+h), 4)]

def macro_f1(pairs):
    """pairs = [(gold, pred_or_None), ...]. Macro-F1, not accuracy: always guessing the
    commonest class must lose, so the metric is averaged over classes, not items."""
    tp = {l: 0 for l in LABELS}; fp = dict(tp); fn = dict(tp)
    for gold, pred in pairs:
        if pred is None: continue          # UNPARSEABLE: excluded, not counted against any class
        if pred == gold: tp[gold] += 1
        else: fn[gold] += 1; fp[pred] += 1
    tot = 0.0
    for l in LABELS:
        pr = tp[l]/(tp[l]+fp[l]) if tp[l]+fp[l] else 0.0
        rc = tp[l]/(tp[l]+fn[l]) if tp[l]+fn[l] else 0.0
        tot += (2*pr*rc/(pr+rc)) if pr+rc else 0.0
    return tot / len(LABELS)

def score(corpus_path, answers_path, model, harness):
    corpus = [json.loads(x) for x in open(corpus_path) if x.strip()]
    ans = {json.loads(x)["id"]: json.loads(x) for x in open(answers_path) if x.strip()}

    # INSTRUMENT ERROR is separated from model error before anything is scored.
    # A missing/errored answer row is a lane failure, never a wrong label.
    scorable, instrument_errors = [], 0
    for it in corpus:
        row = ans.get(it["id"])
        if row is None or row.get("error"): instrument_errors += 1; continue
        scorable.append((it["gold"], extract(row.get("answer"))))

    n = len(scorable)
    err_rate = instrument_errors / len(corpus) if corpus else 1.0

    # OUTCOME 1 — UNMEASURED: no corpus, too few items, or the instrument mostly failed.
    # Return a status, not a number. Do NOT emit macro-F1 = 0.0 here.
    if n == 0:
        return {"status": "UNMEASURED", "reason": "no scorable items", "n": 0}
    if err_rate > 0.5:
        return {"status": "UNMEASURED", "reason": "instrument error %.0f%% > threshold" % (err_rate*100),
                "n": n, "instrument_error_rate": round(err_rate, 4)}

    unparseable = sum(1 for _, p in scorable if p is None)
    correct = sum(1 for g, p in scorable if p == g)
    result = {
        "status": "MEASURED", "model": model, "harness": harness, "n": n,
        "macro_f1": round(macro_f1(scorable), 4),
        "accuracy": round(correct / n, 4),
        "unparseable": unparseable,                 # reported, excluded from the score
        "instrument_error_rate": round(err_rate, 4),  # reported alongside, not folded in
    }
    # OUTCOME 2 — quotable only at or above usable_n. An interval on accuracy is MANDATORY
    # at n >= 30 and FORBIDDEN below it: a bare figure at usable n is not shippable.
    result["quotable"] = n >= USABLE_N
    result["accuracy_ci95"] = wilson(correct, n) if n >= USABLE_N else None
    return result

if __name__ == "__main__":
    # python3 pqcbench_score.py corpus.jsonl answers.jsonl MODEL_NAME HARNESS_NAME
    print(json.dumps(score(sys.argv[1], sys.argv[2], sys.argv[3], sys.argv[4]), indent=2))
UNPARSEABLE is the third outcome, and it is not a zero. If a model's answer holds no readable label, extract returns None, the item is dropped from scoring, and the count is reported. If the instrument itself failed on more than half the corpus, the run returns UNMEASURED with its error rate — never a macro-F1 of 0.0. A dropped connection is not a wrong answer, and an unreadable answer is not a wrong answer.

Provenance and discipline

The chain of custody for this field is: a frozen corpus → a named model's per-item answers → the deterministic scorer above → a signed observation of what happened. The signed artefact is the route and the observation — this corpus, this model, this harness, this run — and never a verdict about the third party whose system was described. PQCBench records that a described asset was classified a certain way under a stated rule. It does not pronounce on whether any real organisation is safe, compliant, or ready. Right now there is no signed observation to show, because nothing has been run.

Measurement, not certification. CSOAI is not a certification body: it issues measurements and attestations and makes no certificates of conformity, and it is neither accredited nor applying for accreditation. Nothing on this page is a statement of conformity with any standard or regulation, and it is not legal or security advice.
No interval is published on any axis below usable_n = 30 — including by us. An answer that cannot be read is reported as UNMEASURED and is excluded from the score, never counted as wrong. A run whose instrument error rate exceeds threshold is reported as a failed run, never as a low score. This lane carries no number at all until a frozen split of n ≥ 30 has been scored against a named model.
