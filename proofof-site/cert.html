📚 API Documentation

Issue a credential

POST /v1/cert/issue
Content-Type: application/json

{
  "subject_did": "did:csoai:user1",
  "course_id": "dora-1",
  "course_name": "DORA 5-Pillar Audit Mastery",
  "score": 95.0,
  "learner_name": "Sarah Chen"
}

Verify a credential

POST /v1/cert/verify
Content-Type: application/json

{
  "cert_id": "abc123..."
}

JavaScript SDK

import { SovereignCertification } from '@meok-os/cert-sdk';
const cert = await SovereignCertification.issue({
  subject_did: 'did:csoai:user1',
  course_id: 'dora-1',
  score: 95.0
});

📤 Issue your own credential

Use the MEOK OS sovereign certification MCP to issue credentials programmatically:

python3 -c "from meok_sovereign_certification_mcp import cert_issue; \
print(cert_issue('did:csoai:user1', 'dora-1', 'DORA', 95.0, 'Sarah'))"

📊 Why W3C Verifiable Credentials?

  • Universal portability — Works in any W3C-VC ecosystem (LinkedIn, Verifiable Credentials, EU eIDAS, etc.)
  • Cryptographic proof — Ed25519 signatures are universally verifiable
  • Privacy preserving — Zero-knowledge proofs possible (selective disclosure)
  • Decentralized — No central authority required to verify
  • Open standard — W3C Recommendation since 2022
