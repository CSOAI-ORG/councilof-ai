📋 Planning MCP — The 5th Core MCP

v1.0.0 MIT 19 tests ✓

Multi-step plans with care-floor BFT. Goals with weighted scoring. Sovereign history searchable by event type.

5 Tools

1. sov_plan_create

Create a multi-step plan. If care_floor_impact=True, BFT approval is required before execution.

2. sov_plan_step

Mark a step done. Propose the next. Auto-detect plan completion when all steps done.

3. sov_goal_set

Set a goal with care-floor weight + sovereign weight. Tracks progress towards completion.

4. sov_goal_progress

Update progress on a goal. Caps at 1.0 (100%). Emits care-floor + sovereign scores.

5. sov_history_search

Search the sovereign history (sigil-anchored JSONL). Filter by query + event_type + limit.

Bonus: Persistence

Every plan, goal, history event is persisted to history.jsonl + Ed25519-signed.

Usage

from meok_sovereign_planning_mcp import (
    sov_plan_create, sov_plan_step, sov_goal_set,
    sov_goal_progress, sov_history_search,
)

# 1. Create a multi-step plan
plan = sov_plan_create(
    "Launch the sovereign empire",
    steps=["Build MCPs", "Test", "Deploy", "Audit"],
    care_floor_impact=False,  # true if plan affects care floor
)
print(plan["plan_id"])  # → abc123
print(plan["status"])   # → APPROVED or PENDING_BFT

# 2. Mark step 0 done, propose next
next_step = sov_plan_step(plan["plan_id"], 0, done=True, next_proposal="Ship it")
print(next_step["next_step"]["text"])  # → "Test"

# 3. Set a goal
goal = sov_goal_set("Ship 22 sovereign MCPs", care_floor_weight=0.5, sovereign_weight=0.3)
print(goal["goal_id"])  # → def456

# 4. Update progress
prog = sov_goal_progress(goal["goal_id"], delta=0.5, note="11/22 shipped")
print(prog["progress"])             # → 0.5
print(prog["care_floor_score"])     # → 0.25
print(prog["sovereign_score"])      # → 0.15
print(prog["status"])               # → ACTIVE

# 5. Search history (sigil-anchored)
hist = sov_history_search("sovereign", event_type="goal_set", limit=10)
print(hist["match_count"])  # → N
print(hist["total_history"])  # → total events in sovereign log

Install

pip install meok-sovereign-planning-mcp

Use Cases

  • Multi-step workflows: deployment, audit, remediation, onboarding
  • Goal tracking: "Ship 22 MCPs by July 4" with care-floor + sovereign scoring
  • Sovereign history: searchable audit trail across the 12 Generals
  • Care-floor BFT: plans that affect care floor require BFT approval (3 voters)

Doctrine

Every plan, goal, and history event is Ed25519-signed. The sovereign substrate remembers. The 12 Generals share plans via the federation. Care floor is sovereign.
