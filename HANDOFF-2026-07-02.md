- Build: `npm run build:client` → `dist/client`. **The local machine has been under heavy load (load avg ~16, a VM + Spotlight)**, which repeatedly **starved full builds** (they hang at "transforming" for minutes).

## 2. Gotchas that already bit us
1. **esbuild ≠ Vercel resolution.** esbuild transform passes even if an import path is wrong-case; Vercel (Linux, case-sensitive) fails with "Could not resolve". macOS is case-insensitive so `write_file` to `WhyCsoai.tsx` silently landed in the existing `WhyCSOAI.tsx`. **Always match the git-tracked filename case** (`git ls-files client/src/pages | grep -i name`).
2. **Before creating a "new" page, check it doesn't already exist** under a different case (`WhyCSOAI.tsx` already existed). Duplicate imports/routes cause build breaks.
3. **`grep` substring counts are noisy** for verification (e.g. "AI OS" is inside "CSOAI OS"). Verify with unique strings.
4. Bash tool: `timeout` isn't available (zsh); long waits time out the tool at ~120s — poll in short steps.
