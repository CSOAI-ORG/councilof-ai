## 3. THE PDCA PLANNING LOOP (Plan-Do-Check-Act)

**The orb uses PDCA for every action:**

### Phase 1: PLAN (the simulation phase)
- **What:** The orb receives a goal (e.g., "deliver package to location X")
- **How:** The orb uses the SOV3 brain to:
  - Query the digital twin of the environment
  - Simulate 10-1000 candidate paths
  - Score each path (distance, time, risk, energy)
  - Select the optimal path
- **Output:** A detailed plan (sequence of muscle commands + sensor expectations + SIGIL signatures)

### Phase 2: DO (the execution phase)
- **What:** The orb executes the plan
- **How:** The orb:
  - Sends muscle commands to the MCMB orbs (via 4VF circulatory network)
  - Reads sensor data in real-time (visible + IR + WiFi CSI + LoRa + acoustic + magnetic)
  - Updates the plan dynamically
- **Output:** A trace of executed actions + real-time sensor data

### Phase 3: CHECK (the verification phase)
- **What:** The orb verifies that the execution matches the plan
- **How:** The orb:
  - Compares expected vs actual sensor data
  - Flags any deviations
  - Updates the SOV3 brain with the deviation
- **Output:** A deviation report (if any) + updated world model

### Phase 4: ACT (the correction phase)
- **What:** The orb corrects the plan based on the deviation
- **How:** The orb:
  - Re-plans from the current state
  - Updates the digital twin
  - Continues the loop
- **Output:** A new plan + continued execution

**The PDCA loop runs continuously** — every action is a PDCA cycle.

**The simulation-before-action capability:** the orb uses the digital twin to simulate 10-1000 candidate paths BEFORE taking any physical action. This makes the orb **10-100x faster** than a non-simulating robot.
