```bash
# 1. provision the GCP VM (if not already)
gcloud compute instances create meok-prod-vm \
  --zone=europe-west2-a \
  --machine-type=n2-standard-8 \
  --image-family=ubuntu-2204-lts \
  --image-project=ubuntu-os-cloud \
  --boot-disk-size=200GB \
  --boot-disk-type=pd-ssd \
  --network-tier=PREMIUM \
  --tags=meok-prod,https-server

# 2. reserve static IP
gcloud compute addresses create meok-prod-ip --region=europe-west2

# 3. attach static IP
gcloud compute instances add-access-config meok-prod-vm \
  --access-config-name=external-nat \
```

## 7. THE RECIPE (the per-hive recipe — the same 8 steps)

For each hive, the recipe is:

1. **Clone** the source repo: `git clone git@github.com:CSOAI-ORG/<hive>.git /opt/meok/<hive>/`
2. **Install** dependencies: `cd /opt/meok/<hive> && pip install -e .`
3. **Test** the install: `pytest tests/ -v` (must be 100% pass)
4. **Service** it as a systemd unit: `/etc/systemd/system/meok-<hive>.service`
5. **Enable** + start: `systemctl enable --now meok-<hive>`
6. **Verify** health: `curl http://127.0.0.1:<port>/health`
7. **Log** to SOV3 audit chain: `sigil_emit(line="Hive <hive> deployed at <port>")`
8. **Update** `meok.ai/<hive>` route with the live URL
