# clawd/AGENTS.md

**This file carries no instructions.** Agent behaviour for everything under `/Users/nicholas`
is defined in `/Users/nicholas/AGENTS.md`; repo-specific rules live in each project's own file
(for this estate, `clawd/councilof-ai/CLAUDE.md`).

What used to be here was a sprint status log — 67 DEFONEOS tick entries plus older mixed-format
lines, 72,682 bytes in total. Combined with the 28,168-byte root AGENTS.md that came to 100,850
bytes against DSH's 65,536-byte workspace instruction budget, so **every session loaded a
truncated copy and silently dropped 7,450 bytes off the tail**. A status log is a record, not an
instruction, and it should never have been competing for that budget.

The history is preserved verbatim in [`_alignment/DEFONEOS-TICKS.md`](_alignment/DEFONEOS-TICKS.md).
Nothing was deleted — the move was verified line-by-line, 67 tick lines and the stray entries,
with zero non-log content removed.

**If you are appending a status tick, put it in the log file, not here.**
