HTTP 402 MCP Payment

x402 — Payment Required Endpoint

MEOK AI implements the HTTP 402 Payment Required flow for MCP tool access. When a client invokes an MCP tool that requires payment, the server responds with a 402 Payment Required status describing the cost and available payment plans.

Flow Overview

1. Client calls an MCP tool — e.g. compliance_audit or governance_check.
2. Server returns 402 with a Payment-Required header + JSON body describing cost, tiers, and payment URL.
3. Client pays via the provided Stripe Checkout Session URL or submits a valid attestation token.
4. Client retries the call with a X-Attestation header containing the Ed25519-signed payment proof. Server verifies, processes, returns 200.
