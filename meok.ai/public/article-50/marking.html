Specification Overview

Article 50 requires that all AI-generated or manipulated content carries both a visible human-readable label and an embedded machine-readable marker. This page defines the technical formats, standards, and implementation requirements for each marking layer.

Compliance deadline: All deployers must implement both marking layers by 2 August 2026. MEOK Pro users get automated compliance tooling including C2PA, W3C, and XMP format support out of the box.

C2PA Provenance Metadata

The Coalition for Content Provenance and Authenticity (C2PA) standard is the leading technical framework for asserting content provenance and AI generation status. C2PA bindings are tamper-evident cryptographically signed assertions embedded directly in file formats.

How C2PA Works

  • Cryptographic signing of content provenance claims
  • W3C-compliant data model using JSON-LD assertions
  • Tamper-evident — any modification invalidates the signature
  • Portable across formats — JPEG, PNG, AVIF, MP4, WAV
  • Backwards-compatible — viewers without C2PA support ignore the data
  • Verifiable via public key infrastructure

Example C2PA Assertion

  "@context": "https://www.w3.org/ns/credentials/v2",
  "type": ["VerifiableCredential", "AIGeneratedContent"],
  "issuer": "did:web:meok.ai",

    "id": "urn:uuid:f81d4fae-7dec-11d0-a765-00a0c91e6bf6",

Watermarking & Digital Signatures

Visible Watermarking

Overlay-based labels applied directly to content. Best practice:

  • Position: bottom-right or top-left corner (consistent)
  • Opacity: 70—85% for readability without obscuring content
  • Content: "AI-Generated" + MEOK compliance badge
  • Persistence: burned into the raster layer (not a separate alpha channel)
  • Minimum size: proportional to content area (≥5% of shortest dimension)

Digital Signatures

Cryptographic proof of origin and content integrity:

  • Algorithm: Ed25519 or ECDSA P-384
  • Key management: HSM-backed or cloud KMS with audit logging
  • Signature binding: attached as C2PA/COSE signature block
  • Verification: public key distributed via .well-known/jwks.json
  • Revocation: OCSP or CRL for compromised keys

Metadata Injection

Embedded markers in standard metadata fields:

  • EXIF: XPAuthor + UserComment fields
  • XMP: dc:creator + xmpRights:Marked
  • IPTC: DigitalSourceType = "AlgorithmicGenerated"
  • ID3 (audio): TXXX frame with "AI-generated" flag
  • Matroska/WebM: <AI-Generated>true</AI-Generated>

Audio Watermarking

Imperceptible frequency-domain markers:

  • Spread-spectrum encoding in 2—4 kHz band
  • Survives: MP3 128kbps, AAC, Opus transcoding
  • Resistant to: time-stretching (±10%), pitch shifting (±3 semitones)
  • Payload: 64-bit assertion (generator ID + timestamp)
  • Detection: cross-correlation with known spreading sequence
