# Draft banks — the design a declared slot needs before an owner go becomes a run

The board's declared subject slots (10 of the 34 axes) say UNMEASURED because no
frozen bank backs them — not because nobody cares (work plan B4: "choose which
banks first, release the budget"). This directory removes the DESIGN half of that
wait: every draft here is complete enough that an owner go plus compute becomes a
run, not a project.

A draft graduates to a frozen bank only when it satisfies every section of
TEMPLATE.md and the freeze lands as sha-pinned JSON with an `.ots` stamp. A draft
that cannot name its referee, its sources, and its deterministic grading rule is
not a draft — it is a wish, and wishes do not belong in this directory.
