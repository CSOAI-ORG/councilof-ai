## Highest-priority next acceptance

Use the existing authority/effect path for **one exact harmless action** in an
owner-controlled sandbox. Prepare the proposal and its dependency hashes first.
An authenticated real human must approve that exact proposal; the executor must
repeat the scope, expiry, revocation and dependency checks at effect time. A
separate observer must read the actual effect and a second reader must reproduce
the receipt. A changed action, argument, source revision or approval state must
refuse execution. This package's logical simulation permit is not that approval.

Do not introduce a second review or decision store to bridge this package.
Adopt the existing canonical event and authority-effect profile, preserve
`UNMEASURED`/unsigned boundaries, and qualify the actual receiver before sending
anything. The existing public configuration observation from 30 October cannot
establish current human identity, accepted reviewer coverage or execution success.
