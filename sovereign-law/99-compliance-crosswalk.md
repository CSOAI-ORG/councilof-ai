## Crosswalk Methodology

The crosswalk was built by:
1. Identifying the 52 sovereign articles (Article 0 = Maternal Covenant, Articles 1-10 = governance, 11-20 = cryptographic, 21-30 = operational, 31-40 = sectoral, 41-52 = ratification/defense/dissolution).
2. Mapping each external framework's obligations to the sovereign articles.
3. Identifying gaps where the sovereign law exceeds the external framework (sovereign > external).
4. Identifying gaps where the external framework exceeds the sovereign law (external > sovereign).
5. Documenting the resolution for each gap (sovereign primacy, external compliance, exception window).

## Exception Window

A MEOK deployment that cannot comply with a sovereign article has a 90-day exception window to
remediate. The exception is SIGIL-signed, publicly announced, and tracked by the Public Watchdog.
Failure to remediate within 90 days triggers a deployment suspension.
