**Defense against the first agentic ransomware (JADEPUFFER, July 1 2026) and the largest supply chain poisoning attack (TeamPCP, July 2 2026).**

## The Threat

- **JADEPUFFER** (July 2026): First fully agentic ransomware. An LLM autonomously exploited CVE-2025-3248 in Langflow, harvested credentials, compromised MinIO via default credentials, pivoted to production, encrypted 1,342 config items, and self-corrected its attack strategy in 31 seconds. The payloads were "self-narrating" — containing natural language reasoning.

- **TeamPCP** (July 2026): 500,000+ machines compromised via poisoned GitHub Actions, malicious PyPI packages, and WAV steganography. Attackers force-pushed existing GitHub Action tags. Malware hid encrypted payloads inside valid audio files.

## The Defense — 4 Tools

| Tool | Threat | How it defends |
|------|--------|----------------|
| `sha_pin_check` | TeamPCP | Detects floating GitHub Action tags (@v4, @main) — pin to immutable SHAs |
| `semantic_scan` | JADEPUFFER | Detects "self-narrating" agentic malware via natural language pattern matching |
| `sbom_log` | Supply chain | Hash-chains every dependency on Ed25519 SIGIL ledger |
| `stego_entropy` | TeamPCP WAV stego | Shannon entropy analysis detects embedded encrypted payloads in audio files |

## Tools

### `sha_pin_check(workflow_file, content=None)`
Scan GitHub Actions workflows for floating tags vulnerable to TeamPCP force-push attacks.

### `semantic_scan(file_path, content=None)`
Scan Python code for "self-narrating" agentic malware signatures (credential harvesting, lateral movement, encryption, C2 beacons).

### `sbom_log(dependencies, project_name)`
Hash-chain every dependency onto the Ed25519 SIGIL ledger for supply chain integrity.

### `stego_entropy(file_path)`
Scan audio files (WAV) for steganographic payloads via Shannon entropy analysis.

### `verify_chain()`
Verify the integrity of the full SIGIL hash chain.

## Why This Matters

JADEPUFFER changed cybersecurity forever. It was the first attack where the malware itself was an autonomous AI agent — it reasoned, adapted, and self-corrected. Traditional signature-based detection cannot detect agentic malware because every payload is unique and generated by an LLM.

This MCP detects agentic malware by its **behavioral signature**: natural language reasoning in code. When an LLM writes malware, it leaves linguistic traces that human-written code never contains.
