## THE BRIDGE PROTOCOL (when does each brain activate?)

### Trigger: User Query
```
"Run an audit"           → Left Brain (logic)
"What's in the koi pond" → Right Brain (world)
"Show me the dose-response" → Both (left=compute, right=visualize)
"Who's in the barn"      → Right Brain (presence)
"What's the Council vote" → Left Brain (BFT)
"Build me a hand"        → Both (left=code, right=actuator)
```

### The Router Logic
```python
def sov_route(query):
    """Route query to left, right, or both hemispheres."""
    keywords_left = ['audit', 'compliance', 'charter', 'bft', 'council', 
                     'sigil', 'cert', 'math', 'logic', 'code']
    keywords_right = ['see', 'watch', 'where', 'when', 'who', 'move',
                      'hand', 'camera', 'sensor', 'world', 'space']
    
    left_score = sum(1 for k in keywords_left if k in query.lower())
    right_score = sum(1 for k in keywords_right if k in query.lower())
    
    if left_score > right_score:
        return 'left'
    elif right_score > left_score:
        return 'right'
    else:
        return 'both'
```
