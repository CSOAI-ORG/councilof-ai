### The Bridge Pattern

Each protocol gets:
1. **Adapter** — speaks the protocol's wire format
2. **Translator** — converts to SOV3 internal representation
3. **Signer** — SIGIL signs every interaction
4. **Auditor** — logs to chain
5. **BFT Gate** — council approves sensitive actions

## THE 4 TIERS OF DISCOVERY (how we connect)

### Tier 1: Direct Connect (we operate the server)
- SOV3 substrate runs the protocol server
- We control the schema, auth, audit

### Tier 2: Federation (we speak + verify)
- We implement the protocol client
- We call external servers, verify responses
- We sign our outgoing calls

### Tier 3: Routing (we pass through)
- We route calls to external servers
- We audit the calls (passive monitoring)
- We sign the routing decisions

### Tier 4: Monitoring (we observe)
- We tap protocol traffic (e.g., DNS, email, webhooks)
- We learn patterns, don't interfere
- We sign observations
