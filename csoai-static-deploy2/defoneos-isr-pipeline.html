🎯 Real-Time Object Detection

YOLOv8-m

80 classes

COCO-trained. Vehicles, personnel, aircraft, vessels. 45 FPS on RTX 3060. Edge-deployable via ONNX/TensorRT.

Orion

+12 military

Military-specific classes: tanks, IFVs, artillery, SAMs, UAVs. Trained on Sentinel-2 + Maxar imagery. Open source.

OpenAthena

<1m CEP

Drone-to-target geolocation. Uses drone telemetry + camera intrinsics. Sub-meter accuracy at 120m AGL.

Fusion Engine

5 sensors

Fuses EO/IR/SAR/RF/acoustic. Bayesian tracker. Multi-sensor correlation. False-positive suppression <0.1%.

Pipeline Stages

1

Collect

Drone (PX4/ArduPilot) + satellite (Sentinel-2/Maxar) + ground sensors (Flock cameras, ESP32-CAM) + ADS-B + AIS

2

Detect

YOLOv8 + Orion running on Jetson Orin (edge) or GPU server. Real-time <50ms latency. Output: bounding boxes + class + confidence

3

Geolocate

OpenAthena: drone telemetry → WGS84 coordinates. SAR georectification. Multi-angle triangulation for static targets.

4

Track

Bayesian multi-target tracker. Maintains tracks across sensor gaps. Predicts future positions. Correlates across EO/IR/RF.

5

Visualise

Cesium 3D globe with real-time overlays. TAK-compatible (CoT messages). Streaming to ATAK/WinTAK. Browser-based COP.
