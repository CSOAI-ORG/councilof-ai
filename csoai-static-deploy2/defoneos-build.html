CI Pipeline Steps

Security scan (pip-audit, npm audit) ├── 6. Build artifacts ├── 7. Deploy to Vercel (preview) ├── 8. Smoke test (curl HTTP 200) ├── 9. Emit SIGIL receipt (Ed25519 signed) └── 10.
