DEFONEOS for Gaming

The same OS that runs defence scenarios also powers game worlds. Dual-use crossover.

UE5 Integration

DEFONEOS SOV SPACE runs on Unreal Engine 5. The same physics, the same AI, the same swarm intelligence. A defence simulation and a game world use the same engine. The difference is just the scenario file.

Swarm AI for NPCs

The bio-cyber swarm (worms, hornets, killer bees) uses multi-agent reinforcement learning (Mava MARL). This same technology can power NPC swarms in games — enemies that learn, adapt, and coordinate like real players.

SIGIL for In-Game Economy

SIGIL chain can audit in-game economies — verifying item ownership, transaction history, and preventing duplication exploits. The same Ed25519 audit trail that proves compliance to auditors can prove fair play to gamers.

Cesium for Games

The Cesium 3D globe (350M buildings, real terrain) can be used as a game world. Real-world locations as game maps. Real-time weather from Met Office MCP. Live AIS vessel data for naval games.
