🏗️ Deployment Modes

1. Local Development

Single machine. Full capability.

  • MacBook (M2/M3/M4) or Linux
  • Ollama local models
  • All MCPs running locally
  • SIGIL chain on local disk
  • No network required

DEFAULT

2. Production Cluster

Multi-node sovereign mesh.

  • M4 (primary) + M2 (edge) + GCP VM (UK region)
  • SSH tunnels with KeepAlive
  • Model routing across nodes
  • PostgreSQL on UK VM
  • LAN + controlled VPN

ACTIVE

3. Air-Gapped

Classified environment. Zero external network.

  • No internet. No cloud. No external API.
  • Local models only (Ollama)
  • Data ingestion via Thunderbolt diode
  • SIGIL chain batch-synced on return
  • Battery-capable (M2)

TACTICAL

4. Coalition Mode

Multi-national deployment with sovereignty preservation.

  • Each nation runs own DEFONEOS instance
  • Federated SIGIL chain (cross-attested)
  • BFT council includes allied agents
  • Data sharing governed by classification labels
  • AUKUS / Five Eyes compatible
  • No single nation has override

5. Edge Deployment

Forward operating base or field HQ.

  • M2 MacBook Air (man-packable)
  • USB-C battery bank (10-12h operation)
  • Local 3B models for real-time inference
  • Sensor data via MQTT/RTSP local network
  • SIGIL chain deferred sync
  • Fanless. Low thermal signature.
