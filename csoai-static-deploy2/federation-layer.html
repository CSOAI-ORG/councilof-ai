§ 06 · WIRE-IN

The 3-patch canonical pattern

Adding a new MCP tool to the federation takes 3 patches. No external scaffolding. No drift. The same recipe for every tool, every hive, every domain.

1

PATCH · the mcp_federation_search index

mcp_federation_search.py
# Append the new tool's signature to the searchable catalog
{
  "server": "my-new-mcp",
  "tool": "my_new_tool",
  "doc": "One-line description",
  "category": "compliance",
  "tags": ["eu-ai-act", "art-50"]
}
2

PATCH · the SIGIL emission hook

mcp_federation_call.py
# Wrap the call in sigil_emit() — Ed25519 over the call args
async def my_new_tool(args):
    sigil_id = sigil_emit(
        op="Q",
        actor="my-new-mcp",
        action="my_new_tool",
        args=args
    )
    result = await do_work(args)
    sigil_emit(op="P", ref=sigil_id, result=result)
    return result
3

PATCH · the OLM router training pair

olm_train_router.py
# Add the QA pair — teaches the router when to use this tool{
  "query": "natural-language user request",
  "route": "my-new-mcp.my_new_tool",
  "score": "1.0",
  "sample_call_id": "sigil_id"
}
# Then: olm_train_router()

Total wire-in time: ~ 9 minutes · 3 files · 0 config drift · SIGIL guaranteed
