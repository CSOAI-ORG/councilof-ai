10. The Weekly Friday 16:00 BST Review

Every Friday at 16:00 BST, 30-min block, the sovereign review. Five things happen:

  1. Re-rank tiers — any buyer whose signal_score crossed 60 promotes up a tier; any below 15 demotes down a tier.
  2. Re-estimate deal_value — adjust based on the latest reply/intelligence.
  3. Move to CLOSED — any buyer with 90d silence OR explicit decline → state = CLOSED, honesty_flag = 🟡 or 🔴.
  4. Open new DISCOVER — if a new buyer surfaces (referral, event, RSS), create a fresh row with state = DISCOVER.
  5. Roll the 90-day calendar forward — every active buyer gets their next 7 touchpoints re-stamped onto the new 90-day window.

11. The Anti-Stale Guarantee

The CRM decays by design if not maintained. The penalties (-10 / -25 / -50) make stalling visible. No buyer can sit in DEMO for 60 days without the signal-score collapse triggering a Friday-review promotion-or-close decision. This is sovereign-by-construction: the data model makes lying-to-yourself impossible.

12. The Reporting Layer

Three sovereign reports auto-generated every Friday:

  • Pipeline-by-tier: count of buyers × state × tier × sum(deal_value). Visible at a glance which tier is converting.
  • Stalled buyers: any row where state = DEMO and last_touch > 14d → must be actioned or moved.
  • Honesty-flag roll-up: count of 🟢 / 🟡 / 🔴 across the 12 rows. If 🔴 > 3, sprint retro must address.

13. The Audit Trail (BFT-defensible)

Every state transition is logged in the append-only Touch Log table with a SHA-512 hash of the row's contents at that moment. This means anyone — including the 33-agent BFT council or the AUKUS-aligned external verifier — can replay the buyer's journey from DISCOVER to CLOSED and prove no field was tampered with. DEFONEOS-SEAL issuance (for CLOSED-WON) requires the audit trail to be intact.
