🔬 Probe Methodology

For each artefact, the freshness probe executes 4 steps:

  1. HEAD request. Confirm artefact is served at the canonical URL and returns HTTP 200.
  2. SIGIL receipt fetch. Fetch the SIGIL receipt (BLAKE3 digest + Ed25519 signature + timestamp) from the witness-list endpoint.
  3. Digest recompute. Recompute the BLAKE3 digest of the artefact body and compare to the SIGIL receipt.
  4. Signature verify. Verify the Ed25519 signature on the SIGIL receipt using the pinned DEFONEOS verification key.

Result: FRESH if all 4 pass AND timestamp < 24h. STALE if all 4 pass but timestamp ≥ 24h. TAMPERED if any of steps 2-4 fails.
