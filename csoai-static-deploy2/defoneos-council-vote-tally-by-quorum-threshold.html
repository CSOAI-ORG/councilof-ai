🛡️ Red-Line Invariants (7)

  1. Owner cosign for SEAL. R1 owner cosign is required for any motion to be SEAL-eligible. Without cosign, the motion is operationally valid but cannot generate a DEFONEOS-SEAL.
  2. Witness fingerprint match. 3 witnesses per ring (15 total) must produce matching tally receipts. Any single disagreement escalates the motion to red-line status automatically.
  3. Threshold computation must match the motion class. A motion filed as standard (23/33) cannot be approved with only 22 approve votes even if R1 cosign is present.
  4. Red-line vector explicit in motion text. Every red-line motion must name the specific red-line vector (US CDN / US root CA / US cloud API / US NTP / US telemetry / US-vendor JS / kinetic).
  5. R5 amendment integration. If R5 files an amendment, the final motion text must include the amendment; otherwise the motion fails on procedural grounds.
  6. Emergency sunset compliance. Emergency motions auto-sunset at 72h unless confirmed by a standard 23/33 vote. Witness logs must record the confirmation vote.
  7. Unanimous requires full witness set. 33/33 motions require every council seat to sign. Any abstention demotes the motion to constitutional (30/33) and the motion is re-filed.
