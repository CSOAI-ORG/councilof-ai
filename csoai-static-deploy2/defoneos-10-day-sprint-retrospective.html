5. What Worked — Pattern Library

  1. Tick cadence (every 2h) — forced regular shipment, prevented drift. 63 ticks over 10 days = avg 6.3/day.
  2. Byte-verified HTTP checks — every deployment verified with curl + content-length byte-match. Zero "I think it deployed" claims.
  3. SHA-512 chain per tick — every artefact signed. Audit trail is forensically recoverable.
  4. 33-agent BFT sign-off — every customer-facing artefact (first-email, pricing, objections) voted on. No single-agent reasoning.
  5. Owner-gate stack isolation — DSP / SC / Cyber Essentials / DASA / DIANA kept separate from autonomous ticks. Never blocked sprint.
  6. Day-10 activation pack — built backwards from "what does Nick need at 09:00 BST 14 Jul?" (CRM + email + portfolio + call-prep + pricing + objection + referral + Day-0 runbook + second-meeting).
  7. 3-variant referral letter — primes / academics / standards bodies each get tailored language. One-size-fits-all = no reply.
  8. Anti-spam calibration — first-email tested against SpamAssassin 0.4 + Mail-Tester 9.6 + Outlook ATP + Gmail Primary. Never get caught in spam on Day-10.
