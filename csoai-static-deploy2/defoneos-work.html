2. Build an MCP Server

Use the Mavis 7-file pattern (pyproject.toml + LICENSE + .gitignore + __init__.py + server.py + README.md + tests/). Pick any public UK data source and wrap it as an MCP server. Submit a PR to the CSOAI-ORG GitHub.

3. Improve a Page

All 60+ DEFONEOS pages are in ~/clawd/csoai-static-deploy2/defoneos-*.html. Find one that's thin or outdated. Add a tab. Add a table. Add real data. Submit a PR.
