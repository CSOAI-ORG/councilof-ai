What is OSCAL?

OSCAL (Open Security Controls Assessment Language) is a NIST-standardized set of XML, JSON, and YAML formats for representing security control information. DEFONEOS encodes its compliance posture as machine-readable OSCAL artifacts — enabling automated assessment, continuous monitoring, and real-time compliance gap detection.
