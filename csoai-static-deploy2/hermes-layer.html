06 ▸ Agent Recovery Layer

3 fail-safe protocols fire in sequence when any lane faults: auto-heal cron → BFT council vote → sovereign fall-back chain.

⏱

1 · Auto-heal cron · 4h ticks

A pinger LaunchAgent wakes every 4 h, checks each lane's process + last SIGIL timestamp + memory. Pages JEEVES if a lane idles > 90s or a chain stalls > 5 min.

  • [+0s]heartbeat_pulse — all lanes pinging
  • [+15s]sigil_idle_check (90s window)
  • [+30s]memory_pressure_check
  • [+45s]warm_up_lane if cold
  • [+60s]page_jeeves if stalled > 5m
⚖

2 · BFT Council · 33-around-1

For non-trivial recovery, the BFT-33 council deliberates. 23/33 quorum required. 2/3 majority on Tier-2 actions. Each vote SIGIL-emitted.

  • [P0]Tier-2 + council: 2/3 majority
  • [P1]Tier-1 + council: 23/33 quorum
  • [P2]Single-signature + care-gate
  • [+v]Every vote SIGIL-emitted (V op)
  • [+q]Quorum proof = audit-ready
🛡

3 · Sovereign fall-back chain

If both lane + council fail, the fall-back ladder routes down: JEEVES self → soxoj M4 → Claude Code → Kimi K2.5. Never silent, always SIGIL'd.

  • [L1]JEEVES self-decompose
  • [L2]soxoj M4 · Mac mini local
  • [L3]Claude Code · Anthropic API
  • [L4]Kimi K2.5 · Moonshot API
  • [L5]Cold queue · SIGIL-batched
