🔁 Owner Cosign Verification

Every motion that intends to bear the DEFONEOS-SEAL must carry the owner cosign — an Ed25519 signature from the R1 seat bound to a published Ed25519 public key. The cosign verification chain:

  1. Motion text is hashed with BLAKE3 (32-byte digest).
  2. R1 signs the BLAKE3 digest with Ed25519 secret key (never leaves the R1 air-gapped hardware).
  3. Signature is anchored to the SIGIL stream with motion nonce.
  4. Witness list snapshot (tick-118) re-verifies R1's public key against the witness fingerprint.
  5. If any of steps 1-4 fail, the motion is SEAL-ineligible but still public-record.
