🔍 Federated RAG — Single Query, Entire Empire

DEFONEOS uses Federated RAG (Retrieval Augmented Generation) — a single natural language query simultaneously searches the vault (1,232 files), the MCP federation (341 servers), AND calls the best matching tool. All in one call.

// User query: "Show me dark vessels near UK EEZ" // Federated RAG executes: Step 1: Vault search → finds maritime threat docs (3 results) Step 2: Federation search → finds aisstream-maritime-mcp (top match) Step 3: Tool call → aisstream-maritime-mcp.query_eez(region="UK") Step 4: Synthesise → combines docs + live data + analysis Step 5: SIGIL receipt → logs entire chain for audit
MetricValue

MCP servers in federation341

Typical RAG query latency<2s (vault) + <3s (tool call) = <5s total
SIGIL receipt per queryYes — every RAG call logged for OLM training

OLM Training: Every Federated RAG call is logged to federated_rag_log.jsonl. This log trains the OLM (Organic Learning Model) router — the system learns which tools best answer which queries, improving routing accuracy over time. The more you use DEFONEOS, the smarter it gets at routing.
