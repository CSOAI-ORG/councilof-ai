2. The DEFONEOS 5-Instance Federation Model

DEFONEOS is not a single product. It is a federation protocol that runs as 5 independent sovereign instances, one per FVEY nation. Each instance:

  • Operates entirely on its own nation's soil (UK → UK, US → US, CA → CA, AU → AU, NZ → NZ).
  • Has its own sovereign BFT-33 council (12 Generals × 3 roles, all nationals of that nation).
  • Has its own SIGIL chain, signed with that nation's sovereign Ed25519 keypair (held in sovereign HSM).
  • Has its own classification-aware data labelling, default NOFORN (Not Releasable to Foreign Nationals) at ingestion.
  • Federates with the other 4 instances only over a controlled coalition network with explicit REL TO FVEY / REL TO EYES ONLY release controls.

4. Classification-Aware SIGIL Audit Chain

Every DEFONEOS SIGIL receipt is signed with classification metadata at the data layer. This is the key technical differentiator vs Palantir/Anduril:

{ "sigil_id": "sigil-fvey-2026-07-09-abc123", "ts": "2026-07-09T14:23:01.456Z", "op": "M", // M = MODIFY "system_id": "defoneos-uk-001", "actor": "uk-sage-agent-3", "action": "ingest.isr.detection", "data_classification": "SECRET//REL TO FVEY", "data_originator": "UK", "release_control": "REL TO FVEY", "dissemination": ["UK","US","CA","AU","NZ"], "redacted_for": [], "sig_payload": "...", "ed25519_signature": "...", "uk_hsm_id": "YubiHSM2-A1B2C3", "prev_sigil_hash": "...", "sigil_hash": "..." }

When this receipt is replicated to the US FVEY node, the CDS (Cross-Domain Solution) guard reads the dissemination field and strips any data tagged with originator-only or NOFORN. The receiving US node's SIGIL chain is signed with a US Ed25519 key but the metadata trail is preserved — UK can prove the data was redacted at the CDS, not the US node.
