8. Federation Technical Spec (for SDA Teams)

8.1 MCP Protocol Integration

DEFONEOS exposes 30 MCP servers via the standard Model Context Protocol (JSON-RPC 2.0 over stdio, HTTP, or WebSocket). A typical integration:

8.2 SIGIL Chain Federation

When a prime federates, they receive a designated SIGIL chain partition. The prime's own actions are signed with their own Ed25519 keypair and chained into the shared audit log. The BFT-33 council votes on consequential events (kill decisions, exfiltration events, certification issuance).

8.3 Sovereign UK Compute

DEFONEOS runs on the prime's own UK sovereign compute (M2/M3/M4 Macs, on-prem GPU cluster, or GCP-UK-SOUTH-2). No byte leaves UK soil. No dependency on AWS / Azure / Palantir / Google Cloud.

8.4 Open Source Licence (Apache 2.0)

All substrate code is Apache 2.0 — the prime can inspect every line, modify, and self-host. The white-label licence grants commercial use with no per-seat fees. The only reserved items are: (a) the DEFONEOS brand and trademark, (b) the BFT-33 General agent personas, and (c) the SIGIL Bitcoin anchoring service (optional paid add-on).
