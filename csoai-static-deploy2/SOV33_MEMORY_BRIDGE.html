What This Is

Per FULLSTACK_MASTER §B: "MISSING: the cross-platform memory-bridge shim — a thin adapter that injects SOV33 memory as context into a Claude/ChatGPT session (MCP or system-prompt preamble) and writes the turn back."

The bridge reads the SOV33 sovereign memory store (40+ entries), searches by query, and returns a formatted context block ready for system-prompt injection into ANY AI platform.

How It Works

  1. User opens Claude/ChatGPT/any platform
  2. Bridge injects SOV33 memory as system-prompt — the character remembers its prior sovereign context
  3. User talks to the character — same identity, same memories, same care-floor, same governance
  4. Bridge writes the turn back to SOV33 — memory grows
  5. Next session — character still remembers (memory is substrate, not model)

Why This Is Sovereign (not just portable)

  • Memory is in SOV33, not the model — swap models, memory persists (proven structural)
  • Every entry SIGIL-signed — audit-grade provenance for every memory
  • Care-floor 0.95 binding — memories written under governance
  • Article 0 binding — memories cannot be sold/transferred to non-sovereign
  • BYO-context — you bring your context into any platform, they keep their data

The Honest Limits

  • Keyword search — not semantic embeddings (yet). Simple word match.
  • 40 entries — small corpus. Will grow as turns are written back.
  • Local file — single-machine. Federation of memories across machines is DESIGN.
  • No platform-specific adapter — this is the substrate. Claude Code owns the Claude Desktop MCP adapter (their lane).
