📋 Step-by-Step: Defence Sourcing Portal (DSP) Route

The DSP is the UK MOD's primary procurement platform. DEFONEOS can be listed as a supplier once CSOAI Ltd (Companies House 16939677) completes registration.

1

Supplier Registration on DSP

Action: Register CSOAI Ltd on the Defence Sourcing Portal as an approved supplier.

Requirements: Companies House number (16939677), Cyber Essentials certificate (in progress), SC clearance (application started), financial statements.

Time: 2-4 weeks · Status: BLOCKED — Needs Nick's company details

URL: https://www.contracts.mod.uk/

2

Cyber Essentials Certification

Action: Complete Cyber Essentials Plus certification (mandatory for MOD suppliers).

Requirements: Firewall config, secure configuration, user access control, malware protection, patch management.

Cost: £320-600 · Time: 1-2 weeks · Status: BLOCKED — Needs company info

Assessor: IASME (approved scheme delivery partner)

3

SC Clearance Application

Action: Initiate Security Check (SC) clearance for key personnel handling classified work.

Requirements: BPSS baseline, UK residency (5+ years), sponsorship by MOD/contractor.

Time: 4-6 months · Status: BLOCKED — Needs Nick's personal details

Level: SC (Security Check) — sufficient for SECRET material

4

Response to MOD Tender / Competition

Action: Once registered, respond to relevant MOD competitions or direct approaches.

Typical DEFONEOS Use Cases:

  • ISR sensor fusion for regional command
  • HADR (Humanitarian Assistance / Disaster Relief) coordination
  • C-UAS (Counter-drone) defence for critical infrastructure
  • Coalition interoperability (AUKUS / Five Eyes data sharing)
  • Air-gapped field deployment for deployed operations

Documentation Package: DEFONEOS architecture whitepaper, security case, SIGIL audit trail sample, MCP module list, deployment runbook, case studies.

5

Evaluation & Pilot Deployment

Action: Deploy DEFONEOS in a controlled evaluation environment for MOD assessment.

Pilot Scope: 3-6 MCP modules, 14-day evaluation, SIGIL audit chain, BFT governance demo.

Deliverables: Operational report, performance benchmarks, security assessment, user feedback.

Time: 4-8 weeks · Cost: £0 (open-source evaluation) or £15K-50K (supported pilot)

6

Full Deployment & Support Contract

Action: Transition from pilot to operational deployment with ongoing support.

Contract Types: Fixed-price deployment + annual support (Pro tier), or managed service (Governance tier).

Timeline: 2-4 months from pilot to full deployment.
