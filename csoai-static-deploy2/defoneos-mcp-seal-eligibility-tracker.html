🏅 SEAL Criteria (7)

An MCP becomes DEFONEOS-SEAL eligible when ALL 7 criteria are satisfied:

  1. SBOM published. SPDX 2.3 SBOM bundle on www.csoai.org/sbom/ with Ed25519 signature from DEFONEOS release key. Freshness probe must return FRESH within 24h.
  2. Red-line scan PASS. All 7 red-line vectors pass (US CDN / US root CA / US cloud API / US NTP / US telemetry / US-vendor JS / kinetic patterns). 30/30 PASS across the fleet; 210/210 vector checks PASS.
  3. Compartment scope boundary declared. MCP must declare which of the 7 compartment scope boundaries it operates within. Cross-compartment references require explicit council approval.
  4. Owner cosign on activation motion. The BFT council motion that promoted the MCP must carry R1 owner cosign. Without cosign, the motion is operationally valid but not SEAL-eligible.
  5. Pen test cycle complete. At least one pen-test cycle (PT-YYYY-QN-CX) must have completed within the last 180 days, with 0 CRIT and 0 HIGH findings.
  6. Witness set rotation up-to-date. The MCP's witness set must have rotated within the last 90 days (R4 monthly) or 180 days (R2/R3 quarterly / R5 semi-annual).
  7. 33-agent BFT council vote (quorum 23/33). A standard 23/33 motion explicitly voting to issue SEAL to the MCP must pass. This is the final gate; until then the MCP is a candidate.

🛡️ Red-Line Invariants (4 specific to SEAL)

  1. SEAL issuance requires 33/33 unanimous vote. Owner-seat activation ceremony — not standard 23/33. This protects against premature SEAL issuance without owner authority.
  2. SEAL revocation is a 27/33 red-line motion. Higher threshold than standard to prevent frivolous revocation. Any ring may file the motion; R5 cannot veto.
  3. SEAL signature chain must be Ed25519. No RSA, no ECDSA-P256, no SHA-1 — only Ed25519 from the DEFONEOS release key. Verification key pinned in the csoai-defoneos charter.
  4. SEAL is non-transferable. Bound to MCP identifier (compartment:meok-defoneos:category:MCP-ID). Cannot be re-assigned, sold, or licensed. Re-issuance requires fresh BFT motion.
