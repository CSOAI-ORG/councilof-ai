Troubleshooting sovereign operations — 12 scenarios, 5-step ladder, 14 errors.

This page is the canonical troubleshooting surface for sovereign operators. Each scenario is a named failure mode with a 5-step escalation ladder. Each error code in the lookup table is resolved with a SIGIL-anchored recipe. No destructive action proceeds without human-owner cosign.

Escalation ladder

  1. L1 — operator self-serve. Try the recipe. Sign the action. SIGIL record.
  2. L2 — operator + on-call witness. 2-of-2 signed action. SIGIL pair-record.
  3. L3 — operator + on-call + quorum. BFT vote required (≥17/33 emergency threshold).
  4. L4 — operator + owner cosign. Human-owner biometric-gated cosign required.
  5. L5 — locked + page owner. Red-line flag. Owner wakes. Quorum 27/33 supermajority to recover.

12 named failure scenarios

S1 · BFT_QUORUM_LOST SEV1

Symptom: SIGIL gap or quorum-drop alert; new motions cannot pass.

Step 1: Check BFT council pod status kubectl get pods -n defoneos-bft. Step 2: review witness quorum log. Step 3: if ≥10 witnesses down, page on-call L4. Step 4: trigger emergency session protocol. Step 5: BFT supermajority vote 27/33 — never reduce quorum below 23/33.

S2 · SIGIL_GAP_DETECTED SEV2

Symptom: SIGIL sequence number skips. Sequence index mismatch.

Step 1: Read sequence index from sigil-index.json. Step 2: query last 10 SIGILs from witness. Step 3: identify gap entry. Step 4: if entry missing from 3-of-3 witnesses, treat as compromised; L3. Step 5: BFT supermajority to issue replacement SIGIL.

S3 · RED_LINE_ATTEMPT SEV1

Symptom: Any agent or operator attempts a red-line action.

Step 1: Action is auto-rejected at policy layer. Step 2: SIGIL records the attempt (signed by anti-policy). Step 3: Notify human-owner within 5 minutes. Step 4: BFT supermajority vote 27/33 — owner-signed disclosure. Step 5: If pattern repeats, freeze agent-id pending investigation.

S4 · KEY_ROTATION_FAILURE SEV2

Symptom: Shamir split generation fails; ring quorum unreachable.

Step 1: Check ring health. Step 2: degrade to 2-of-2 emergency. Step 3: trigger emergency rotation procedure. Step 4: BFT quorum to ratify. Step 5: post-rotation SIGIL must be verified before service resumes.

S5 · TLS_PINNING_MISMATCH SEV2

Symptom: SPKI / full-cert pin fails; agent refuses to connect.

Step 1: Read current pin set. Step 2: check rotation calendar. Step 3: if rotation due, push new pin via SIGIL ledger update. Step 4: 3-witness verification on pin update. Step 5: document in pin rotation log.

S6 · MCP_ADMISSION_BLOCKED SEV3

Symptom: New MCP fails admission control.

Step 1: Read admission log. Step 2: identify failing check (SBOM, signature, owner, scope, capability, identity). Step 3: fix the failing check. Step 4: re-submit MCP. Step 5: SIGIL record admission event.

S7 · SUPPLY_CHAIN_INTEGRITY_FLAG SEV2

Symptom: SBOM hash or Ed25519 SIGIL on a layer fails.

Step 1: Identify failing layer (L1 OS → L7 data). Step 2: suspend the layer. Step 3: query upstream registry. Step 4: if upstream signature diverges, treat as compromise. Step 5: BFT vote to roll back to prior known-good hash.

S8 · INCIDENT_RESPONSE_TRIGGER SEV1

Symptom: External report · breach detection · CSP violation · forensics alert.

Step 1: Open SEV1 incident. Step 2: engage 7-phase IR runbook. Step 3: BFT containment vote (≥17/33 emergency threshold). Step 4: forensic capture (7-year retention). Step 5: post-incident review + BFT-ratified disclosure.

S9 · DATA_ESCROW_HOLD SEV3

Symptom: Escrow release request denied by policy.

Step 1: Check escrow policy state. Step 2: verify legal warrant or owner-signed attestation. Step 3: 3-witness quorum. Step 4: ratify release SIGIL. Step 5: log release in escrow audit trail.

S10 · PROMPT_INJECTION_DETECTED SEV2

Symptom: Trusted Instruction Hierarchy detects instruction injection.

Step 1: Quarantine affected tool output. Step 2: log to defense spec. Step 3: review 7 defense layers. Step 4: if injection reached L7, freeze model output. Step 5: BFT ratification + post-incident review.

S11 · FEDERATION_DISCOVERY_FAILURE SEV3

Symptom: P2P manifest lookup fails; agent cannot find peer.

Step 1: Verify manifest signatures. Step 2: check 6-state lifecycle. Step 3: re-broadcast peer manifest. Step 4: 3-witness verification. Step 5: log in federation log.

S12 · HUMAN_OVERRIDE_LOCKOUT SEV1

Symptom: Owner cannot cosign a red-line action.

Step 1: Verify biometric gate (Secure Enclave). Step 2: fallback identity path (key + PIN). Step 3: 3-of-3 emergency witnesses. Step 4: BFT supermajority to ratify. Step 5: post-event forensics + owner verification.
