🔒 The Three Problems Open Source Solves

1. Trust: You don't trust us? Read the code. Fork it. Audit it. Build it yourself. Run it on your own infrastructure. You never need to trust CSOAI — you trust the code you've verified.

2. Cost: No proprietary licensing. No per-seat fees. No vendor lock-in. Deploy DEFONEOS for £50K (consulting + setup) or for free (DIY). The MOD can run it on their own bare metal with zero ongoing license payments.

3. Security: "Given enough eyeballs, all bugs are shallow." — Linus's Law. Open code is MORE secure because anyone can find vulnerabilities — not just the vendor. Security through obscurity has failed repeatedly in defence procurement.

ITAR & Export Control Analysis

Open source software published under Apache 2.0 is generally ITAR-exempt under the US Export Administration Regulations (EAR) §734.7 and §734.10 — "publicly available" technology that is "already published" and "technology made publicly available at conferences, in journals, or on the internet."

This means:

1. No export licence required for base DEFONEOS code sharing between AUKUS partners (UK, US, AU)

2. No ITAR restrictions on the open-source codebase — it's public domain technology

3. Classified modifications (done by MOD) remain classified and are NOT published — but the base framework is open

4. FVEY sharing — each nation can deploy their own DEFONEOS instance with their own modifications, all derived from the same open base

Security: Open ≠ Insecure

The most secure software in the world is open source: Linux (runs the internet), OpenSSL (protects every HTTPS connection), WireGuard (VPN standard), Signal (encrypted messaging). The idea that "closed = secure" has been disproven repeatedly:

Closed-Source BreachYearImpact
SolarWinds202018,000 customers including US DoD compromised. Nobody could audit the code.
Palo Alto PAN-OS2024Zero-day in closed firewall code. Active exploitation for months.
Microsoft Exchange2021Hafnium breach. 30,000 organisations. Closed source delayed detection.

Compare to open source: Heartbleed (OpenSSL, 2014) was found, patched, and deployed in 72 hours because the entire community could inspect the code. The closed-source equivalent would have taken months to discover and fix.

DEFONEOS invites continuous security review. Every MCP server, every data pipeline, every BFT vote — it's all on GitHub. The UK security community can scrutinise it constantly.
