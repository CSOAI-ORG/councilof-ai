❓ Frequently Asked Questions

  • Is DEFONEOS cleared for OFFICIAL-SENSITIVE?
    DEFONEOS can be deployed in air-gapped environments. SC clearance is being processed for key personnel. The system architecture supports JSP 440 manual handling controls out of the box.
  • Can DEFONEOS run entirely offline?
    Yes. Full edge deployment on Jetson Orin / Raspberry Pi. All 30 MCP servers run locally. No cloud dependency. Sovereign data guaranteed.
  • What is the licensing model?
    Open source: Apache 2.0 (MCP servers) and MIT (core tools). Enterprise and Government: CSOAI Ltd commercial license with SLA, support, and compliance packaging. See Pricing.
  • How does DEFONEOS compare to Palantir?
    DEFONEOS is open source, sovereign-deployable, 30x cheaper, and purpose-built for UK defence standards (JSP 936/440). See comparison page.
  • What data sources are integrated?
    30 MCP servers covering satellite imagery (Sentinel Hub), OS open data, AIS maritime, air quality, OSINT (GDELT), IoT (MQTT), RTSP cameras, government open data, and more. See Data Architecture.
  • How is AI governance handled?
    33-node BFT (Byzantine Fault Tolerant) council with Ed25519-signed SIGIL audit chain. Every AI decision is logged, hash-chained, and verifiable. See BFT Council.
  • Can I contribute MCP servers?
    Yes! All MCP servers are open source. Fork the repo, build your sensor wrapper, submit a PR. See GitHub.
  • What's the roadmap for JSP 936 compliance?
    JSP 936 compliance generator v0.1 is built. Full mapping of DEFONEOS architecture to JSP 936 controls. See JSP 936 page.

🚨 Security Incident Response

For security incidents involving DEFONEOS deployments: all incidents are SIGIL-audited on the Ed25519 hash chain. The immutable audit trail provides full accountability. Contact CSOAI Ltd immediately for coordinated disclosure.
