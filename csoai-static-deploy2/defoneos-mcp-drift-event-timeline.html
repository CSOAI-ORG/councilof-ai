5. Recovery Action Catalogue

  1. Auto-SIGIL — emitted by cron every 2h if any window exceeded; no human action
  2. Owner-page — iMessage + email to Nick; SIGIL receipt logged in BFT minutes
  3. Witness co-cosign — if owner unavailable, 2nd witness cosigns under 30/33 constitutional amendment
  4. Recertification vote — BFT quorum revotes on SEAL eligibility (REDLINE 27/33 threshold)
  5. Emergency sunset — 17/33 emergency motion immediately downgrades MCP; SEAL burned
  6. SEAL revoke — red-line 27/33 revocation vote; MCP returned to PENDING; 180-day cool-off

6. 7 Drift-Detection Invariants

  1. Window monotonicity: Once a state advances, it cannot regress unless under CRITICAL drift
  2. SEAL permanence: SEAL_ISSUED state is terminal unless REDLINE 27/33 revokes
  3. BFT vote pre-condition: WITNESS_ROTATED must be ≤180d before BFT_VOTED
  4. Owner cosign uniqueness: Each SEAL requires exactly 1 owner cosign; no double-cosign
  5. 3-witness fingerprint: Any 2-of-3 witness disagreement blocks transition
  6. SBOM immutability: SBOM_PUBLISHED state cannot be edited; only superseded
  7. Recertification schedule: SEAL_ISSUED MCPs auto-schedule BFT recertification vote at T+365d
