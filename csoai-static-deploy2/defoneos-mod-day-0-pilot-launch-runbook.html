  • Data breach / IP leak: any OSCAL SSP, 240-test pytest evidence, or buyer contact data exposed externally. Stop all sends. Notify NCSC within 72h per UK-GDPR.
  • Negative press: any Tier-1 publication (FT, Telegraph, Wired, Register) publishes negative DEFONEOS coverage. Pause all sends. Crisis-comms review.
