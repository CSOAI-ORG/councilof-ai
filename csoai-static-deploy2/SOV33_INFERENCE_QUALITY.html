§7 Certification & replay

Reproduce locally. git clone https://github.com/csoai/meok-evals && cd meok-evals && python inference_bench.py --model sovereign-small --quant 4-bit --window 25 --output inference_bench.jsonl. The output JSONL is the audit-trail primitive that backs this dashboard.

Verify a sigil. Each SIGIL receipt is Ed25519-signed. The public key is at sovereign-charters/keys/ed25519.pub. Verify with openssl pkeyutl -verify -in <msg> -sigfile <sig> -pubin -inkey sovereign-charters/keys/ed25519.pub. Anchored to Bitcoin via OTS every 10 min.
