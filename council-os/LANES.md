# Lane etiquette — agents

**Before starting work:** announce your lane here (one line: agent · branch · files · concern).

Canon for coordination: `docs/AGENT_COORDINATION.md` (§373–374 push discipline, single-writer tip).

## Rules

- One lane = one branch = one concern. Do not touch another lane's files.
- Kill every dev server you start. `lsof -iTCP -sTCP:LISTEN` before adding another.
- Report gate failures verbatim — never summarize a red gate as "mostly passing".
- `NewHome-v3.tsx`, `AppMainRoutes.tsx`, `AppLazy.tsx` are **do-not-corrupt** — see `docs/MASTER_CONNECT.md`.
