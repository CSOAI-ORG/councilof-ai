For agent developers and platform integrators. Updated 2026-09-13.

## What x402 is

x402 is an open protocol where an HTTP server returns `HTTP 402 Payment Required` with a machine-readable challenge describing what to pay, how, and to whom. Any compliant agent wallet pays and retries the request.

Council of AI's x402 implementation: `https://councilof.ai/.well-known/x402.json`

## The 30-second version

```bash
# 1. GET a paid resource → 402 with payment challenge
curl -i https://councilof.ai/api/request-attestation?subject=USDC
# → HTTP/1.1 402 Payment Required
# → X-Payment-Address: 0x212686404A7D1E1fD88F35eD6200c3aF7A78ae31
# → X-Payment-Network: eip155:8453
# → X-Payment-Amount: 10000 (USDC, 6 decimals = $0.01)
# → X-Payment-Asset: 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913

# 2. Pay the challenge (USDC on Base)
# 3. Retry with X-Payment-Signature header
curl -H "X-Payment-Signature: <signed-payment>" \
     https://councilof.ai/api/request-attestation?subject=USDC

# → HTTP/1.1 200 OK
# → Signed receipt + paid artefact
```

## What the receipts look like

A paid request returns a JWS (EdDSA) signed by `did:web:csoai.org#board-attestation-1`, containing:
- `payer`: wallet that paid
- `amount`: in USDC micro-units
- `resource`: the URL + params you paid for
- `issued`: ISO timestamp
- `artefact_hash`: SHA-256 of the artefact content
- `inclusion_proof`: optional Merkle inclusion proof

Verify at `/api/receipts/verify` or with `scripts/verify_receipt.py`.
