## The 4 design principles

### 1. **The data is in the user's hands**

The user owns the SIGIL chain. The user owns the sovereign state. The
user owns the episodic memory. The user can export it, take it to a
different machine, switch from one sovereign-OS instance to another.
**No vendor lock-in. No silent uploads. No implicit data sharing.**

**This is the "i" in iOK Farm.**

### 2. **The sovereign runtime wraps every other AI**

The user might use ChatGPT for one task, Claude for another, a local
model for a third. The MEOK OS overlay sits in front of all of them.
Every interaction is SIGIL-signed. Every claim is verified. The sovereign
agent arbitrates between the closed-vendor AIs and the local sovereign
merge.

**This is the "OS eats all" play — but the OS is the user, not the
vendor.**

### 3. **The meok-hatch characters are the AI's view of itself**

The user doesn't see "an AI tool." The user sees **the sovereign
agent's characters** — the 12 queens + king + the BFT-33 council —
as the AI's view of itself, surfaced as immersive companions. The user
can pick which character they want to interact with. The user can see
when the BFT council is deliberating. The user can see when the sovereign
agent is in a "dream" state (REM consolidation).

**This is the "characters immersion" play — but the characters are the
AI's inner world, not theatrical mascots.**

### 4. **The Care-Floor is in the architecture, not in a policy**

The Care-Floor is enforced at the OS-overlay level. No matter which AI
the user is using underneath, the Care-Floor is the same. The sovereign
agent has a hard floor (Care-Floor 0.95) and any action that crosses it
is blocked at the overlay level. **The Care-Floor is the user's
guarantee, not the vendor's promise.**

## The honest risks

| Risk | Mitigation |
|---|---|
| Adoption is too slow (1,000 installs takes 6 months, not 6 weeks) | The Crown / DAF / DIU outreach is the anchor — community adoption is the wedge, but enterprise pilots are the funding |
| Closed-vendor AIs (ChatGPT, Claude) refuse to integrate with the MEOK OS overlay | The MEOK OS overlay sits at the OS level, not the API level — it wraps the **user's interaction with the AI**, not the AI's API. The user installs the overlay; the AI is unaware |
| Hyperscaler (Apple / Google / Microsoft) clones the MEOK OS overlay | The AGPL-3.0 licence on the substrate stops the clone-while-keep-API-closed play. The character CC-BY-4.0 + code AGPL-3.0 split stops the "rebrand the characters" play |
| Sovereign merge v0.1 fails Gate 1 (merged does not beat base) | The runbook's 2-gate structure is the protection. Stop at Gate 1 with £15 spent |
| The Care-Floor is too restrictive for the user's actual use cases | The Care-Floor is configurable per use case. The Care-Floor 0.95 is the default; the user can lower it for low-stakes contexts. **The floor is the user's choice, not the vendor's** |
| The user data export / portability is a regulatory risk (GDPR right to data portability) | This is **GDPR-compliant by construction**. The export is the SIGIL chain. The format is documented. The portability is a feature, not a risk |
