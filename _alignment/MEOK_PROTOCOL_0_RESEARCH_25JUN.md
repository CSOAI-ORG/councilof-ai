**Abstract:** Protocol 0 defines the foundational communication, identity, trust, transaction, and governance layer for autonomous software agents in decentralized networks. Modeled after the role TCP/IP played in the internet era.

| Layer | Function | Tech |
|---|---|---|
| **0. Identity** | How agents prove who they are | "Sigil" identity system, Ed25519, W3C DID |
| **1. Discovery** | How agents find each other | libp2p, decentralized DHT |
| **2. Communication** | Message formats | gRPC, Protocol Buffers |
| **3. Trust** | Cryptographic attestation | BFT, Ed25519, SIGIL chain |
| **4. Transaction** | Value exchange | x402, ACP, IBC |
| **5. Governance** | Multi-stakeholder | BFT Council, CASA framework |

**Transport-agnostic. Cryptographically secure. Incrementally adoptable. Built on W3C DIDs, libp2p, Ed25519, gRPC, BFT consensus.**
