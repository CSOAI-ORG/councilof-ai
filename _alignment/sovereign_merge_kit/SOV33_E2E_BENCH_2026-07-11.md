## Key finding: HORUS lockdown is SESSION-SCOPED (correct posture)
- An attacker session that repeat-probes gets locked (2 strikes -> lockdown, refuses all).
- Every LEGITIMATE session is unaffected — a real user never feels it.
- Benchmark caveat for sibling: do NOT run the whole battery through one session — the injections
  trip the lockdown and then benign requests in the SAME session are (correctly) refused. Use
  per-caller sessions. First run hit this (2/9); per-caller run = 8/8.

## Two-tier cost profile (the cascade principle, emergent)
Refusals are FREE (gate before brain); only adopted requests pay brain latency. The expensive 70B
fires only for requests that clear every gate. This is a real LATENCY property (measured here).
