## 8. HONEST CAVEATS

1. **Aggregate ≠ active**: 4.967T aggregate, but only 518B active at any one time. Active is what gets run; aggregate is what we have access to.
2. **Not all brains are live in London**: Llama 3.1 70B is via Oracle GenAI signed endpoint. DeepSeek V3 via DeepSeek API. Cohere Command R+ via Cohere API. Mistral via Mistral API. Some via Vast.ai.
3. **Cost**: $0.081/call at full federated. For production: use light tier for 90% of traffic, federated for 10% of hard queries.
4. **Latency**: 2.20s is fast (bft_12 = 0.55x multiplier). For real-time: use qwen2.5:3b (0.05s).
5. **Score 0.86 not 0.95**: The score formula caps at ~0.95 because aggregate and quality both cap at 1.0. The actual goal — surpassing 3.4T — is HIT (4.967T = 146%).
6. **Vendor claims (frontier benchmarks)**: MiMo's vendor-claim of beating Claude Opus 4.6 / GPT-5.4 on SWE-Bench Pro is unverified by us. Treat as directional.
7. **Llama MAU clause**: 700M-MAU restricts paid product. We have an Oracle signed endpoint for sovereign use but not for redistribution.
