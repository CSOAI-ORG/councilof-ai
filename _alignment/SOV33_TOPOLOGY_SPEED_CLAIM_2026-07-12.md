# SOV33 topology → the honest "better + faster than ungoverned AI" claim (2026-07-12)
_Locks what 3-around-1 / 12-around-1 / stage-specialists can HONESTLY claim. The claim is "true improve existing",
NOT "beat the frontier". That claim is real, measurable, and survives scrutiny._

## THE CLAIM (defensible)
SOV33 makes EXISTING open models better than running one ungoverned model, on 3 measurable axes:
- FASTER/CHEAPER: small models (reflex tier) handle most work; large model fires only on escalation → lower
  cost-per-correct-answer + lower latency than always-run-big.
- MORE CONSISTENT: cross-lineage BFT vote catches errors a single model makes alone (measured ρ decorrelation).
- AUDITABLE: every step SIGIL-signed → reproducible trail no single-model API gives you.
CEILING (hard line): "better than an UNGOVERNED single model of comparable size" — provable. NOT "better than
GPT-5/Claude" (unwinnable, falsifiable). "True improve existing" = the exact honest frame.

## 3-AROUND-1 (2 small + 1 large + SIGIL) — REAL
Reflex 2 small draft fast; escalate hard cases to the large; 3-way cross-lineage vote; SIGIL signs. Most tasks
exit cheap. Better+faster than one ungoverned model of the same size. This is the shippable topology.

## 12-AROUND-1 (planner → 12 executors) — REAL as THROUGHPUT
Large model PLANS/decomposes → 12 small workers execute subtasks in PARALLEL (= years→days fan-out). Speeds up
DECOMPOSABLE work (many things at once). HONEST caveat: raises THROUGHPUT, does NOT make a single answer smarter.

## "EACH OF 12 IS A PDCA STAGE, EACH AN MoE/MoM" — HALF-REAL
GOOD: map the 12 to PDCA/9-stage ROLES (each stage a specialist function) — clean architecture.
TRAP: "each is an MoE/MoM" only if those specialists EXIST as separate tuned models. Today they're PROMPT/ENSEMBLE
configs over shared bases, NOT 12 distinct MoE models. Claiming "12 MoEs" = the T-params category error again.
HONEST: 12 specialist ROLES routed to whichever model fits (some MoE, some small, REUSED) — not 12 owned giants.

## THE ALL-REAL SYNTHESIS
Large planner + fan-out of small specialist workers, each mapped to a PDCA stage, BFT cross-checked, SIGIL-signed
→ work done FASTER + MORE CONSISTENTLY than a single ungoverned model. That IS "true improve existing". Ship that.
