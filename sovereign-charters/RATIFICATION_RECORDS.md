## 6. ED25519 SIGNATURE VERIFICATION

Each BFT agent signs their vote with an **Ed25519 digital signature**. The `SIGIL Digest of Vote` recorded in the ratification table is the SHA256 hash of the entire vote payload (charter ID, agent ID, vote choice, timestamp). This hash is then signed by the agent's private Ed25519 key.

### 6.1 Verification Workflow (for external auditors)

1. Retrieve the `SIGIL Digest of Vote` from the table above.
2. Retrieve the `Ed25519 Public Key` for the relevant Agent ID (available at `https://csoai.org/bft-council/agents`).
3. Retrieve the full **signed SIGIL line** from `https://csoai.org/sigil-explorer/digest/<SIGIL_Digest_of_Vote>`.
4. Use standard Ed25519 libraries (e.g., `PyNaCl`, `libsodium`) to verify the signature against the digest and the agent's public key.

Example (Python pseudocode):
```python
import nacl.signing
import hashlib

public_key_hex = "..."
message_digest_hex = "..." # This is the SIGIL Digest of Vote
signature_hex = "..." # From the SIGIL line

# Convert hex to bytes
public_key_bytes = bytes.fromhex(public_key_hex)
message_digest_bytes = bytes.fromhex(message_digest_hex)
signature_bytes = bytes.fromhex(signature_hex)

# Create a verifying key object
verify_key = nacl.signing.VerifyKey(public_key_bytes)

# Verify the signature
try:
    verify_key.verify(message_digest_bytes, signature_bytes)
    print("Signature is VALID")
except nacl.exceptions.BadSignatureError:
    print("Signature is INVALID")
```

This robust cryptographic framework ensures that no vote can be spoofed or tampered with without detection. The entire chain of custody, from agent vote to Bitcoin anchor, is auditable.
