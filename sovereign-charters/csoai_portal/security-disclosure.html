📋 Disclosure Format

Required information in every report:

1. Vulnerability Summary (1-2 paragraphs)
2. Affected Systems + Versions
3. Reproduction Steps (with screenshots)
4. Attack Vector (external/internal/physical)
5. Discovery Method
6. Suggested Mitigation
7. Your Contact Info + Sovereign Citizen DID
8. Care Score Attestation
9. Disclosure Preference (coordinated / public / silent)
