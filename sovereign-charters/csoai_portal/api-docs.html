🔐 Authentication Examples

1. Ed25519 signing (Python)

# In python
import nacl.signing
import hashlib

signing_key = nacl.signing.SigningKey.generate()
verify_key = signing_key.verify_key.encode().hex()

# Sign the request
body = json.dumps({...}).encode()
timestamp = '2026-07-02T10:00:00Z'
message = timestamp.encode() + b'POST' + b'/v1/report' + hashlib.sha256(body).digest()
signature = signing_key.sign(message).hex()

# In curl
curl -X POST https://api.csoai.org/v1/report \
  -H "X-Partner-DID: did:csoai:..." \
  -H "X-Signature: ed25519:${signature}" \
  -H "X-Timestamp: ${timestamp}" \
  -d '${body}'

📊 Error Codes

  • 200 OK — Success
  • 400 Bad Request — Invalid input (missing required field)
  • 401 Unauthorized — Missing/invalid signature or token
  • 403 Forbidden — Insufficient permissions (e.g. non-BFT agent trying /sigil/emit)
  • 404 Not Found — Charter / framework / partner not found
  • 429 Too Many Requests — Rate limit exceeded
  • 500 Internal Server Error — Server error (SOV3 substrate may be down)
  • 503 Service Unavailable — OTS Bitcoin temporarily down
