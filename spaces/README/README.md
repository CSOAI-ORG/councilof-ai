# Council of AI

**Council for the Safety of Artificial Intelligence** · Operated by CSOAI Ltd

We publish scoped AI measurements with their methods, evidence and limitations. GSPC is our public measurement board. A measured result applies to a particular question, system and method; it is not certification, accreditation or permission to execute.

## Read the results accurately

- **MEASURED** means evidence is available for that axis. It does not mean a model won.
- **TIE** means the published comparison did not establish a separated lead. **UNTESTED** means separation was not established by a test.
- **UNMEASURED** is an explicit coverage gap. Missing information is never a zero.
- Model comparisons and deterministic source facts answer different questions; do not pool them into one accuracy score.
- A valid signature establishes integrity, not admission or suitability. Check a card's intake receipt, withdrawal status, scope and limitations before quoting it.

Current counts and dates come from the [live board JSON](https://councilof.ai/api/gspc). Dataset releases are dated snapshots; a page refresh is not a new evaluation.

## Build with the evidence

Use the [public API description](https://councilof.ai/openapi.json), [MCP endpoint](https://councilof.ai/mcp) or [source repository](https://github.com/CSOAI-ORG/councilof-ai). For reproducible research, pin a dataset revision and retain its `SNAPSHOT.json`, source hashes and method references.

Board data is **CC-BY-4.0**: attribute Council of AI / CSOAI Ltd. Other datasets and third-party material retain their stated licences. Use the [corrections register](https://councilof.ai/corrections/) when checking whether a result is still quotable.
