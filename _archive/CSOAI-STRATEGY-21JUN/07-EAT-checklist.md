- [ ] Add "Council of Experts" page with named advisors, credentials, LinkedIn links
- [ ] Publish 3 technical white papers:
  - [ ] `did:csoai` method specification
  - [ ] BFT council architecture and security model
  - [ ] PDCA runtime policy engine design
- [ ] Add methodology docs to every compliance page (how controls map to frameworks)
- [ ] Contribute to open standards: W3C DID, IETF AIP, AGNTCY, x402 Foundation
- [ ] Maintain 475+ repos with clear READMEs, examples, and responsive issues
- [ ] Launch CSOAI analyst certification (CASA)
