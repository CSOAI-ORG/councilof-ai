# CSOAI Strategic Plan — Absorb the Ecosystem

## Winning position

> **CSOAI is the independent, sovereign, protocol-native trust and compliance layer for the agentic economy.**

Competitors sell dashboards. CSOAI sells the Layer 0 runtime substrate that binds agent identity, compliance, and audit across MCP, A2A, AP2, and x402.

## Core USPs

1. **Independent standards body** — UK-registered, no Big Tech ownership.
2. **Cryptographic proof** — Ed25519 Watchdog certificates, public verify URLs.
3. **Protocol-native governance** — MCP/A2A/AP2/x402 enforcement at agent-call latency.
4. **Sovereign identity** — `did:csoai` + W3C DID alignment.
5. **Open-source moat** — 475 repos, MIT-licensed MCP servers.
6. **Cross-regulatory engine** — 13-framework crosswalk (EU AI Act, NIST, ISO 42001, GDPR, DORA, NIS2, etc.).
7. **Vertical API wedge** — EU-regulated verticals (waste, plant hire, taxi, aquaculture, trading).

## Two go-to-market plays

### Play A: "Switch to CSOAI" — competitor transfer buttons

Create a `/switch` page listing every major incumbent. For each:

- What you lose by staying
- What you gain by switching
- One-click import / evidence bridge (Vanta → CSOAI, Drata → CSOAI, etc.)
- Pricing comparison
- Migration checklist
- CTA: "Start transfer"

Target: Vanta, Drata, Secureframe, Thoropass, OneTrust, Credo AI, Holistic AI, IBM watsonx.governance, ServiceNow, AWS Audit Manager, Microsoft Purview.

### Play B: "Absorb them into Layer 0" — the CSOAI OS

Do not replace competitors. Make them components of the CSOAI OS:

- **Vanta/Drata** → evidence source
- **OneTrust** → AI BOM catalog
- **Holistic AI** → model-test evidence
- **IBM/Azure/AWS** → compute substrate
- **MCP registries** → verified server marketplace
- **x402/AP2** → payment rails wrapped with compliance pre-checks
- **Regulators / notified bodies** → attestation acceptance network

Frame as: *"They are apps. CSOAI is the operating system."*

Visual language: OpenGridWorks-style node graph showing every competitor and authority body as a node that plugs into the CSOAI Layer 0 kernel.
