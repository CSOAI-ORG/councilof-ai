## Part 2: Absorb narrative (`/os`)

### Hero

> "They are apps. CSOAI is the operating system."

### Visual

OpenGridWorks-style node graph:
- Centre: CSOAI Layer 0 kernel (identity, attestation, policy, audit, BFT council)
- Orbiting nodes: Vanta, Drata, OneTrust, IBM, Azure, AWS, Google, x402, AP2, MCP registries, regulators, notified bodies, legislators, vertical AI hives
- Edges labelled: "evidence in", "policy out", "verify", "attest", "settle"

### Sections

1. **Identity bus** — every agent, user, and system gets a `did:csoai`.
2. **Attestation bus** — every compliance event becomes a signed, public-verify receipt.
3. **Policy bus** — PDCA runtime enforces rules across all connected apps.
4. **Payment bus** — x402/AP2/ACP flows pre-checked for compliance.
5. **Audit bus** — immutable, regulator-checkable logs.
6. **Council bus** — BFT multi-stakeholder governance overrides.

### Authority absorption

- Regulators: public verify dashboards + API
- Notified bodies: joint conformity packages
- Legislators: sandbox participation + policy white papers
- Standard bodies: liaison status + contributed schemas
