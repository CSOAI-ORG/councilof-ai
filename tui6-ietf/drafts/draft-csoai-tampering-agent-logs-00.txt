                "Tampering Risks in AI Agent Logs"
              draft-csoai-tampering-agent-logs-00

Abstract

   This document examines tampering risks in AI agent log systems and
   proposes cryptographic mitigations.

1.  Introduction

   AI agents log tool invocations, payment transactions, and evidence
   deliveries.  These logs are critical audit evidence.

2.  Tampering Risk Categories

   2.1.  Log Deletion or Modification
   2.2.  Receipt Replay Attacks
   2.3.  Merkle Tree Manipulation
   2.4.  Timestamp Manipulation

3.  Proposed Mitigations

   Append-only chains, external transparency-log witnessing, multi-key
   signing, and client-side receipt retention.

4.  Security Considerations

   No single mitigation eliminates all tampering risks.
