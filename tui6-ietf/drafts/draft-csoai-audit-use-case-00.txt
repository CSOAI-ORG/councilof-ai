     "Cryptographic Receipts for AI Governance Audit Trails"
                   draft-csoai-audit-use-case-00

Abstract

   This document describes the use of cryptographic measurement receipts
   and Ed25519-signed evidence cards for AI governance audit trails.

1.  Introduction

   Organizations deploying AI systems need auditable evidence of model
   behaviour across governance axes including safety, transparency,
   fairness, and regulatory compliance.

2.  Measurement Card Format

   Each measurement card contains a subject identifier, axis, accuracy
   with Wilson 95 percent confidence interval, sample size, run
   identifier, and harness version.

3.  Verification Pipeline

   Cards are verified via Ed25519 signature, Merkle root inclusion,
   and transparency log witness (Sigstore Rekor).

4.  Current Deployment

   The CSOAI infrastructure at councilof.ai serves 22 GSPC axes,
   155 models measured, 1,493 signed cards, and 425 stablecoins
   indexed across 211 chains.

5.  Security Considerations

   Private signing keys are never placed in source code or artifacts.
