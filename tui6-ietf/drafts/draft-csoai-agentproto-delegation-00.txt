1.  Introduction

   This document describes CSOAI's measurement and evidence
   infrastructure as it relates to the IETF community.  CSOAI Ltd (UK
   Companies House 16939677) maintains signed measurement cards for AI
   governance evidence at councilof.ai.

2.  Evidence Model

   Each measurement card contains a subject identifier, axis, accuracy
   with Wilson 95 percent confidence interval, sample size, run
   identifier, harness and grader version, and cryptographic signature
   (Ed25519 with DID-bound keys).

3.  Verification

   Cards are verified via Ed25519 signature, Merkle root inclusion, and
   Rekor transparency-log witness.  The root is published at
   https://councilof.ai/root.json with per-card SHA-256 leaves and
   inclusion proofs available via /api/proof.

4.  Security Considerations

   Private signing keys are never placed in source code, artifacts,
   logs, or browser storage.  The signing ceremony uses GitHub OIDC with
   off-device key custody per did:web:csoai.org.  Failures fail closed
   and preserve UNCHECKABLE rather than substituting defaults.
