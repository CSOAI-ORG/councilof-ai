Layer 0: Identity — “The Sigil”
Every agent has a Sigil — a cryptographic identity derived from an Ed25519 key pair.
Sigil Format: did:sigil:<base58-encoded-public-key>

Example: did:sigil:z6MkhaXg...7Qz

Components:
├── Public Key: Ed25519 (32 bytes)
├── DID Document: Contains services, keys, endpoints
├── PeerID: libp2p-compatible hash of public key
└── Certificate: Optional X.509 bridge for legacy systems
Features: - Self-certifying (no central authority needed) - Quantum-safe upgrade path (ML-DSA-65 hybrid) - Key rotation with social recovery - Revocation lists for compromised agents
