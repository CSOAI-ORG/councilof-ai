## Behaviour and boundaries

The displayed lesson revision and case digest bind feedback. Stale material, invalid context, unknown cases, extra role/identity/report fields, malformed/oversized JSON and duplicate keys are rejected. Educational XP is recomputed per distinct case in a submitted history; the UI grades one attempt at a time and does not accumulate rank. It is not a persistent anti-fraud system or proof a human learned anything.

A correct practice answer never implies named human identity, presence, competence, appointment, execution approval, model-training permission, SAFE submission, settlement or GSPC admission. These states are separately explicit. The lesson's human-review step remains an unsent request until an accepted authenticated receiver exists. No confidential incident content is accepted by these tools.

`learning_tools.py` reuses the existing `research_lab.record_call` and canonical `csoai.evidence-event/0.1` builder. Responses bind implementation/asset digests and input/output hashes, remain unsigned/PARTIAL and are not durably archived. That contract records the function execution, not human learning, correctness of underlying evidence or an independently observed effect.
