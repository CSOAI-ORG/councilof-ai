Use case 1: Healthcare · Templeman lineage domiciliary eye care

BFT deliberation: 22-of-33 votes. The Article 14 (4-eyes optometrist review) is enforced. The Article 50(2) C2PA marking flags AI-generated clinical content (e.g. AI summary of notes).

SIGIL chain: every visit is signed. The audit trail is verifiable in any browser.

The pattern

Every use case follows the same sovereign Maps pattern:

  1. Sovereign consent: the citizen grants GDPR Article 6(1)(a) consent (specific, informed, freely revocable).
  2. Maps API call: the substrate calls the Maps API server-side (key in keystone).
  3. OSCAL stamp: the response is stamped with the 14-component OSCAL proof.
  4. BFT deliberation: 22-of-33 votes. Hermes external voice holds right-of-veto on lethal decisions.
  5. Article 14 (4-eyes): high-risk decisions require human review.
  6. Care Floor 0.95: the substrate respects citizen privacy (Article 9) + geolocation precision (no PII leak by default).
  7. SIGIL-signed: every action is signed Ed25519 + PQC ML-DSA-65.
