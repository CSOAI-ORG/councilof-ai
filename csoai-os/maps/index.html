How to deploy (when the owner is ready)

Step 1: Get a Google Maps API key

Visit console.cloud.google.com and create a new Maps API key. Apply these restrictions:

  • Application restrictions: HTTP referrers — your domain only (e.g. csoai.org/*)
  • API restrictions: only the 5 Maps APIs above (Maps JavaScript + Geocoding + Places + Distance Matrix + Elevation)

Step 2: Store the key in keystone

# Copy the key to your clipboard, then: $ pbpaste | keystone set GOOGLE_MAPS_API_KEY # Stored in GCP Secret Manager + macOS Keychain. Never in source.

Step 3: Deploy the sovereign proxy

$ keystone run GOOGLE_MAPS_API_KEY -- \\ uvicorn sovereign_maps_proxy:app --host 0.0.0.0 --port 8042 # Key injected as env var; never appears in process listing.

Step 4: Embed the widget on any page

<script src="https://csoai.org/csoai-os/maps/embed.js" data-lat="51.5074" data-lon="-0.1278" data-zoom="12"> </script>

What this gives you

  • No PII leak — the API key never appears in the browser. The browser never sees it.
  • OSCAL-stamped — every Maps response is stamped with 14 components (provenance + integrity).
  • BFT-deliberated — every Maps call is voted on by 22-of-33 sovereign agents (2.0s cycle).
  • Care Floor 0.95 — geolocation precision respects citizen privacy (default 100m, sub-10m never revealed).
  • Article 14 (4-eyes) — high-risk geolocation decisions (police, immigration, defence) require 4-eyes human review.
  • Article 50(2) C2PA — AI-generated maps content is C2PA-signed for detectability.
  • GDPR Article 9 — health, biometric, ethnic-origin data gets elevated SIGIL logging.
