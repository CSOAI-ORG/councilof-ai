🔍 Pillar 2: DISCOVER

Passively discover signals within a radius. Combines 4 sensor layers: noise + frequency + vibration + presence.

Try the discover API: 
GET https://api.csoai.org/watchdog/v1/discover?lat=51.5074&lon=-0.1278&radius_m=1000
→ {
  "query": {"lat": 51.5074, "lon": -0.1278, "radius_m": 1000},
  "noise": [...],
  "frequency": [...],
  "vibration": [...],
  "presence": [...],
  "ambient_score": 0.296,
  "classification": "moderate"  // "quiet" | "moderate" | "busy" | "chaotic"
}

🗺️ Pillar 3: SIMULATE

Simulate a pre-route before moving. Returns route + outcome predictions + risk scores. Live re-routing every 30s while moving.

Try the simulate-route API: 
POST https://api.csoai.org/watchdog/v1/simulate-route
Content-Type: application/json

{
  "start": {"lat": 51.5074, "lon": -0.1278},
  "end": {"lat": 51.5174, "lon": -0.1378},
  "mode": "humanoid",  // or "walking" | "driving" | "cycling"
  "avoid": ["high_noise", "anomaly_zones", "high_vibration"]
}
→ {
  "route": [...10 waypoints...],
  "outcome_predictions": [...10 predictions with risk scores...],
  "heat_map_layer": "predicted_risk",
  "ws_url": "ws://api.csoai.org/ws/v1/simulate-route/{route_id}"
}
