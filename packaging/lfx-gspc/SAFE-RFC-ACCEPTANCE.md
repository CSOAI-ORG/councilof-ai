# SAFE RFC acceptance map for this candidate

The [SAFE proposal](https://github.com/OpenSecureAIAlliance/RFCs/blob/main/rfc-safe-proposal.md) asks for reproducible verification, retained evidence, and a versioned defensive-control catalog. This file maps the existing candidate to those requests. It does not claim that SAFE accepted the package.

| Public discussion | Candidate response | Evidence today | Remaining gate |
| --- | --- | --- | --- |
| [#4: method failure and noise floor](https://github.com/OpenSecureAIAlliance/RFCs/issues/4) | OpenBMC origin/redirect and status-state controls have explicit positive and negative tests. A transport or format failure cannot become a measured result. | Nine unit tests, including malformed base and redirect rejection. The collector's exact-byte digest is deterministic for a retained response. | Run against a consenting BMC; record response-change/timing behavior if any stochastic detector is added. Do not infer a noise floor from these unit tests. |
| [#5: evidence representation](https://github.com/OpenSecureAIAlliance/RFCs/issues/5) | Retain the Redfish source URL, GET method, observation time, response digest, selected non-secret fields and result state. Use the existing CSOAI SAFE crosswalk; do not invent a SAFE telemetry namespace. | `measurement/crosswalk/sources/osaia-safe.json` is included by digest. | Export one real tool-call trace using the current OpenTelemetry GenAI conventions and verify its join to the retained receipt without exposing raw BMC payloads or credentials. |
| [#6: pre-connection tool trust](https://github.com/OpenSecureAIAlliance/RFCs/issues/6) | A least-privilege OpenShell policy lists 12 allowed read-only CSOAI MCP tools and four denied paid tools. | Live MCP `tools/list` and free `board_totals` succeeded on 28 September; the policy was accepted by the v0.1.1 gateway in the earlier qualification. | Prove allowed and denied calls in a current sandbox, capturing policy hash and structured allow/deny events. Tool discovery alone is not enforcement or attestation. |

**Admission rule:** source observation, policy decision, GSPC measurement, signing, anchoring and publication are separate events. A missing or failed gate stays UNCHECKABLE/UNMEASURED; this package does not generate a public GSPC score. Confidential SAFE incidents remain outside the public package.
