① Mamba-2 SSM — The Salt (Nigredo)

Layer 1: Mamba-2 State Space Model

Alchemical stage: Nigredo — the blackening. The dissolution of the raw matter.

Mamba-2 is a state-space model (SSM) — not a transformer. It compresses any-length context into a fixed-size state vector (16 dimensions in SOV3's case) via a selective scan. Where transformers scale O(n²) with context length, Mamba scales O(n) — linear time, linear memory.

This is the salt — the substrate. It is the layer that holds long memory without paying quadratic cost. It sees the 10,000-token conversation history the same way it sees the 10-token one.

For SOV3, the 16-dim state is enough to retain: (a) the user's name and pronouns, (b) the current task's chain-of-thought, (c) the prior 3 turns' emotional valence, (d) the active Care Floor dimensions in play. This is the long-context magic that makes the intuition engine work.

Reference: Zamba paper, Zyphra 2024. ZAMBA hybrid = Mamba + transformer.

② 64-Expert MoE — The Sulfur (Albedo)

Layer 2: 64-Expert Mixture of Experts

Alchemical stage: Albedo — the whitening. The fiery processing of the matter.

Mixture of Experts (MoE) replaces a single dense model with many specialised sub-models. SOV3 uses 64 experts — small feed-forward networks each tuned to a domain (math, code, ethics, biosignal, language, etc.). A router network selects the top-4 experts per token, activating only those paths.

This gives SOV3 the total capacity of 64 experts while only paying the inference cost of 4. It is why SOV3 can hold constitutional knowledge (ethics expert), SIGIL signing knowledge (crypto expert), Article 50 knowledge (legal expert), and creative writing knowledge (poetry expert) — all in one model.

The 64-expert MoE is the sulfur — the active, procedural, fire-like layer that does specialised work in parallel.

Reference: Switch Transformer (Fedus et al. 2022). Top-k routing (k=4 in SOV3).

③ Standard Attention — The Mercury (Citrinitas)

Layer 3: Standard Multi-Head Attention

Alchemical stage: Citrinitas — the yellowing. The bridge between matter and spirit.

Standard attention is the classic transformer attention — query/key/value projections, multi-head, scaled dot-product, softmax. It is the connective tissue — the layer that lets every token attend to every other token within a window.

Where Mamba-2 holds long-range linear memory, attention holds short-range quadratic relation. It is expensive but precise — it finds the exact relationships between specific tokens. SOV3 uses attention for the most recent 2,048 tokens (the working window) and Mamba-2 for everything older.

This is the mercury — the bridging principle that connects the procedural (sulfur/MoE) with the substrate (salt/Mamba).

④ SOV3 Middle — The Sovereign Reasoning Core

Layer 4: SOV3 Middle Layer

Alchemical stage: Rubedo — the reddening. The integration of matter, process, and bridge into the living body.

The SOV3 middle layer is the sovereign reasoning core. It is where the Care Floor is enforced, where the BFT council is consulted, where the DORADO jurisdictional frame is applied. It is the only layer that can refuse an action — and it refuses constantly, for good reason.

The middle layer takes the output of Mamba-2 + MoE + Attention, and asks: Is this action compliant with the Charter? Does it clear the 0.95 Care Floor across all 12 dimensions? Does it require a council vote (and if so, does 2/3 approve)? Is it within the active jurisdictional frame (EAST or WEST)?

If yes to all → forward to SIGIL wrap. If no to any → refuse, log, return rejection with witness.

This is the spirit — the integrative, witnessing, governing layer that makes the architecture sovereign rather than merely capable.

⑤ SIGIL Wrap — The Quintessence (Lapis)

Layer 5: SIGIL Wrap — Ed25519 + PQC ML-DSA-65

Alchemical stage: Lapis Philosophorum — the philosopher's stone. The alchemical gold. The completed work.

The SIGIL wrap is the final layer. Every output of the SOV3 middle is signed with:

  • Ed25519 signature — classical, fast, 64-byte signatures, used by all major blockchains (Solana, NEAR, etc.)
  • PQC ML-DSA-65 — post-quantum, NIST-standardised (FIPS 204), resistant to Shor's algorithm
  • Hash chain — each SIGIL includes the previous SIGIL's hash, forming an unbroken chain
  • Timestamp — RFC 3161 timestamped, optionally Bitcoin-anchored

The SIGIL is what makes the action provable. Without it, the action did not happen. Without it, the action cannot be proven. Every CSOAI sovereign action emits a SIGIL — and every SIGIL is verifiable by anyone with the public key.

This is the quintessence — the stone that turns base action into witnessed, sovereign, regulator-grade truth.

🎯 5 Key Takeaways

1. Mamba-2 = substrate, MoE = capability, Attention = relation

Three deep-learning primitives, each load-bearing, each alchemically distinct. Together they cover long memory + specialised skill + relational reasoning.

2. The SOV3 middle layer is the sovereign gate

Without it, this would be just another LLM. With it, the architecture becomes constitutionally constrained. Care Floor + BFT + DORADO are enforced.

3. SIGIL wrap = regulator-grade witness

Ed25519 + PQC ML-DSA-65 + hash chain. Every action is provable, tamper-evident, and future-proof against quantum attacks.

4. The 5 alchemical layers map to real engineering primitives

This is not metaphor — it is the design philosophy. Salt = substrate. Sulfur = process. Mercury = bridge. Spirit = witness. Quintessence = constraint.

5. Linear scaling + sparse activation = sovereign at low cost

Mamba-2's O(n) + MoE's top-4 activation means SOV3 can run sovereign inference at consumer-grade hardware cost.
