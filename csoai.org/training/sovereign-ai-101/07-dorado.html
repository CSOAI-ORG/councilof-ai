🌐 What is DORADO?

DORADO (Decentralised Operational Realm for Authorised Data Orchestration) is the sovereign jurisdictional layer of the SOV3 system. It is the substrate that lets a sovereign AI deployment switch its legal/governance frame in a single click — without changing the model, the data, or the substrate.

DORADO is named after the dorado fish — a species that traverses multiple oceanic realms. Like the fish, a sovereign AI deployment can move between jurisdictional realms while remaining the same identity, the same audit trail, the same chain of SIGILs.

DORADO has two operating modes — EAST and WEST. Each mode corresponds to a different jurisdictional frame, a different regulatory alignment, and a different set of operational defaults. The citizen or operator chooses; the switch is one click.

🟦 EAST Mode

🟦 EAST — Five Eyes / AUKUS / Commonwealth Realms

  • Primary jurisdictions: UK, US, AU, CA, NZ (Five Eyes)
  • Secondary: AUKUS partners (UK, US, AU), Crown Dependencies, Commonwealth Realms
  • Default governance: UK GDPR / DPA 2018 / EU AI Act (UK retained) / ISO 42001 / NIST AI RMF
  • Default audit: SIGIL chain + UK ICO + EU AI Office + NIST conformance
  • Default crypto: Ed25519 + PQC ML-DSA-65 + ML-KEM-768 (Kyber)
  • Default hosting: UK + EU sovereign regions (Frankfurt, Dublin, London)
  • Article 50 mode: Full passport issuance + Annex IV technical documentation
  • Best for: UK / EU / Five Eyes governments, defence, financial services, regulated industries

🟨 WEST — BRICS / ASEAN / Commonwealth Nations

  • Primary jurisdictions: BRICS+ (BR, RU, IN, CN, ZA, EG, ET, IR, AE, SA), ASEAN, SCO
  • Secondary: Commonwealth Nations (non-Realm), Non-Aligned Movement, Global South
  • Default governance: National AI policies + BRICS AI declaration + China GenAI rules + India DPDP Act 2023
  • Default audit: SIGIL chain + national regulators + cross-border data flow agreements
  • Default crypto: Ed25519 + PQC ML-DSA-65 + SM2/SM3 (China), GOST R 34.10 (Russia)
  • Default hosting: National sovereign regions (São Paulo, Mumbai, Beijing, Singapore, Cape Town)
  • Article 50 mode: EU compliance when EU-deployed; national frameworks elsewhere
  • Best for: BRICS+ governments, ASEAN enterprises, Global South deployments, sovereign wealth funds

The EAST↔WEST split is not a value judgment. It is a recognition that the world is multi-jurisdictional, and that sovereign AI must serve each jurisdiction's constitutional frame. The split allows the same SOV3 substrate to operate legally in either regime — without operator-level changes.

🖱️ 1-Click Switch

⚡ THE 1-CLICK DORADO SWITCH
sov-cli dorado switch --region WEST
→ Sovereignty switched. All subsequent SIGILs will be anchored to the WEST jurisdictional frame. The substrate, model, weights, and audit chain remain unchanged. The switch is itself witnessed by a SIGIL.

The 1-click switch is more than a config change. It is a constitutional moment — and like all constitutional moments, it is witnessed. The switch itself emits a SIGIL with: timestamp, prior region, new region, operator identity, and confirmation that the Care Floor and BFT council are still operating correctly.

🎯 5 Key Takeaways

1. DORADO = jurisdictional frame, not model change

The same SOV3 substrate. The same weights. The same SIGIL chain. Only the legal/governance frame changes.

2. EAST = UK / Five Eyes / AUKUS / Commonwealth Realms

GDPR / EU AI Act / NIST AI RMF alignment. Best for EU/UK/Five Eyes regulated industries.

3. WEST = BRICS / ASEAN / Commonwealth Nations

National AI policies / BRICS AI declaration / China GenAI rules. Best for Global South, BRICS+, ASEAN.

4. 1-click switch is itself a witnessed constitutional act

The switch emits a SIGIL. The Care Floor + BFT keep operating. The audit chain remains unbroken.

5. Sovereignty is reversible

The citizen can switch back. The citizen can audit. The citizen can revoke. This is the difference between sovereignty and captivity.

1. Which jurisdictions does DORADO EAST mode primarily cover?

✓ Answer: B. Five Eyes (UK, US, AU, CA, NZ) plus AUKUS partners (UK, US, AU) and Crown Dependencies / Commonwealth Realms.

2. What stays unchanged when you switch DORADO EAST↔WEST?

✓ Answer: A. The model, weights, substrate, SIGIL chain, Care Floor (0.95), and BFT council (12-around-1) are all unchanged. Only the jurisdictional frame changes.

3. What is the command for the 1-click DORADO switch?

✓ Answer: B. sov-cli dorado switch --region WEST. The canonical command. The switch emits a SIGIL with prior/new region + operator identity.
