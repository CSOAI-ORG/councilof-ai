How do I install SOV3?

Q: How do I install SOV3 small3 (the compressed OS)?
A: Run this one command on any Mac or Linux with Ollama installed: 
curl -sSL https://sov3.csoai.org/install.sh | bash
Installs 4 sovereign models (qwen3:1.7b-edge, llama3.2:3b, gemma3:4b, meok-sov3:latest) totaling ~7.8 GB. Optional flags:
