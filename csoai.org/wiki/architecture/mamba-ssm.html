Mamba SSM

State-space sequence model — linear time, infinite context, sovereign memory.

sovereign.wiki CSOAI Ltd UK 16939677 4 Jul 2026

Definition

Mamba is a selective state-space model (SSM) introduced by Albert Gu and Tri Dao in December 2023. It achieves Transformer-quality language modelling with linear-time complexity and a constant-size recurrent state, making it ideal for sovereign AI where long memory and predictable compute matter.

Why SSM, Why Not Transformer?

Standard Transformers (see Standard Attention) have O(n²) complexity in sequence length — doubling the context quadruples the FLOPs. For sovereign memory (e.g., 100K SIGIL events, 1M audit log lines), this is prohibitive. Mamba compresses any-length context into a fixed-size state vector (16 dimensions in CSOAI's deployment), enabling O(1) memory and O(n) compute.

Mathematical Sketch

h_{t+1} = A * h_t + B * x_t
y_t = C * h_t

where h is the hidden state, x is the input, and A, B, C are learned matrices. The selective variant makes B, C, and Δ input-dependent, enabling the model to remember or forget as content warrants.

Role in OOWM

In the OOWM Sandwich (see OOWM Sandwich), Mamba-2 is the long-context layer. It receives every SIGIL emission (1 Hz cadence) and maintains a 16-dimensional state vector that summarises the agent ecosystem. This state vector drives the Intuition Engine.

Sovereign Alignment

Mamba is well-suited to sovereignty for three reasons: (1) the constant-state enables local-only inference (no need to ship context to a remote server), (2) the linear compute makes cost predictable (no surprise bills), and (3) the architecture is open-source (Apache 2.0), so the weights are auditable.

Historical Context

SSMs date to the 1970s (Kalman filters) but were eclipsed by RNNs (1990s) and Transformers (2017). Mamba's 2023 breakthrough — making the SSM selective — restored SSMs to the frontier. CSOAI deployed Mamba-2 in production by Q1 2025; by Q2 2026 it had been adapted to the sovereign use case via the 16-dim Intuition Engine.

Modern Usage

CSOAI customers use Mamba-2 in two ways: (1) as the long-memory component of OOWM (default), and (2) as a standalone embedding model for SIGIL chain analysis (the sov_zamba_ingest tool). The SIGLIL Verify Demo demonstrates Mamba's pattern-matching on a 100K-event SIGIL transcript.
