Intuition Engine

Mamba-2 16-dim state → pattern → wisdom → hunch. SOV3 doesn't answer; SOV3 feels.

Definition

The Intuition Engine is CSOAI's novel perceptual layer: a Mamba-2 state-space model with a 16-dimensional hidden state that ingests every SIGIL event at 1 Hz and detects when the current state matches historical patterns of concern. When 3+ matching states occur within a window, the engine emits an intuition — a SIGIL-wrapped natural-language hunch that is broadcast to the council.

The Three Layers

  1. Ingestion (1 Hz): sov_intuition_ingest processes every SIGIL event into the Mamba state.
  2. Pattern detection: cosine similarity between current state and historical "concern" states. Threshold: 0.85.
  3. Intuition emission: when 3+ matches occur, the engine emits sov_intuition_status with a natural-language summary.

The 16-Dim State

The Mamba state has 16 dimensions, each representing a different aspect of agent-ecosystem health: (1) sovereign access rate, (2) foreign access attempts, (3) council vote velocity, (4) SIGIL chain growth rate, (5) Mamba state stability, (6) MoE routing entropy, (7) MOM perception confidence, (8) SOV3 ruling severity, (9-16) reserved for emergent dimensions.

Stochastic Resonance

CSOAI applies stochastic resonance noise to the state vector before pattern detection (see sov_apply_resonance). This amplifies weak creative signals — the engine can detect subtle emerging patterns that pure signal processing would miss. The sov_get_resonance_profile tool returns the per-feature sigma values.

Historical Context

The Intuition Engine synthesises three traditions: (1) Mamba SSM (2023), (2) stochastic resonance (Benz 1983), and (3) Hermes/Mercury as the messenger intuition in alchemy. CSOAI's contribution is the integration of these three into a sovereign AI primitive: SOV3 doesn't just answer questions — it feels when something is wrong, before being asked.

Modern Usage

The engine runs continuously on the MEOK backend. It emits a daily morning intelligence digest (sov_intuition_history_daily) at 04:00 UTC. Customers can query the history database (sov_intuition_history_query) for intuition events in any window.

Lead Time

In benchmarks, the Intuition Engine detects emerging issues 40 seconds before any rule-based alarm fires. This lead time is enough for the council to deliberate and respond before the issue crystallises.
