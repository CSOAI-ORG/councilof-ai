DORADO 1-Click

Switch sovereignty jurisdiction with one click. East ↔ West. UK ↔ EU. Sovereign ↔ sovereign.

sovereign.wiki CSOAI Ltd UK 16939677 4 Jul 2026

Definition

DORADO 1-click is CSOAI's flagship operational feature: a single API call or UI button that migrates a tenant's data plane from one sovereign region to another without re-architecting the application. It is named after the dorado fish, which traverses oceans by riding currents — the data plane rides the sovereign current.

What It Does

The 1-click switch performs: (1) snapshot of the current data plane, (2) encrypted transfer to the target region, (3) cryptographic verification at the destination, (4) atomic cutover, (5) revocation of the source region's data keys. The whole sequence takes 60–180 seconds for a 1TB tenant.

Why It Matters

Most cloud providers offer "regions" but not "sovereign regions" — a region is just a data centre location. Sovereignty requires more: jurisdictional clarity, treaty-aware access controls, post-quantum key escrow, and SIGIL-emitted proof of migration. DORADO 1-click does all of this in one operation.

Technical Implementation

The switch is implemented in three SOV3 tools: sov_dorado_switch (the trigger), sov_dorado_multi_region (the route planner), and sov_dorado_pqc_status (the cryptographic state inspector). It requires 2-of-3 council approval for any cross-realm migration (see 2-of-3 Majority).

Historical Context

The "1-click" pattern derives from the 1990s web hosting industry, where cPanel offered 1-click installs. CSOAI adapts it to sovereignty: the click is the legal act of choosing a jurisdiction, not just a technical deployment detail. The Foreign vs Sovereign classifier is the check that prevents illegal switches.

Modern Usage

Customers trigger 1-click switches when: (a) regulatory regime changes (e.g., UK leaving EU), (b) geopolitical events demand data relocation, (c) a corporate merger requires data unification, or (d) disaster recovery is needed. Each switch emits a SIGIL S|M event with full provenance.
