Ed25519 Signatures

Edwards-curve digital signature algorithm — sovereign signing primitive.

sovereign.wiki CSOAI Ltd UK 16939677 4 Jul 2026

Definition

Ed25519 is a public-key signature system based on the Edwards-curve form of Curve25519, defined in RFC 8032 (2017). It is the default signature algorithm for CSOAI's SIGIL chain, DIDs, and Article 50 passports.

Properties

  • Fast: signing ~50µs, verification ~150µs on commodity hardware
  • Compact: 32-byte public keys, 64-byte signatures
  • Deterministic: no randomness required for signing (k derived from secret + message)
  • Side-channel resistant: designed for constant-time implementation
  • Quantum-vulnerable: requires rotation to ML-DSA-65 for post-quantum security

Why Ed25519?

CSOAI chose Ed25519 over RSA-2048, ECDSA-P256, and BLS12-381 for the following reasons: (1) speed — verification is fast enough for high-throughput SIGIL emission (1 Hz per agent × 33 agents = 33 sigs/sec), (2) size — small signatures keep the chain compact, (3) simplicity — no parameter choices to get wrong, (4) audit history — well-studied since 2017 with no major breaks.

Usage in CSOAI

Ed25519 keys are issued at principal registration via sov_did_create. Each key signs: (1) every SIGIL emission, (2) every Article 50 passport, (3) every Council vote, (4) every DORADO switch. Keys are rotated every 90 days by default — see Key Rotation.

Mathematical Sketch

Ed25519 uses the curve -x² + y² = 1 + d·x²·y² over the prime field GF(2²⁵⁵ - 19). The signature is a pair (R, S) where R is a curve point derived from the message and S is a scalar derived from the secret key, R, and the message. Verification checks 2^c · S · B = 2^c · R + 2^c · H(R || A || M) · A, where B is the base point and A is the public key.

Historical Context

Daniel J. Bernstein designed Ed25519 in 2011 as part of the NaCl cryptography library. It was standardised by the IETF in RFC 8032 in 2017. CSOAI deployed it as the SIGIL chain signature in March 2026. The migration to post-quantum (ML-DSA-65) is scheduled for 2027 — see ML-DSA-65.

Modern Usage

Every customer gets an Ed25519 keypair on signup. The private key is generated on the customer's device and never exported; the public key is registered with CSOAI as part of the customer's DID. Verification is done by anyone with the public key — see sov_did_resolve.
