Sovereign Methodology

How to build a sovereign AI system from scratch — the seven-phase method.

sovereign.wiki CSOAI Ltd UK 16939677 4 Jul 2026

Definition

The Sovereign Methodology is CSOAI's seven-phase procedure for building a sovereign AI system from scratch. It is the synthesis of 100+ deployment projects between 2024 and 2026, distilled into a repeatable method.

Phase 1 — Charter

Write a charter identifying the principal, the jurisdictions in scope, and the sovereignty properties the system must have. Reference the Five Axioms. The charter is a public document.

Phase 2 — Substrate

Establish the substrate: a file system (MEOK), a hash chain (SIGIL), and a key management layer. Every byte must be addressable by hash, every key must be tied to a principal's DID. Reference SIGIL Chain and Ed25519.

Phase 3 — Identity

Issue DIDs to every actor. Generate Ed25519 keypairs on principal devices. Document the rotation policy (90-day default — see Key Rotation). Plan the PQC upgrade path to ML-DSA-65.

Phase 4 — Jurisdiction

Map the data to its jurisdiction. Install the Foreign vs Sovereign classifier. Configure the treaty database. Define the eight sovereign realms (UK, USA, EU, CA, AU, NZ, JP, AUKUS — see Realms).

Phase 5 — Model

Choose the sovereign model architecture: OOWM sandwich (see OOWM Sandwich) for central inference, Big Braim (see Big Braim) for ensemble, SOV3small3 for offline/edge. All weights must be open-source.

Phase 6 — Governance

Stand up the 12-around-1 council (see 12-around-1). Define the 2/3 majority rule for sovereignty-changing actions (see 2-of-3 Majority). Publish the council member DIDs.

Phase 7 — Compliance & Audit

Wire the 30-framework compliance check (see Specification). Emit Article 50 passports for AI-generated content (see EU AI Act). Open the SIGIL explorer publicly. Schedule quarterly checklist reviews (see Checklist).

Methodology Outputs

A system built via this method produces: a Charter (public), a DID registry, a SIGIL chain, an OOWM model, a Council, a Compliance report, and a Checklist score of 20/20. Time to sovereign: 6–9 months for an enterprise, 3–6 months for a startup.

Historical Note

The methodology emerged from CSOAI's deployment to UK AISI (AI Safety Institute, see UK AISI), DEFONEOS defence consortium, and the iOK Farm sovereign deployment in 2026.
