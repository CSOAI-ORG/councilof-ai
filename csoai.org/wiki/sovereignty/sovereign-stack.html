Definition

The Sovereign Stack is CSOAI's vertically-integrated AI infrastructure, built so that no layer of the system depends on a non-sovereign intermediary. Sovereignty is enforced at every seam, from the silicon to the user interface.

Why Vertical Integration?

Horizontal AI stacks (model from OpenAI, storage from AWS, compute from Azure, governance from a third-party SaaS) cannot enforce sovereignty because each layer has a different sovereign. CSOAI's vertical integration means the same legal entity (CSOAI Ltd, UK 16939677) owns the audit chain from byte to button.

Historical Precedents

The vertical integration pattern is taken from the IBM System/360 era (1964) when IBM owned the chip, the operating system, the compiler, and the application layer. Apple (2007 onward) replicated this for the smartphone. CSOAI replicates it for sovereign AI in 2026.

Layer 0: Silicon

CSOAI prefers RISC-V over x86 because the ISA is open and auditable. Sovereign data centres are located in the eight sovereign realms. See Realms.

Layer 1: Substrate

MEOK is the operating substrate. Every byte is hash-chained to the SIGIL ledger. See SIGIL Chain.

Layer 2: Model

OOWM is the central sovereign world-model: Mamba-2 long-context + Left MoE reasoning + Right MOM perception + SOV3 middle. See OOWM Sandwich.

Layer 3: Governance

12-around-1 BFT council. See 12-around-1.

Layer 4: Compliance

30-framework check covers EU AI Act, GDPR, CRA, NIS2, ISO 42001, NIST AI RMF, UK AI Bill, AUKUS guidance. Article 50 passport covers watermarking. See Laws.

Layer 5: Interface

MEOK OS + iOK Farm physical layer. The interface is sovereign — no foreign telemetry is sent.

Layer 6: Tunnels

The seven protocols (MCP, A2A, x402, DID, JWT, ANP, AGNTCY) are sovereign because they are open specs, not proprietary APIs.
