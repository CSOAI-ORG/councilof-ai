Promise vs Property

Why auditability beats SLAs, and why CSOAI builds properties not promises.

sovereign.wiki CSOAI Ltd UK 16939677 4 Jul 2026

Definition

A Promise is a contractual assurance: "we will not access your data without consent." A Property is a mathematical guarantee: "we cannot access your data without consent." CSOAI builds properties, not promises, because properties are falsifiable, promises are not.

The Argument

Consider a typical cloud SLA: "Your data is encrypted at rest and in transit." This is a promise. It does not say who holds the keys. It does not preclude a court order. It does not preclude an employee with admin access. It is enforced by audit, not by mechanism.

CSOAI's equivalent is a property: "Your data is encrypted with a key you alone hold, the system has no copy of the key, and any decryption attempt emits a SIGIL event visible to you in real time." This is enforced by mechanism. It cannot be silently violated because doing so would require breaking the SIGIL hash chain.

Historical Examples

The Schrems II decision (2020) invalidated the EU–US Privacy Shield because US national security letters could compel disclosure — a promise broken by a property (the actual capability of the US state). The lesson: any system whose sovereignty depends on a promise will eventually be broken by a sovereign with different interests.

CSOAI's Property Catalog

  • Key exclusivity: principal's Ed25519 key is generated on-device, never exported, never held by CSOAI (see Ed25519)
  • Foreign access visibility: every cross-jurisdiction access emits a SIGIL event (see Foreign vs Sovereign)
  • Council ratification: sovereignty-changing actions require 12-around-1 BFT (see 12-around-1)
  • Post-quantum integrity: keys can be rotated to ML-DSA-65 / ML-KEM-768 without downtime (see ML-DSA-65)
  • Public auditability: SIGIL chain is publicly verifiable via the explorer API (see SIGIL Chain)

Why This Matters

For a regulator, the difference is between trusting a vendor's compliance department and verifying the vendor's source code + cryptographic chain. For a citizen, the difference is between hoping their data is safe and being able to prove it. For a nation, the difference is between dependence and sovereignty.

Criticisms Addressed

Critics argue that properties are more expensive than promises. This is true — but only in engineering cost. In trust cost, properties are dramatically cheaper because they do not require ongoing legal enforcement. CSOAI's experience is that property-based sovereignty wins contracts precisely because it eliminates the trust premium.
