01. What is the Coigndaltion?

The empire has 3 brands working in concert: SOV3³ (DEFONEOS) for defence, SOV3 (meok) for the public substrate, and CSOAI for certification. When a DEFONEOS sensor reading is shipped to a CSOAI auditor via a meok substrate call, where does that coordination live?

Until W34, it lived nowhere canonical — scattered across 67+ sovereign MCPs, 1,156+ tests, the SIGIL chain, and the BFT council. None of these was the integration layer. The Coigndaltion is that layer.

The name is a portmanteau of Coign (a cornerstone, from Old French coign — corner) + -daltion (an atom of data, from Latin datum) + cognition (the act of knowing). It is the cornerstone cognition layer that bears the integration load between the 3 brands.

cog_route(data, source_layer, target_layer, via=None)

Routes a datum from one layer to another with a SIGIL receipt. The cornerstone's data router.

from coigndaltion_mcp import cog_route

result = cog_route(
    data={"sensor": "drone-1", "reading": "thermal_hotspot"},
    source_layer="L1_DEFONEOS",
    target_layer="L2_MEOK",
)
# → routed_payload + sigil_receipt + latency_ms + path
print(result["path"])
# "L1_DEFONEOS → L2_MEOK"

cog_unify(data_points, target_frame="audit")

Unifies multiple data points from different layers into one cognitive frame with provenance chain and confidence score.

from coigndaltion_mcp import cog_unify

unified = cog_unify(
    data_points=[
        {"layer": "L1_DEFONEOS", "payload": {"sensor": "drone-1"}},
        {"layer": "L2_MEOK", "payload": {"classification": "person"}},
        {"layer": "L3_CSOAI", "payload": {"verdict": "compliant"}},
    ],
    target_frame="audit",
)
# → unified_frame + provenance_chain + confidence_score

cog_bridge(source_brand, target_brand, intent, ttl_seconds=86400)

Emits a formal cross-layer integration contract between two brands. The cornerstone's contract layer.

from coigndaltion_mcp import cog_bridge

contract = cog_bridge(
    source_brand="defoneos",
    target_brand="meok",
    intent="attest_every_sensor_reading",
    ttl_seconds=86400,
)
# → bridge_contract + sigil_receipt

cog_audit(operation_id)

Verifies the 3-layer audit chain (L1 identity + L2 execution + L3 compliance) for any operation. Returns a verdict.

from coigndaltion_mcp import cog_audit

audit = cog_audit(operation_id="op_xyz_123")
# audit["verdict"] == "PASS"
# audit["chain_hash"] == sha256(...)
# audit["l1_identity_status"] == "verified"
# audit["l2_execution_status"] == "verified"
# audit["l3_compliance_status"] == "verified"

cog_inquire(query)

Resolves a natural-language query to the right layer(s) + tool(s). The cornerstone's NL router.

from coigndaltion_mcp import cog_inquire

plan = cog_inquire("What did the drone see on the perimeter?")
# → resolved_intent + routing_plan + primary_layer
# plan["routing_plan"] == [
#   {"layer": "L1_DEFONEOS", "tool": "defoneos-sensor-mcp.sensor_query"},
#   {"layer": "L2_MEOK",      "tool": "meok-core-mcp.os_route"},
# ]

cog_summon(council_brand, question, quorum=23)

Convenes the BFT council of any brand to answer a cross-layer question. Returns a signed verdict.

from coigndaltion_mcp import cog_summon

verdict = cog_summon(
    council_brand="csoai",
    question="Should we export this payload to a foreign jurisdiction?",
)
# verdict["council_verdict"]["decision"] == "APPROVED"
# verdict["quorum"] == "23/33"

cog_anchor(data_id, scope)

Anchors a data point to the SIGIL chain with a cross-layer scope. The cornerstone's audit anchor.

from coigndaltion_mcp import cog_anchor

anchor = cog_anchor(
    data_id="decision_xyz_789",
    scope="defoneos→meok→csoai",
)
# anchor["hash_chain_position"] → the position in the SIGIL chain
# anchor["chain_valid"] == True

cog_origin()

Returns the full 4-layer topology + integration map. The cornerstone's self-description.

from coigndaltion_mcp import cog_origin

origin = cog_origin()
# origin["topology"] → {L1, L2, L3, L4} with brand, domain, function, mcps, tests
# origin["integration_map"] → 7 cross-layer paths
# origin["empire_state"] → total_mcps, total_tests, sigil_chain_len, brand_layers=4
