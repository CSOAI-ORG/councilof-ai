🔬 Self-Scaffolding Methodology (the real innovation)

Ornith-1.0 uses RL to learn both the SOLUTION and the SCAFFOLD (the orchestration that drives the solution):

  1. Stage 1 (Scaffold): Conditioned on task + previous scaffold, model proposes a refined scaffold.
  2. Stage 2 (Solution): Conditioned on task + new scaffold, model generates a solution rollout.
  3. Reward: Rollout reward propagates to BOTH stages — both scaffold + solution are optimized jointly.

3 Defense Layers:

  1. Fix outer trust boundary (env, tools, tests are immutable)
  2. Deterministic monitor flags any attempt to read withheld paths / modify verification
  3. Frozen LLM judge acts as veto on top of verifier (catches intent-level gaming)
