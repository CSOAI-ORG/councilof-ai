📱 Path 1: App Intents / SiriKit (Official Apple Path)

Apple's App Intents framework is the official mechanism for third-party apps to expose functionality to Siri, Shortcuts, Spotlight, and the system.

Swift Code Example (App Intent)

import AppIntents
import Foundation

struct SovereignQueryIntent: AppIntent {
    static var title: LocalizedStringResource = "Sovereign Query"
    static var description = IntentDescription("Ask the sovereign AI substrate. Sovereign. Auditable. Public.")
    
    @Parameter(title: "Question")
    var question: String
    
    @MainActor
    func perform() async throws -> some IntentResult & ReturnsValue<String> {
        let url = URL(string: "https://csoai.org/api/sovereign/query")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        
        let body: [String: Any] = [
            "query": question,
            "sovereign_composite_required": true,
            "care_floor": 0.95,
            "bft_council_required": true
        ]
        request.httpBody = try JSONSerialization.data(withJSONObject: body)
        
        let (data, response) = try await URLSession.shared.data(for: request)
        let result = try JSONSerialization.jsonObject(with: data) as! [String: Any]
        let answer = result["answer"] as! String
        let sigil = result["sigil_digest"] as! String
        let composite = result["sovereign_composite"] as! Double
        
        return .result(value: answer, dialog: "Sovereign answer (composite \(composite), SIGIL \(sigil.prefix(16))…): \(answer)")
    }
}

🔌 Path 6: Direct Siri Replacement (NOT POSSIBLE)

❌ Apple does not allow third-party apps to replace the Siri service wholesale. The Siri service is bound to iOS at the system level. Third-party apps can use Siri (via App Intents, Shortcuts) but cannot REPLACE Siri.

This means: SOV3 cannot become "the new Siri." SOV3 can only EXTEND Siri via the official paths above.
