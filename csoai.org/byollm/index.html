# Bring Your Own Local Model (BYOLLM) - Sovereign Integration Guide

SOV3 BIG BRAIM v2 supports any sovereign-compatible model. This guide shows how to integrate your own local LLM.

## Step 1: Choose a sovereign-safe model

| Family | License | Sovereign |
|---|---|---|
| Qwen3 family | Apache 2.0 | YES |
| Llama 3 family | Llama | YES |
| Gemma 3/4 family | Open | YES |
| DeepSeek R1/V4 | MIT / Open | YES |
| Ornith-1.0 (DeepReinforce AI) | MIT | YES |
| Kokoro TTS (broadcast) | Apache 2.0 | YES |
| AVOID: MiniMax, Zhipu, Deepseek-Sapiens (foreign backdoors) | | NO |

```bash
# Sovereign examples
```
