Step by step

Step 1/5: Install Ollama

If you don't have Ollama yet, the script installs it automatically (Linux) or downloads the Mac zip (you install manually).

Step 2/5: Start Ollama service

Runs ollama serve in background, listening on http://localhost:11434

Step 3/5: Pull SOV3 small3 (4 sovereign models)

qwen3:1.7b-edge + llama3.2:3b + gemma3:4b + meok-sov3:latest = 7.8 GB.

Step 4/5: Create sovereign Modelfile

Generates ~/.sov3/models/Modelfile.sovereign with full SOV3 system prompt: Public. Auditable. Sovereign. Solve et Coagula. Empire 10/10.

Step 5/5: Verify

Lists installed models. Run ollama run sov3-small3 to start.
