# CSOAI Ltd — 5-Year Financial Model

**Series A Financial Projections | 3 Scenarios | July 2026**

---

## Executive Summary

This model presents three scenarios for CSOAI Ltd over a 5-year horizon (FY2027–FY2031), grounded in the following baseline assumptions:

- **Current state:** £0 revenue, 0 paying customers (July 2026)
- **Product status:** Built and deployed (640 MCP packages, 2 live production systems)
- **Series A:** £3,000,000 at £12,000,000 pre-money (£15,000,000 post-money)
- **Runway:** 24 months at planned burn rate
- **Gross margin (steady state):** 84% (cloud infrastructure + support costs; benchmark: SaaS compliance tools, Vanta/Drata comparable margins of 80-88%)

## Honest Limitations of This Model

1. **No revenue data exists to calibrate CAC, conversion rates, or churn.** All unit economics are projected from SaaS benchmarks, not observed CSOAI data. These numbers will change materially once we have 3-6 months of real customer data.

2. **The Base case assumes aggressive growth** (50 → 5,000 customers in 3 years = 100x growth). This is achievable but not probable without exceptional GTM execution. The Base case should be treated as the optimistic scenario for planning purposes.

3. **Exit multiples assume favourable market conditions.** If AI/compliance valuations compress (as they did in 2022-2023), exit multiples will be lower. The model uses 8-15x ARR; a bear-case compression to 3-5x would reduce exit values by 50-65%.

4. **The Moonshot scenario assumes category-creation dynamics.** If CSOAI becomes the standard for sovereign AI governance (analogous to how Vanta defined compliance automation), the returns are exceptional. This is low-probability but high-impact.

5. **No discount for dilution in later rounds.** If CSOAI raises a Series B to fund growth (likely in Base and Moonshot cases), Series A investors will experience additional dilution of 15-25%.
