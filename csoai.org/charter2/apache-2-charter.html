Article 2 — The Patent Grant

The Apache 2.0 License includes an explicit patent grant. The contributor grants the recipient a perpetual, worldwide, non-exclusive, no-charge, royalty-free, irrevocable patent license to make, have made, use, offer to sell, sell, import, and otherwise transfer the work. The recipient's patent license terminates if the recipient initiates patent litigation against any entity alleging that the work infringes a patent.

Article 3 — The History of the Apache License

The Apache License was developed by the Apache Software Foundation (ASF) in the 1990s. The ASF was formed in 1999 to oversee the Apache HTTP Server project, which began in 1993. The Apache License, Version 1.0 was released in 1995. The Apache License, Version 1.1 was released in 2000. The Apache License, Version 2.0 was released in January 2004. The license is now used by over 8,000 Apache projects and countless other open-source projects including Kubernetes, TensorFlow, Apache Spark, Apache Kafka, Apache Hadoop, and many more.

Article 4 — The Apache 2.0 License + Sovereign AI

The Apache 2.0 License is the second-most-permissive open-source license (after MIT). The CSOAI substrate is MIT-licensed, but it interoperates with Apache 2.0 projects (e.g., Apache Kafka, Apache Spark, TensorFlow, Kubernetes). The substrate's 8 Layer-0 protocols, 22 legacy bridges, 531 MCPs, 33-agent BFT, 554-comp OSCAL proof, Care Floor 0.95, and Ed25519 + PQC ML-DSA-65 are all designed to interoperate with Apache 2.0 projects without license conflicts.

Article 5 — The Apache 2.0 License + Care Floor 0.95

The Apache 2.0 License is compatible with the sovereign substrate's Care Floor 0.95. The license is permissive (the substrate may add Care Floor obligations via separate agreements or technical architecture without conflicting with the license). The substrate enforces Care Floor 0.95 via the 33-agent BFT council, the 554-comp OSCAL proof, and the SIGIL chain - not via license terms.

Article 6 — The Apache 2.0 License + Patent Sovereignty

The Apache 2.0 License includes a patent grant. The CSOAI substrate respects the patent grant. The substrate never initiates patent litigation against any entity alleging that the substrate infringes a patent. The substrate uses the patent grant to ensure sovereignty: every sovereign consumer of the substrate is protected by the patent grant.

Article 7 — The Apache 2.0 License + 22 Legacy Bridges

All 22 legacy bridges in the CSOAI substrate are designed to interoperate with Apache 2.0 projects. The bridges can be integrated into Apache Kafka streams, Apache Spark jobs, Apache Hadoop clusters, Kubernetes pods, and TensorFlow models without license conflicts.

Article 8 — The Apache 2.0 License + SIGIL Chain

The Apache 2.0 License is compatible with the SIGIL chain. The SIGIL chain is the sovereign substrate's audit trail. Every Apache 2.0 bridge in the substrate is SIGIL-signed Ed25519 + PQC ML-DSA-65. The license does not conflict with the SIGIL chain because the SIGIL chain is metadata (audit data), not a derivative of the licensed software.
