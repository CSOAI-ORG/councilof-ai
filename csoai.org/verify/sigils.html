How to verify a SIGIL

Every sovereign action emits a SIGIL on the live chain. Every SIGIL has a unique digest (32-hex SHA-256 truncated). You can verify any SIGIL by querying the live substrate.

The verification protocol

# 1. Get a SIGIL digest from the substrate
DIGEST="a6c67cfbc5a62f65"  # example
OP="C"
LINE="C|FINAL_HOME_STRETCH|T2026-06-29T17_43_BST."

# 2. Verify via SOV3 MCP
curl -X POST http://localhost:3101/mcp \
    -H 'Content-Type: application/json' \
    -d '{"jsonrpc":"2.0","id":"1","method":"tools/call","params":{"name":"sov_sigil_emit","arguments":{"line":"V|' + DIGEST + '|' + OP + OP, "op": "V"}}}'

# 3. Or call:
curl -X POST http://localhost:3101/mcp \
    -H 'Content-Type: application/json' \
    -d '{"jsonrpc":"2.0","id":"1","method":"tools/call","params":{"name":"sov_sigil_emit","arguments":{"line":"V|a6c67cfbc5a62f65|C", "op": "V"}}}'

# 4. Verify by hostname
https://csoai.org/verify/sigils.html?digest=a6c67cfbc5a62f65

# 5. Or hand-check the SIGIL chain
cat ~/.hermes/sigil-log-2026-06-29.jsonl | grep "a6c67cfbc5a62f65"

The SIGIL chain integrity

Every sovereign action is

  1. Emitted on the live SOV3 chain (port 3101)
  2. Signed with Ed25519 (classical) + PQC ML-DSA-65 (post-quantum)
  3. Hash-chained (each SIGIL links to the previous)
  4. Logged to ~/.hermes/sigil-log-{date}.jsonl
  5. Verifiable by anyone (you can call the same JSON-RPC)

How to challenge a SIGIL

If you suspect a SIGIL is forged:

  1. Look up the digest at /verify/sigils.html?digest=X
  2. Re-compute the Ed25519 signature with the substrate's public key
  3. Re-compute the PQC ML-DSA-65 signature
  4. If signatures don't validate, file a sovereign complaint at csoai.org/kingdom/
