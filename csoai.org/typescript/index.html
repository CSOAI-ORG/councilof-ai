Quickstart

import { SovereignClient, SIGIL, Article50Passport } from '@sov3/sdk';

// 1. Create your sovereign client
const client = new SovereignClient({
  sov3McpUrl: 'http://localhost:3101/mcp',
  meokBackendUrl: 'http://localhost:8000',
  apiKey: process.env.SOV3_API_KEY,
});

// 2. Run a sovereign audit
const audit = await client.audit({
  system: 'Production AI',
  frameworks: ['EU AI Act', 'UK AI Bill', 'ISO 42001'],
});
console.log(`Sovereign composite: ${audit.composite}`); // 7.305

// 3. Issue an Article 50 passport
const passport = await client.articles50.issue({
  contentHash: 'sha256-of-content',
  watermarked: true,
});
console.log(`Passport ID: ${passport.id}`); // art50-72384578499f

// 4. Emit a sovereign SIGIL
const sigil = await client.sigil.emit({
  line: 'C|production|T2026-07-04T09_00_BST. eu_ai_act_compliant.',
  op: 'C',
});
console.log(`SIGIL: ${sigil.digest}`);

The SovereignClient API

Three core sub-clients, all type-safe:

client.substrate

The SOV3 MCP substrate. Discover 330 tools, invoke any with full TypeScript types.

await client.substrate.listTools();
await client.substrate.invoke('sovereign_compliance_check', {
  system: 'AI',
  frameworks: ['EU AI Act'],
});

client.sigil

Immutable SIGIL chain. Every action recorded with Ed25519 + PQC ML-DSA-65.

await client.sigil.emit({ line, op });
await client.sigil.verify(digest);
const chain = await client.sigil.recent(10);

client.cascade

4-tier sovereign cascade. Routes queries across 33 sovereign districts.

await client.cascade.routeQuery({
  query: 'EU AI Act audit for fintech',
  taskType: 'compliance',
});

client.articles50

EU AI Act Article 50 watermarking. Passport issuance + verification.

await client.articles50.issue({...});
await client.articles50.verify(passportId);

client.iCharacter

Consent-first digital twin. Create, evolve, trade on TwinStore.

await client.iCharacter.create({...});
await client.iCharacter.evolve(icharId, msg);

client.council

12-around-1 BFT council. Vote on sovereign proposals. 2/3 majority.

await client.council.vote({
  proposal: 'switch EAST',
  choice: 'for',
});

Errors

import { SovereignError, SIGILFailedError, DORADORefusedError } from '@sov3/sdk';

try {
  await client.substrate.invoke('sovereign_action', args);
} catch (e) {
  if (e instanceof DORADORefusedError) {
    console.error('Sovereignty switch refused:', e.reason);
  } else if (e instanceof SIGILFailedError) {
    console.error('SIGIL chain error:', e.chainStatus);
  }
}
