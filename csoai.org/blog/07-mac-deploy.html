The Install

# 1. Install Ollama
brew install ollama

# 2. Pull SOV3small3 (the 4-model stack)
ollama pull llama3.1:8b
ollama pull qwen2.5:3b
ollama pull nomic-embed-text
ollama pull moondream

# 3. Clone the sovereign substrate
git clone https://github.com/CSOAI-ORG/sov3-sovereign.git
cd sov3-sovereign

# 4. Build
make sovereign

# 5. Run
./sov3 sovereign shell
