🦠 LLM Defender Flag Rundown

When Windows Defender, Malwarebytes or Norton flags an LLM client as "malware" — is it real?

TL;DR (90-second read)

If your AV flagged minimax-m3 (or MiniMax AI) as malware, it's 95% likely a false positive caused by behavioural heuristic matching — not actual malware.

Why? Local LLM clients exhibit the SAME behavioural pattern as keyloggers: persistent background service, writes user data to disk, calls out to overseas servers, may auto-update, monitors clipboard.

Defender's neural heuristic sees this pattern and flags anything resembling it. The same heuristic that catches a real Trojan also catches MiniMax M3.

Why MiniMax-M3 specifically got flagged

MiniMax (a Chinese AI startup) ships a local app + binary. When installed, the binary:

  1. Registers a Windows service that auto-starts at boot
  2. Installs a heavy DLL into %APPDATA%\MiniMax\
  3. Calls https://api.minimaxi.chat every 60s
  4. Writes chat logs to %LOCALAPPDATA%\MiniMax\conversations.db
  5. Captures clipboard if "smart paste" is enabled

These are not illegal or malicious — they're how the LLM provides "auto-context." But Defender doesn't know that.

What to do

  1. Don't restore the file. Quarantine stays put.
  2. Submit to VirusTotal at virustotal.com. If only Defender flags it (1/70 engines), it's almost certainly a false positive.
  3. Re-download from the official website if you want to reinstall. minimaxi.com
  4. Add an exclusion in Defender if you've verified the binary is clean: Defender > Virus & threat protection > Exclusions > Add folder > %APPDATA%\MiniMax
  5. Run a second scanner like Malwarebytes or ESET Online Scanner — if they agree with Defender it's likely real, but if they don't, it's a false positive.

⚠️ When it IS malware

Only treat this as malware if:

  • VirusTotal shows 10+ detections across multiple engines (Kaspersky, ESET, Sophos, Avast, etc.)
  • The binary is packed/obfuscated (unreadable strings)
  • You downloaded it from a non-official mirror (e.g. a third-party "mod")
  • Your other security tools also flag it
  • You see unexpected outbound traffic to non-MiniMax IPs
