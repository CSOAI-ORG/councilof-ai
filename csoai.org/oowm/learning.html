The 3 Architecture Layers (the brain)

1. Mamba-2 Long Memory

State-space compression. Any-length context → 16-dim state vector. Per ZAMBA (Zyphra 2024). Persistent across sessions.

state(t+1) = A · state(t) + B · x(t) ; y(t) = C · state(t) + D · x(t) ; state ∈ ℝ¹⁶

2. 64-Expert MoE (Mixture of Experts)

Task routing. Each citizen query hits the top-k experts (k=4). Sparse activation = low inference cost, high capacity. Trained on 25 industry verticals + 22 hieroglyphs.

P(expert_i | x) = softmax(W_g · x) ; y = Σ_{i ∈ top-k} P_i · Expert_i(x)

3. Standard Attention (planning)

For multi-step reasoning, BFT council deliberation, and planning horizons > 7 steps. 32K context. FlashAttention-2. RoPE positional encoding.

4. Sovereign Layer (governance)

The wrapper. Every token tagged with: BFT vote id, SIGIL digest, Article 50 passport, Care Floor score, DORADO region, citizen DID.
