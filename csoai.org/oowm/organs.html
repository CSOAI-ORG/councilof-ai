Organ Failure Modes (what happens if one fails)

  • Brain (MoE): Fallback to base model. BFT convenes. Composite drops; auto-revision.
  • Heart (Care Floor): All output halted. SIGIL emitted: care-floor-offline. Custodian alerted.
  • Lungs (BFT): Read-only mode. Custodian takes manual vote. Reweight on recovery.
  • Spine (SIGIL): Auto-replay from last valid anchor. Affected events tombstoned.
  • Skin (DORADO): Multi-region failover. Zero-Trust posture elevated.
  • Voice (Article 50): Output blocked until passport issued. Free tier HMAC fallback.
  • Memory (Mamba): Cold restart from snapshot. 16-dim state rebuilt. Loss of in-flight context only.
