Reproduce the list:

```bash
cd ~/clawd/councilof-ai
git worktree list --porcelain | awk '/^worktree /{w=$2} /^branch /{b=$2; print w" "b}' \
| while read wt br; do
    git merge-base --is-ancestor "$br" origin/master 2>/dev/null \
      && printf "%-8s %s\n" "$(du -sh "$wt" | cut -f1)" "$wt"
  done
```

**I did not remove them.** A branch being merged does not prove its worktree is idle — a lane can
still be working in one, and `--force` would take uncommitted work with it. This is the governor's
call, one line each:

```bash
git -C ~/clawd/councilof-ai worktree remove ~/clawd/<name>     # no --force; refuses if dirty
```

Running it **without** `--force` is the safe form: it refuses on uncommitted changes, so a busy
lane protects itself.

## What is NOT cold and must stay

`~/clawd/councilof-ai` (2.8G) is the shared main checkout every lane's worktrees are anchored to.
Removing or moving it detaches all 30 worktrees at once. **Do not touch it.**

## The arithmetic

| Action | Frees | Needs RunPod? |
|---|---|---|
| Remove 19 merged worktrees | **3.15 GB** | **no** |
| Clear `~/Library/Caches` | 1.8 GB | no |
| Archive the bundle + `_evacuation` | 1.0 GB | yes (or any cold store) |
| Archive `~/Downloads` after mining | 2.5 GB | yes |
| **Total reachable** | **~8.4 GB** | only 3.5 GB of it |

**~5 GB of the ~8.4 GB needs no RunPod at all** and no owner decision beyond "is this lane idle".
The RunPod move is the smaller half, and it is the half that costs something.

## Standing rule this supports

v3 already says: sparse worktree for data/doc PRs, full checkout **only** when you must build
`client/` (R16). Measured today: sparse 80 KB–340 MB, full ~2.8 GB. R16 is the reason the disk is
survivable at all; the 19 merged worktrees above are what happens when it is followed but cleanup
is not.
