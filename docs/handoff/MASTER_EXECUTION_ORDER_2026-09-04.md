usable dashboard and evidence-scoped GSPC assets; keep duplicate shells,
simulated runtimes, placeholder proofs and unsupported claims out. Revenue,
growth, IP and GSPC work must produce local, reviewable evidence artifacts—not

## Order of work

1. Hermes resolves the current base, refreshes the claim/evidence ledger and
   writes an internal path/owner classification only.
2. TUI 1 and TUI 2 work in parallel inside their exclusive boundaries and
   return exact-path manifests plus fresh tests. Neither integrates or deploys.
3. Claude Master checks every manifest against the same resolved base, returns
   ownership conflicts, and prepares a local integration only if needed.
4. Claude Master runs the complete current workflow gate chain on one unchanged
   tree and shows the production-shaped preview.
5. Stop. Commit, push, PR, merge, workflow dispatch, external publication,
   email and spend require a separate explicit owner instruction.

No lane pushes directly to `master`, stages broadly or writes outside its
boundary. New features become later tasks unless they close a demonstrated
truth, security or usability blocker.

## Required release checks

The current workflow is authoritative. At minimum, the local integration must
pass every command in the Claude Master brief, including:

- wallet-secret self-test and scan;
- evidence-integrity and Council-truth gates;
- candidate root/witness gate;
- redirects and both source/built Pages-size guards;
- TypeScript ratchet, tests, build and dashboard/full prerender;
- shell E2E, prerender filesystem check and launcher checks;
- brand, signed-JSON, price, facts and required-dist inventory checks;
- `git diff --check` on the exact reviewed tree.

A separately authorised future deployment must also pass immediate,
anti-clobber and hold verification, exact deployed-root recheck and the live
root/witness gate. A successful local build or merge is never deployment proof.

## Definition of done

Done for this post-release pass means: all four bounded evidence artifacts are
present; every changed path has one owner; the UI and APIs use the same evidence
states; current root, card and witness scopes agree; every unavailable function
fails closed; and the complete gate chain passes on one unchanged tree. It does
not mean an email was sent, a dataset was published, money moved, a patent was
filed, a branch was merged or production was changed.
