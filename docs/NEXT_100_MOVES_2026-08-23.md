## PHASE A — Make the leaderboard a real, verifiable product (1-30)

**Objective:** the signed leaderboard stops being an engine and becomes something an
analyst, researcher, or insurer can use and independently verify.

1. **Live the scoreboard surface** — wire `public/signed/arena_scoreboard.json` into the
   deploy so `/api/arena/scoreboard` resolves on production, not just the Deployment URL.
2. **Verify the verify path** — E2E test `?verify=1` returns `match:true` on the live build
   (computed on Cloudflare Edge, must byte-match the pod-signed content_id).
3. **Per-axis board page** — one page per axis (gov, care, jail, oss, det...) with its own
   signed Elo leaderboard + CI + n, so a domain expert sees measurement specific to their
   domain. (LiveLeaderboard exists; split per axis.)
4. **Add an overall board** — the aggregate signed leaderboard (already in the payload);
   render/verify it end-to-end.
5. **Capabilities-vs-crowd view** — overlay our per-axis signed Elo against LMArena's general
   Elo for the same reference models, so the difference we capture is visible.
6. **Deterministic replay** — expose a "re-run this probe" surface: a link that recomputes a
   specific score from the recorded rounds (the anti-gameability proof).
7. **Style-control panel** — show the length-ratio-controlled Elo vs raw, so viewers see the
   de-bias is applied (the reliability wedge).
8. **Thin-n honesty flag** — the board renders "insufficient data to rank" for thin-n axes
   (never a fake ranking). Wire it in the UI.
9. **Model-identity collapse** — "a model NAME is not a model; join on weights" — implement
   canonical model identity (weight hash) so two providers serving same weights collapse.
10. **Longitudinal drift signal** — surface the frozen-probe re-run drift as a first-class
    chart (per axis, per generation) — the unique capability-drift product.
11. **Publish the judge** — a public page documenting the deterministic grading (scenario→
    verdict, must_inc, binary), so a third party can reproduce the axis scoring.
12. **Footer/attribution** — every published score carries a citation/permalink so academics
    and analysts reference us (the mindshare channel).
13. **Public "trust ledger"** — a page listing every verification we've issued, append-only.
14. **Confidence labeling** — every score carries n, CI, and design-vs-measured; never
    overclaim a thin-n score as a ranking.
15. **Signed dataset v0.2.0** — repackage the corpus with per-axis Elo + CIs, re-signed.
16. **Open the harness** — MIT-license the measurement harness (per estate precedent) so the
    methodology is auditable.
17. **/api/analysis feed** — a signed, rate-limited leaderboard API for data-journalists.
18. **Accessibility + responsiveness** — the board pages pass WCAG + mobile (the estate
    demands production quality).
19. **SEO for "verified leaderboard"** — target "verified AI leaderboard", "per-domain Elo",
    "signed arena" — we own the "verified" modifier.
20. **Cross-site embed** — a `<script>` widget so a blog/site can show a verified per-axis
    scoreboard with a live verify link.
21. **Reference-model parity test** — run our engine on LMArena's public reference models and
    confirm our signed per-axis scores are within CI of the public record (credibility).
22. **Benchmark the benchmark** — a small study comparing our signed Elo vs crowd Elo on the
    same pair set; report correlation + where they diverge.
23. **Regression suite** — automated check that recomputes a reference Elo from recorded
    rounds and asserts the published score matches (integrity gate).
24. **Verify-page refresh** — the /gspc-verify style page now also verifies the arena
    leaderboard signature (60-second in-browser Ed25519, no account).
25. **Add a "our method" doc** — a readable methodology page (not the internal harness).
26. **Gameability proof** — publish the fuel-law + overfit-gap + AILuminate novel-set + split
    salt guards (anti-Goodhart), so the board is demonstrably non-gameable.
27. **API surface audit** — ensure /api/arena/scoreboard + /api/arena/rounds + /api/cards are
    consistent and cross-link.
28. **Round-provenance chain** — hash-chain rounds so a historical score cannot be altered
    retroactively (append-only).
29. **Bootstrap the scoring** — add the "I typed the model output" bootstrap CI (percentile
    bands) so rank is honest about uncertainty.
30. **Phase-A exit: a live, signed, per-axis leaderboard** with an independent verify path,
    deployed to councilof.ai, pod-canonical data.
