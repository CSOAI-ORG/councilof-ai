## Interest Statement

CSOAI Ltd operates an independent AI measurement body that publishes signed, independently verifiable evidence for AI governance. We measure AI systems on 22 axes using frozen test banks and deterministic grading, with Ed25519-signed measurement cards and a public Merkle root.

We are interested in contributing to W3C standards work related to:
- AI transparency and provenance (aligned with our measurement methodology)
- Verifiable credentials and signed evidence (we use Ed25519, DID:web, Merkle roots)
- Agent-to-agent protocols (we implement A2A, MCP, x402)
- Web content integrity (our cards are independently verifiable from published bytes)

## Relevant Work

- GSPC Board: 22-axis AI measurement, live at councilof.ai/api/gspc
- 335 signed measurement cards with Ed25519 signatures
- Public Merkle root (257 leaves) with Rekor witness
- x402 payment protocol integration on Base mainnet
- MCP server with 12 tools (8 free, 4 paid)
