# Contact = public artifact only

**Doctrine:** outreach and corpus rows reference **public URLs and on-chain addresses** — never private inboxes as the primary artifact.

## Allowed contact fields

- Public issuer page (regulator filing, fund factsheet, NYDFS trust page)
- Explorer link (XRPScan r-address, Etherscan contract)
- Dated press or filing with a stable URL
- `public_id` on-chain identifier when verified

## Not allowed as “the contact”

- Unpublished email threads or DMs as proof
- “Trust us” AUM figures without a cited primary
- Invented `measured_score` or MEASURED AUM/TVL from secondary headlines

## RWA attestation posture

- Stage 1: data + doctrine only
- Stage 2: testnet pointers to **public** facts (clean plays first; JMWH demo-only)
- Stage 3: mainnet clean set post-counsel

Attestation ≠ tokenization ≠ ownership. Measurement, not certification.
