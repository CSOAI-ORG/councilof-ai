## Next gates

- Release: pass existing worldLens tests, exact-head build and strict protected CI; merge through the normal single writer; verify production HTTP, 3D canvas, iframe camera commands, keyboard/touch and 390px mobile UI with an outside browser. No auto-merge.
- Ontology: source and authority registry for every node, with explicit geo provenance or NON_GEOSPATIAL and source/observation/event/fetch timestamps. Never fabricate lat/lon for a benchmark, user or simulated agent.
- Simulation: adapt the existing world-rehearsal engine through a scoped authenticated broker. A MiroFish/OASIS runner can later be isolated behind licence and model/data permissions, deterministic seed, cost quota, content safeguards, replay/negative controls and provenance.
- MEOK: qualified reciprocal identity/capability contract, explicit provider and model identity, consented user context, tenant isolation and safe read-only transcript. Council and MEOK maintain independence; neither model can self-approve an execution.
- Human authority: independently authenticated fresh human approval of an exact request; executor checks qualifications, expiry and revocation at effect time; independent observer and receiver readback. Start with one harmless sandbox action, never unapproved physical-world actuation.
- Replay and learning: practice XP and synthetic outcomes are not professional qualifications, GSPC scores, real-world predictions or accepted effects. Require event digests, producer identity, scenario versions, counterfactual trace, independent measurement and corrections.
- Security: same-origin and bounded globe postMessage, safe iframe and CSP, no private DEFONEOS telemetry, avoid arbitrary scripts and untrusted 3D tiles, no default billing or private models.
- Production truth: browser deployment, replay, source verification, licensing and commercial acceptance must each be independently reported. Passing offline source tests does not imply any are complete.

This is one integrated Council World candidate, not a replacement operating system, new authority ledger or claim that simulations are reality.
