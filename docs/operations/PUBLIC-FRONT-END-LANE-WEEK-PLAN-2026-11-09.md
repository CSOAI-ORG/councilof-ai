## 0. Standing rules for the week (so unattended runs stay safe)

1. **PR-only.** `master` is protected; every landing is a branch + PR + green gates. No force to master, ever.
2. **One lane = one writer = one branch = one worktree.** Other lanes' surfaces are read-only; a conflict
   goes to `LANE_COORDINATION.md` as an appended notice, never as a byte counter-attack.
3. **Generated bytes regenerate through their own script.** The axis pages, `openapi.json`, `sitemap.xml`,
   the signed index and the catalogue are producers' outputs; they are never hand-edited.
4. **Stamped bytes are untouchable by hand.** A producer artefact regenerates via its script + restamp.
5. **Owner-gated rows are observed, never faked.** A security-key touch, a credential, a named human label
   and an owner's promotion decision are recorded as *waiting on a named human*, never simulated.
6. **A gate that cries wolf is worse than no gate.** A check that cannot fail protects nothing; one that
   fails on a difference between two hosts protects nothing either.

## 2. The invariant this week keeps

**A door is a promise only if something published names it.** On 2026-11-09, 61 doors were probed and 10
answered 404 — and every one of those ten was a door no published surface names. That is the difference
between a broken journey and an invented one, and this week keeps the distinction measurable rather than
impressionistic.

**A dated read is a new document.** The 2026-11-03 audit stays as it is; the 2026-11-09 audit is a second
reading beside it. The 2026-11-03 journey auditor stays in its lane's delivery bundle until that lane
lands it; this lane's cross-check is named as a cross-check.

**Frozen is published; fluid is derived.** The board's numbers are read from the payload; a page that
quotes a number reads it at write time. The CSP is the same shape: the policy is a claim about what the
site loads, and it is promoted only when the report names what it actually loads.
