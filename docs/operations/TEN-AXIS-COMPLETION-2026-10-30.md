## Charter and human-operation mapping

The ten rows attach to the existing 33 specialist definitions; they do not create ten new
authorities or running hives. A specialist observes, tests and proposes within the existing
task grant. Its own measurement must never grant it execution, signing or admission authority.

For the end user, show three separate facts: **what was observed**, **what is still unknown**,
and **what action a named human can approve or stop**. A changed source produces a review task,
not an accusation or automatic sanction. A failed fetch produces an evidence gap, not a zero
score. A digest proves consistency of retained bytes, not truth, legitimacy or safety.

The private governance backend should bind the task, permitted tool, target, limits, expiry
and expected effect to its existing proposal/decision receipt. Recheck that grant immediately
before an effect, retain a result or unresolved-effect state, and make Stop prevent new work
while reconciling anything already dispatched. Source correction and replay belong to the
same evidence trail; they do not create a new public measurement or human approval.

Offline operation can verify local frozen policies and evidence using available trusted keys.
It must label missing current revocations, network receipts or independent review as unknown.
It cannot provide universal tracking or stop software outside its enforcement boundary.

## Interpretation limits

The discovery runner's 3-of-5 threshold was chosen after seeing the data. Its SHA-negative
controls only check payload consistency. Some public responses were capped and the selected
subjects form convenience samples. None of those facts justify silently changing the original
axis definition so that discovery becomes a measurement. The generated audit retains these
limits and the current ten-axis hold explicitly.

## Follow-through: retained artifacts and an executed example

The new `scripts/measurements/subject-artifact-evidence.mjs` consumes every row of the
original nine discovery frames after verifying each frame against its recorded hash. It
includes the 26 rows omitted from the older successful-fetch banks. It freezes its own
method and inputs before collection, deduplicates exact repository/URL sources, retains
complete successful responses and records failures separately. It does not merge named
organisations merely because their repositories share an owner.

The final run covered all 362 original frame memberships through 349 deduplicated source
reads: 175 pinned repositories, 700 verified file artifacts, 146 retained web responses
and 28 unavailable sources. All 349 records replayed. Twenty-two collector tests passed,
including eight mutations of the retained report; seven reproduction-runner tests also
passed. These are 29 new checks, separate from the earlier 29 claim-wave checks.

For GitHub sources, the collector pins a commit and its tree, rejects incomplete trees,
selects a bounded set of actual filename candidates, and verifies each downloaded file
against the pinned Git blob and its SHA-256. README, licence, environment, method, test
and result filenames are review aids; filename matching cannot establish their semantics.
It never executes collected third-party code. The separate Tracr experiment below is an
explicitly scoped execution with its own input freeze and environment.

The final collection and per-axis counts are retained in
[TEN-AXIS-ARTIFACT-EVIDENCE-2026-10-30.json](TEN-AXIS-ARTIFACT-EVIDENCE-2026-10-30.json).
The updated audit adds explicit rejection reasons, including omitted original candidates,
unreviewed identities, posthoc thresholds, capped responses and the regulator axis's
forbidden composite score. Historical banks are preserved; this audit rejects their use
as admission evidence instead of silently rewriting them.

Collection follows GitHub's documented [tree completeness](https://docs.github.com/en/rest/git/trees#get-a-tree)
and [blob response](https://docs.github.com/en/rest/git/blobs#get-a-blob) contracts. The
API and retained file bytes support provenance review, not repository trustworthiness.

### Tracr: one published example, actually executed

The runner `scripts/measurements/tracr-example-reproduction.py` reproduced the
[reverse-program example at commit 9ce2b8c](https://github.com/google-deepmind/tracr/blob/9ce2b8c82b6ba10e62e86cf6f390e7536d4fd2cd/README.md).
Before importing or running Tracr, it froze every sequence of lengths one to three over
the vocabulary `{1, 2, 3}`: 39 cases, with exact expected reversals. It compiled and ran
the actual upstream transformer on M4 CPU, alongside a deliberately wrong identity
program. All 39 reversals matched. The wrong program was rejected on all 24 non-palindromic
inputs; the other 15 inputs cannot distinguish identity from reversal and are reported
separately. All 39 retained observation rows replayed.

- [Frozen input, source hashes and resolved environment](tracr-example-20261030/input.json)
- [Observed outputs](tracr-example-20261030/outputs.jsonl)
- [Result and limits](tracr-example-20261030/result.json)

The first attempt stopped while compiling a bare-token identity control, before collecting
any case outputs: the pinned compiler had no layers to allocate. That failed attempt is
retained privately. The second attempt uses an explicit identity attention selector, with
a new method/input freeze and the same predeclared input domain and acceptance counts.
No failed observations were discarded or substituted. Dependencies were installed in an
isolated environment; no model weights, paid compute or API inference were used.

This establishes a scoped example reproduction by this operator on one machine. It does
not reproduce the paper's full experiments, create 39 independent group observations,
establish harness or serving fidelity, satisfy independent review, or admit an axis.

The public output rows can be checked without JAX or private installation metadata:

```python
import hashlib, importlib.util, json
from pathlib import Path
p = Path("docs/operations/tracr-example-20261030")
spec = importlib.util.spec_from_file_location("repro", "scripts/measurements/tracr-example-reproduction.py")
repro = importlib.util.module_from_spec(spec)
spec.loader.exec_module(repro)
frozen = json.loads((p / "input.json").read_bytes())
result = json.loads((p / "result.json").read_bytes())
raw = (p / "outputs.jsonl").read_bytes()
assert hashlib.sha256((p / "input.json").read_bytes()).hexdigest() == result["input_sha256"]
assert hashlib.sha256(raw).hexdigest() == result["outputs_sha256"]
assert frozen["input_bank"] == repro.bank()
assert repro.evaluate_rows(frozen, [json.loads(line) for line in raw.splitlines()]) == result["counts"]
assert result["admission_eligible"] is False and result["axes_promoted"] == 0
```
