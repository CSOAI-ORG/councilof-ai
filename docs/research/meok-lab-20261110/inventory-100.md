## Group-specific proposed tests

### Runtime and interfaces
Expose one bounded task with verified refusal/error semantics, without replacing the existing MEOK coordinator.

### Routing and improvement
Compare a frozen workflow or compatible model variant on episode-disjoint tasks; keep evaluator and authority unchanged.

### Evaluation and environments
Run a small fixed task slice with exact input/source pins, negative controls and explicit missingness; no leaderboard claim.

### Worlds and embodied systems
Predict a retained next-state observation in a headless synthetic environment; distinguish generated imagery from validated dynamics.

### Memory and ontology
Retrieve versioned facts from 100 synthetic compact records; test corrections, expiry, access boundaries and retrieval against a keyword comparator.

### Older and efficient methods
Test the specific mechanism on a small held-out process task, including full wall-time and memory; do not infer foundation-model compatibility.

### Visual memory and content addressing
Roundtrip 1000 synthetic records, tamper one object, query a viewport and compare full-data bytes with index bytes; rendering is not canonical memory.

### Photonic numerical and design tools
Run a CPU numerical or electromagnetic fixture with known reference output; reserve hardware/energy advantage claims for actual device measurements.

### Quantum and tensor simulation
Run tiny circuits or tensor contractions with exact classical references, bounded qubits/shots and full timing; simulated circuits are not hardware speedups.

### Distribution and existing simulation reuse
Reuse existing services through pinned interfaces; distinguish open client/runtime code from separately paid hosted infrastructure and data rights.
