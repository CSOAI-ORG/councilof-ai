# Agent Action Evidence — measurable risks, observable effects and honest acceptance

**CSOAI candidate evidence product / 24 November 2026.** Existing Agent Authority & Evidence pilot, not a newly approved legal service, instant checkout, guarantee or independent certification.

## The buyer's problem

Agents can miss harmful instructions **and** wrongly refuse legitimate work. A model saying “approved” is not permission; an action transcript is not the receiving system's observed state; a hash is not an independently authenticated human. These are measurable, separate failures.
