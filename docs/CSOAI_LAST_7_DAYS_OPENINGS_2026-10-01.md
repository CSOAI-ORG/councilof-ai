## Focused execution order

1. Source-pin and license-check OpenShell, OCSF and ACS. Produce a synthetic allowed/denied policy fixture and a **source-only** mapping to the existing HarnessEnvelope/GSPC evidence schema; never ingest secrets or unlicensed catalog data.
2. Add the four NIST delegation negative/positive cases to the shared one-job harness acceptance path. Re-run the same job via human UI and MCP, then A2A and agent UI, with one receipt and a clear not-measured state where an adapter is absent.
3. Keep the x402 offer narrow: paid named-question measurement and maintained claim, free public evidence and verification. Repair stale discovery metadata before any additional registry push. Cloudflare's closed US beta is a compatibility target, not today's UK distribution channel.
4. Feed only verified source-change records into claim maintenance and the private RAS opportunity index. Publish a claim or card only after admission, exact-byte public readback, and correction/withdrawal handling; no endorsement or compliance badge.
5. Keep the public A2A agent card machine-readable: test both a browser-like client and a standard Python HTTP client. The 1 Oct readback saw the same card at HTTP 200 for curl but Cloudflare 1010 for Python-urllib. A zone-level, GET-only Browser Integrity Check exception for the exact agent-card path is a candidate, but only through the authorized Cloudflare release owner and with post-change probes. Other protections must remain on.

## Competitor baseline outside the seven-day window

[Portkey's MIT-licensed gateway](https://github.com/Portkey-AI/gateway) already provides model routing, fallbacks and guardrails; its [Agent Gateway beta](https://portkey.ai/blog/agent-gateway/) adds governed agent endpoints, access control and tracing. These were announced earlier in 2026, **not** in the last seven days. Do not rebuild their generic gateway as the claimed moat. A pinned, locally tested open-source gateway could eventually carry calls beneath GSPC, while GSPC owns the independent admission, outcome comparison, correction and claim-maintenance semantics. The license of any chosen revision and the boundary between repository code and Portkey's hosted product must be checked before reuse.
