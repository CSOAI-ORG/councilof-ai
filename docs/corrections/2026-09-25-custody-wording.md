# Correction C-2026-0925-01: board-key custody wording said "3-party" and "2-of-3"; the shares are on one host

**Lane:** `publication-bus-20260925` (first payload). **Builds on:** `board-refreeze-20260925`
(`docs/corrections/2026-09-25-board-snapshot-refreeze.md`), which found the defect and corrected
the producer of the signed freeze. **Owner ruling, 2026-09-25:** "both". Correct the wording now,
and do the real 2-of-3 split at the owner's physical Layer 0 root ceremony.

## The truth, stated once

- **2026-09-02 freeze key `did:web:csoai.org#gspc-board-22axis-2026`.** The key was produced by
  the Coinbase cb-mpc signing protocol. All three additive shares are files in **one directory on
  one host**, and one process uses them. That is one failure domain. The share split was **never
  performed**. That the helper never assembles a whole private scalar is its design claim, and it
  has not been audited.
- **Current board freeze `public/signed/gspc-board.2026-09-25.signed.json`.** It is signed by
  **one key**, `did:web:csoai.org#board-attestation-1`. The key is held as the Cloudflare Pages
  secret `BOARD_SIGN_KEY_PKCS8_B64` and used only inside `POST /api/board-sign`. It is not MPC
  and not threshold.
- **Planned, not performed:** a real 2-of-3 split at the owner's physical root ceremony. Until
  that ceremony is performed and recorded, no surface may describe a board key as split,
  "3-party" or "2-of-3" held.

## The guard that keeps it corrected

`scripts/custody-wording-guard.mjs` (test: `scripts/custody-wording-guard.node-test.mjs`). It
scans `functions/`, `client/src/`, `public/`, `council-os/` and `scripts/`. It fails on
"3-party", "three-party", "2-of-3", "3-of-3" or "threshold key/custody/Ed25519/signing" unless
one of the following holds:

- correction or planning context appears within 400 characters of the match;
- the file is pinned signed bytes whose correction document exists;
- `council-os/custody-ceremonies.json` records a **PERFORMED** ceremony with shares in two or
  more custody domains, and a record file that exists.

When the root ceremony is performed, add it to that registry with its record. The guard then
allows the wording, because the wording is then true. Add a new dated corrections entry that
supersedes this one.
