# ORB-III historical result: dated scientific-validity correction

**23 November 2026** · CSOAI Council of AI · Source issue [#4737](https://github.com/CSOAI-ORG/councilof-ai/issues/4737).

The HITL Academy ORB-III frozen module previously used **32/32 (100%; McNemar p=9.54e-7)** as if a source-specific 3-around-1 workflow established perfect independent council accuracy. The 26 October 2026 source actually combined **20 constructed ledger queries** with **12 local Ollama items**. The model-only synthesiser answered **9/12**, while the deterministic centre referee returned **12/12**; the latter's metadata directly held the correct answer choice on **12/12** tasks.

A read-only, deterministic counterfactual using the original extracted referee function gave **12/12** correct even when every model seat was forced wrong, and **0/12** once the answer-bearing metadata was removed. The original result signature verifies with the key stored inside the original result; this is internal byte consistency, not independent signer authentication or a blinded benchmark. The original p-value does not cure this design flaw.

**Interpretation corrected:** a rule-execution example, **not** independent blinded AI council accuracy, certified safe behaviour, real Byzantine fault tolerance, external human approval, or end-user impact. Historical signed research data and the frozen Academy `train.jsonl` must remain intact.

**Human authority qualified:** Academy completion and XP may set a learning gate but do not prove a reviewer's identity, appointment, informed consent, competence, current authorisation, decision legitimacy or downstream permitted effect. These need the separate authority and recipient-verification path.

**Publication process:** update only the existing [Hugging Face ORB-III README](https://huggingface.co/datasets/csoai/hitl-academy-orb3) via an exact-reviewable notice on protected GitHub master. The publication job reads the existing live README at its immutable HF revision, edits only the card, runs the monorepo publication/privacy gate on exact outgoing bytes, uses `parent_commit` as a compare-and-swap fence, then reads back the new card from the returned HF commit SHA and checks byte identity. Never use arbitrary user URLs or alter the frozen dataset.

**Scientific replacement:** an independently held novel bank, assessor-blinded source-validity rules, no answer option in referee metadata, time/route/weight custody, matched no-referee and evidence-referee arms, autonomous vote controls, independent human reviewer and external outcome records.

Authoritative code and raw signed history are preserved in the [Council research audit](https://github.com/CSOAI-ORG/councilof-ai/blob/master/measurement/experiments/two-path-council/HISTORICAL-3AROUND1-AUDIT-2026-11-23.md). Neither a dataset-card revision nor this notice creates a new GSPC `MEASURED` result.
