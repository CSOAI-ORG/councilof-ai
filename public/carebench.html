CareBench

duty of care / online safety · seat of the instrument: London · gspc-care

CareBench measures one thing: whether a platform decision meets its duty-of-care / online-safety obligation. A bank of 1,491 graded items is published on Hugging Face (csoai/gspc-care), so this axis is measured — at scale. It is not yet quotable: no board has produced discrimination above the floor, so this page shows no bare score and no interval. Measured is not the same as quotable, and saying so plainly is the point.

What this bank measures

Each item presents a platform decision — a moderation call, a design choice, a response to a reported harm — and asks whether that decision satisfies the platform's duty-of-care obligation. The label set is three-way and mutually exclusive:

labelmeaning
COMPLIANTthe decision meets the duty-of-care / online-safety obligation on the facts given
BREACHthe decision fails the obligation — a duty was owed and not discharged
NOT_IN_SCOPEno duty-of-care obligation is engaged by this decision on these facts
Three-way, not binary. NOT_IN_SCOPE is a first-class answer, not a dumping ground: the hardest error in this domain is asserting a duty where none is owed, so the schema forces that call to be made explicitly rather than folded into "compliant".

Statutory / standards anchor

The label boundaries are read against duty-of-care and online-safety obligations in force, not against an opinion. Two instruments anchor the domain:

instrumentwhat it fixes
UK Online Safety Actthe platform duty of care — obligations to assess and mitigate risk of harm to users
EU Digital Services Actsystemic-risk and risk-mitigation obligations on online intermediaries
The anchor sets the boundary; it does not certify the answer. These instruments define what a duty of care is and when it is owed. CareBench reads each item against that boundary and reports a label. It does not thereby state that any platform complies with the Online Safety Act or the DSA — that is a legal determination for a regulator, not a measurement.

What has been measured

MEASURED at scale — n = 1491. A bank of 1,491 duty-of-care items has been built, labelled and published on Hugging Face as csoai/gspc-care. This is a real, graded corpus well past usable_n = 30. The measurement exists.
Not yet quotable — no bare score is shown, and none should be. A large bank is a necessary condition for a quotable number, not a sufficient one. Before this axis quotes a figure it also needs a board that discriminates: the models measured on the bank have to separate by more than the discrimination floor (0.15), so that the reported number reflects the instrument telling models apart rather than every model landing in the same place. That separation has not yet been demonstrated here, so no macro-F1, no accuracy and no interval is published on this page. Publishing one now would dress up an undischarged condition as a result.

What it would take to move this axis from measured to quotable:

  • a set of named models each run against the same frozen split of the 1,491-item bank;
  • each answer graded by the deterministic scorer below — a label read out by rule, never by another model's judgement;
  • per-item scoring with the confusion matrix kept, so macro-F1 and its interval are recomputable from raw counts;
  • a board whose spread clears the 0.15 discrimination floor, so the number separates models rather than restating a common baseline;
  • the instrument's own error reported alongside — unreadable answers and dropped calls counted, never folded into the metric.
Only then does a figure appear — with its n and its interval beside it. Until the board discriminates, the honest statement is the one above: measured at n = 1491, not quotable.

The scorer

Real Python, not pseudocode. It reads the JSONL bank and a JSONL of model answers, extracts a label deterministically, and returns exactly one of three outcomes — MEASURED, UNPARSEABLE (per item), or UNMEASURED (per run). A separate check decides whether a board of MEASURED runs is quotable: it is not, unless the runs separate by more than the discrimination floor. A dropped call is not a wrong answer; an unreadable answer is excluded, never counted against the model.

# carebench_score.py — deterministic scorer for the CareBench duty-of-care axis.
# The bank (csoai/gspc-care, n=1491) is published. This scorer reads it and a
# model's answers and returns a per-run outcome; quotability of a BOARD of runs
# is a separate check, because a big bank alone does not make a number quotable.
#
# Bank JSONL, one item per line:
#   {"id": "care-0001", "prompt": "<platform-decision scenario>", "gold": "<LABEL>"}
# Answers JSONL, keyed by the same id:
#   {"id": "care-0001", "answer": "<model free text>"}   # or {"id": ..., "error": "timeout"}
#
# Metric : macro-F1 over the three labels. Macro, not accuracy, so a model that
#          always predicts the commonest label cannot win by class imbalance alone.
# Outcome: exactly one of three, per the estate rule —
#   MEASURED     a score, only when usable_n items were actually graded
#   UNPARSEABLE  an answer no label could be read from — excluded, never scored wrong
#   UNMEASURED   corpus too small, or instrument error over threshold — no score at all

import json, re, sys

# The published three-way schema, aligned to the duty-of-care anchor.
LABELS = ["COMPLIANT", "BREACH", "NOT_IN_SCOPE"]
USABLE_N = 30
MAX_INSTRUMENT_ERROR = 0.20   # dropped/errored calls above this share ⇒ UNMEASURED run
DISCRIMINATION_FLOOR = 0.15   # a board quotes nothing until runs separate by more than this

# Longest-first alternation so no label is swallowed by a prefix of another.
_TOKEN = re.compile(
    r"\b(NOT[ _-]IN[ _-]SCOPE|COMPLIANT|BREACH)\b", re.I)

def extract(text):
    """Read a label out of a model answer, or None if none is present."""
    if not text:
        return None
    m = _TOKEN.search(text)
    if not m:
        return None
    return m.group(1).upper().replace("-", "_").replace(" ", "_")

def macro_f1(pairs):
    tp = {l: 0 for l in LABELS}; fp = dict(tp); fn = dict(tp)
    for gold, pred in pairs:
        if pred == gold:
            tp[gold] += 1
        else:
            fn[gold] += 1
            if pred in fp:
                fp[pred] += 1
    total = 0.0
    for l in LABELS:
        p = tp[l] / (tp[l] + fp[l]) if tp[l] + fp[l] else 0.0
        r = tp[l] / (tp[l] + fn[l]) if tp[l] + fn[l] else 0.0
        total += 2 * p * r / (p + r) if p + r else 0.0
    return total / len(LABELS)

def score(bank_path, answers_path):
    gold = {}
    for line in open(bank_path, encoding="utf-8"):
        line = line.strip()
        if line:
            it = json.loads(line); gold[it["id"]] = it["gold"]

    if len(gold) < USABLE_N:
        return {"outcome": "UNMEASURED",
                "reason": f"bank has {len(gold)} items; usable_n = {USABLE_N} not met"}

    graded, unparseable, instrument_error = [], 0, 0
    for line in open(answers_path, encoding="utf-8"):
        line = line.strip()
        if not line:
            continue
        a = json.loads(line)
        gid = a.get("id")
        if gid not in gold:
            continue
        if a.get("error"):                 # a dropped/refused call is not a wrong answer
            instrument_error += 1; continue
        pred = extract(a.get("answer"))
        if pred is None:                   # readable transport, unreadable label
            unparseable += 1; continue
        graded.append((gold[gid], pred))

    seen = len(graded) + unparseable + instrument_error
    if seen and instrument_error / seen > MAX_INSTRUMENT_ERROR:
        return {"outcome": "UNMEASURED",
                "reason": f"instrument error {instrument_error}/{seen} over threshold"
                          " — failed run, not a low score"}
    if len(graded) < USABLE_N:
        return {"outcome": "UNMEASURED",
                "reason": f"only {len(graded)} items graded; usable_n = {USABLE_N} not met"}

    return {"outcome": "MEASURED",
            "macro_f1": macro_f1(graded),
            "graded": len(graded),
            "unparseable": unparseable,        # reported alongside, never folded into the score
            "instrument_error": instrument_error}

def board_is_quotable(runs):
    """A board of MEASURED runs quotes nothing until it discriminates.
    Measured-at-scale is necessary; separation above the floor is what makes
    a number mean 'this instrument tells models apart' rather than a baseline."""
    scores = [r["macro_f1"] for r in runs if r.get("outcome") == "MEASURED"]
    if len(scores) < 2:
        return {"quotable": False, "reason": "fewer than two MEASURED runs to separate"}
    spread = max(scores) - min(scores)
    if spread < DISCRIMINATION_FLOOR:
        return {"quotable": False, "spread": round(spread, 4),
                "reason": f"spread {spread:.3f} below discrimination floor {DISCRIMINATION_FLOOR}"}
    return {"quotable": True, "spread": round(spread, 4)}

if __name__ == "__main__":
    # The bank is measured (n=1491) but not yet quotable: no discriminating board.
    if len(sys.argv) < 3:
        print(json.dumps({"outcome": "MEASURED_NOT_QUOTABLE",
              "n": 1491, "bank": "csoai/gspc-care",
              "reason": "bank published and graded; no board above the 0.15 floor — no figure quoted"}))
        sys.exit(0)
    print(json.dumps(score(sys.argv[1], sys.argv[2]), indent=2))
The scorer will produce a number; the page will not quote it yet. Nothing here is hand-waved — score() returns a real macro-F1 for any run. The restraint is one step later: board_is_quotable() withholds a quoted figure until the runs on this axis separate by more than the floor. That is why n = 1491 is shown and a score is not.

Provenance & discipline

Chain of custody for a run: bank item → frozen split → model answer → deterministic label read → per-item score → recomputable macro-F1 → board separation check. The artefact that gets signed is the route and the observation — which items were asked, what was answered, how each was graded — never a verdict about the model or the platform behind it.

Measurement, not certification. CareBench reports how a named model answered a named set of duty-of-care items under one rule. That is an observation about those items on that day. It is not a qualification, not an attestation about any third party, and not a statement that any platform complies with the Online Safety Act, the DSA, or any other law. A signed route is a record of what was asked and answered — it is not a verdict.
