## Card schema (Regulatory-Exposure fields; no conclusion)

Each card nests `payload.regulatory_exposure` with:

- `obligation` — voluntary GPAI Code of Practice
- `binds` — voluntary signatories (not a mandatory signature duty)
- `fine_ceiling` — `N/A (voluntary)`
- `enforcer` — `N/A for the code itself`
- `measured_fact` — `{what, when, how, url, sha256}` of the retrieved Commission page
- `UNMEASURED[]` — explicit
- `status` — `DISCOVERED` (list appearance); never `MEASURED` as compliance
