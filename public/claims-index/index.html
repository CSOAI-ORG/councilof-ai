What the axes mean

  • Claim specificity: 2 = named benchmarks with numeric scores as text on the model card; 1 = numbers only as images or in a linked report; 0 = none found.
  • Reproducibility: 2 = public weights and the evaluation settings (shots, harness or metric) for the published numbers; 1 = public weights only; 0 = neither.
  • Disclosure: 2 = training-data size or composition and a limitations section on the card; 1 = one of the two; 0 = neither.
  • Claim vs evidence: scored only where a vendor claim is comparable to one of our signed cells, with agreement judged inside the Wilson 95% interval. In v0 no published vendor claim is comparable to a signed cell, so every row is untested.
  • Correction record: 2 = a dated public correction of a published figure or claim; 1 = a dated public fix to a released artifact (config, template, readme); 0 = none found in the model card and its public commit titles.

Method, sources and how to reproduce or challenge a score: METHOD.md. Open data: JSON · CSV. Verify any card: /gspc-verify. Corrections: corrections ledger · open an issue.
