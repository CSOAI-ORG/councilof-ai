What this checks 
1. Card kind = gspc.measurement-card
2. Recompute id = sha256(canonical_json(body))
3. Card id matches the recomputed id
4. Fetch /.well-known/did.json → pick #card-attestation-1 (or #board-attestation-1)
5. Verify Ed25519 signature under the pinned public key
6. Report verdict + reason + key used

A card that is internally consistent but signed with a freshly
generated key is INVALID — the signature must be under the
councilof.ai pinned key, not a self-keyed one.
