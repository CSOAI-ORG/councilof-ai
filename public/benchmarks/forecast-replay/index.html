Research example

Did a pull request merge within one hour of opening? Twelve consecutive public pull requests, #4976–4987, were scored retrospectively. A local Qwen model saw the retrieved title only. Titles can change after opening. The reference assigns 50% to every case.

How scoring works

The Brier score averages (probability − outcome)². Zero is perfect. Both forecasts use the same cases with complete predictions and outcomes. Missing values are reported separately. The sample measures this one workflow. Its outcomes were already public when the model ran.
