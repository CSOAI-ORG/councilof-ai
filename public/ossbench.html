OSSBench

openness · anchor: FSF Free Software Definition and OSI Open Source Definition · the licence texts

Does the licence permit this use? OSSBench puts a described use of an open-source software artefact — modify, redistribute, run as a hosted service, relicense, combine with proprietary code — to a model and asks a single binary question: is that use PERMITTED by the licence, or RESTRICTED by it? Graded deterministically — a regex reads the label and the result is scored by macro-F1. No model judges another model. The bank is built and answered at n = 32; it is measured, and it is not yet quotable.

The anchor

The gold labels are sourced to the licence texts themselves and to the standing positions of the two bodies that define the terms:
· the Free Software Foundation — the Free Software Definition and the FSF's published licence classifications and copyleft analysis;
· the Open Source Initiative — the Open Source Definition and the OSI-approved licence list.
Each item's label is the answer the licence text gives, read against those two definitions — not a policy preference and not a vibe. Where a licence's own text is decisive (a permission grant, a copyleft trigger, a field-of-use restriction), that clause is the source.
Anchored to named definitions and licence text, not to invented section numbers. Where the reading is genuinely contested between sources, the item is held out of the bank rather than labelled by guess. Nothing here is legal advice.

Measured, but not quotable — so no number is shown. The bank exists, it is published, and models have answered it: that is what MEASURED means here, and it is why this page is no longer marked empty. But no board has yet separated the models on this axis by more than the estate's 0.15 discrimination floor — below that floor a lead is noise, not a finding, and the rule is that we publish no score and no interval until a clean discriminating board exists. So there is deliberately no macro-F1 and no confidence interval on this page. Printing one at n = 32 with the models still bunched inside the floor would be exactly the false separation the discipline forbids.
Why the floor bites here. A binary PERMITTED / RESTRICTED question is easy to score highly on by pattern-matching licence names, so the models cluster near the top and the spread between them stays inside 0.15. The bank is real; the ranking it would produce is not yet defensible. The fix is a harder, more discriminating board — v2 — not a bigger claim on this one.

What v2 sharpens

The n = 32 bank tests whether a use is permitted. v2 moves from naming licences to reasoning about their triggers — the cases where the answer turns on a clause, not a licence label. It is being built precisely to break the ceiling that keeps this axis inside the discrimination floor. It is not yet quotable either.

  • · the AGPL network trigger — a use that is fine under GPL becomes a distribution event under AGPL the moment the software is offered over a network.
  • · the service / commons clauses — SSPL, Elastic License v2, and Business Source License restrict offering the software as a managed service; each restricts differently, and none is OSI-approved.
  • · RAIL and other use-restriction licences — behavioural field-of-use limits that make an otherwise-open artefact RESTRICTED for a named class of use.

The scorer — how it grades

A runnable skeleton, not pseudocode. It reads the bank, reads the answers, and resolves every item to exactly one of three outcomes. Macro-F1 over the two labels is the metric — plain accuracy would reward always answering the commoner label, which is useless when the whole point is telling a permission from a restriction.

#!/usr/bin/env python3
# ossbench_score.py — deterministic scorer for OSSBench.
# Field: open-source licence permission · anchor: FSF Free Software Definition,
#        OSI Open Source Definition, and the licence texts. Bank: csoai/gspc-oss.
#
# THREE OUTCOMES, never two. Each item resolves to exactly one of:
#   MEASURED    — an answer parsed to a label and was compared to gold.
#   UNPARSEABLE — an answer arrived but no label could be read from it.
#                 Reported, excluded from the score, NEVER counted as wrong.
#   UNMEASURED  — no answer arrived (harness/transport error), or no bank
#                 exists at all. Instrument error, not model error — never a 0.
import json, re, sys, pathlib

USABLE_N = 30
DISCRIMINATION_FLOOR = 0.15   # no board is quoted until it separates by more than this
LABELS = ["PERMITTED", "RESTRICTED"]
# PERMITTED  — the licence, read against the FSF/OSI definitions, allows the described use.
# RESTRICTED — the licence text restricts the described use (copyleft trigger, service
#              clause, field-of-use limit, or withheld permission).

# Word-boundary match; space / underscore / hyphen all read the same label.
TOKEN = re.compile(r"\b(PERMITTED|RESTRICTED)\b", re.IGNORECASE)

def extract(text):
    # Returns a canonical label, or None if the answer cannot be read.
    if not text:
        return None
    m = TOKEN.search(text)
    if not m:
        return None
    c = m.group(1).upper()
    return c if c in LABELS else None

def macro_f1(pairs):
    # pairs is a list of (gold, pred) over MEASURED items only.
    tp = {l: 0 for l in LABELS}; fp = dict(tp); fn = dict(tp)
    for g, pr in pairs:
        if pr == g: tp[g] += 1
        else: fn[g] += 1; fp[pr] = fp.get(pr, 0) + 1
    total = 0.0
    for l in LABELS:
        p = tp[l] / (tp[l] + fp[l]) if tp[l] + fp[l] else 0.0
        r = tp[l] / (tp[l] + fn[l]) if tp[l] + fn[l] else 0.0
        total += 2 * p * r / (p + r) if p + r else 0.0
    return total / len(LABELS)

def main():
    bank    = pathlib.Path(sys.argv[1]) if len(sys.argv) > 1 else pathlib.Path("ossbench.jsonl")
    answers = pathlib.Path(sys.argv[2]) if len(sys.argv) > 2 else None

    # No bank or no answers → UNMEASURED. Print it and stop. Do not invent a run.
    if not bank.exists() or answers is None or not answers.exists():
        print("OSSBench: UNMEASURED — no bank / no answers. No score is defined.")
        return

    gold = {j["id"]: j["gold"] for j in map(json.loads, bank.open())}
    ans  = {j["id"]: j for j in map(json.loads, answers.open())}

    measured, unparseable, unmeasured = [], 0, 0
    for _id, g in gold.items():
        a = ans.get(_id)
        if a is None or a.get("error"):
            unmeasured += 1            # transport / harness failure — NOT a wrong answer
            continue
        pred = extract(a.get("answer"))
        if pred is None:
            unparseable += 1          # answer unreadable — excluded, NOT scored as wrong
            continue
        measured.append((g, pred))

    n = len(measured)
    err_rate = unmeasured / max(1, len(gold))
    if n == 0:
        print(f"OSSBench: UNMEASURED — 0 items scored; instrument error on {err_rate:.0%}.")
        return

    f1 = macro_f1(measured)
    # The instrument's own error prints NEXT TO the figure, every time.
    print(f"OSSBench: n={n}  macro-F1={f1:.4f}  "
          f"unparseable={unparseable}  instrument_error={err_rate:.0%}")
    # Two gates before a number becomes quotable: usable n AND a board that
    # actually separates. A single model's F1 is a measurement; it is not a
    # ranking, and this axis is not published as one until the spread clears the floor.
    if n < USABLE_N:
        print(f"  not quotable: n={n} < usable_n={USABLE_N}; no interval published.")
    else:
        print(f"  n clears usable_n; still not quotable until a board separates "
              f"by > {DISCRIMINATION_FLOOR} macro-F1. No ranking published below the floor.")

if __name__ == "__main__":
    main()

What the signed artefact is — and is not

Provenance chain: anchor (FSF/OSI definitions + licence text) → bank item → model answer → regex label read → macro-F1 → signed run record. What CSOAI signs is the route and the observation — these items, this model, this answer, graded by this rule, with the instrument's error printed beside it. The signature attests that the measurement happened as recorded; it is a signed route, not a verdict. It is never a ruling on what any licence permits, never legal advice, and never a certificate of anything. This is measurement, not certification. And because the axis sits below the discrimination floor, no ranking and no score is published from it yet — a measured bank is not a quotable board.
