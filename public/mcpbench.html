MCPBench

conformance · seat of the instrument: Seattle · Model Context Protocol — declared-vs-actual tool behaviour

MCPBench measures one narrow, decidable thing: does a tool behave the way its own declared contract says it will? An MCP server advertises a contract — a set of tools, each with a declared input schema, a declared result shape, and the capabilities it negotiated at initialize. The bench captures an exchange and asks whether the actual behaviour matched that declaration. Two labels only: CONFORMS or VIOLATES. The verdict is machine-decidable, so the ground truth is computed by a checker, not judged by a panel or by another model.

This axis is MEASURED. A labelled bank of 35 items exists and is published on Hugging Face, and models have been run against it. It is not yet quotable, and this page says so plainly and shows no number.

MEASURED is not the same as quotable. The bank clears usable_n = 30 (n = 35), so the sample-size gate is met. It fails the second gate: the board does not separate the models. Observed discrimination between runs is marginal — around 0.18, only just past the 0.15 discrimination floor — which is not a clean separation. Under the estate's own rule, a lead that narrow is reported as a lead, never as a result. So no macro-F1 point estimate and no interval is published on this axis, and none is shown below. The bank stands; the board does not yet.

Why the anchor is the MCP specification and not a statute. This is a protocol-conformance lane, not a regulatory one. The contract a tool must honour is the one it declared under the Model Context Protocol; the transport base — JSON-RPC 2.0 — is stable and cited directly, while the MCP-specific provisions are pinned to a single named specification revision so that a VIOLATES verdict names the exact rule and the exact revision it was written against. No clause is cited without its revision.

The deterministic scorer

This is the rule the bank is scored by. It is a real skeleton, not pseudocode: the two-class label set, one regex extraction, macro-F1 over the two conformance classes, and the three-outcome discipline — an item is MEASURED, an answer that cannot be read is UNPARSEABLE and excluded, and a run whose instrument error exceeds threshold is UNMEASURED. A lane error is never folded into a zero. Quotability is a separate, stricter gate below the score.

#!/usr/bin/env python3
# mcpbench_score.py — deterministic declared-vs-actual conformance scorer for the
# Model Context Protocol lane.
# Input: JSONL, one item per line:
#   {"id": "m07", "transcript": [ ...JSON-RPC 2.0 messages... ],
#    "declared": { ...the contract the server advertised... }, "gold": "VIOLATES"}
# The gold verdict is produced by a validator comparing the transcript to the declared
# contract — that is what makes this lane deterministic. A model is scored on how well
# its own verdict matches that machine-decidable label.
import json, re, sys

# Two conformance classes: the behaviour honoured the declared contract, or it did not.
LABELS = ["CONFORMS", "VIOLATES"]

# Longest-first alternation is unnecessary with two disjoint tokens, but the word
# boundaries still stop CONFORMS matching inside e.g. "nonconformant".
TOKEN = re.compile(r"\b(CONFORMS|VIOLATES)\b", re.I)

# Runs whose instrument error rate (dropped transports, timeouts) exceeds this
# are reported UNMEASURED, never scored as a low number.
INSTRUMENT_ERROR_THRESHOLD = 0.20
USABLE_N = 30
# Second gate: below this board separation the axis is measured but NOT quotable.
# A number that cannot separate the models is a lead, not a result.
DISCRIMINATION_FLOOR = 0.15


def extract(text):
    """Read one label out of a model's answer, or None if none is present."""
    if not text:
        return None
    m = TOKEN.search(text)
    if not m:
        return None
    c = m.group(1).upper()
    return c if c in LABELS else None


def macro_f1(pairs):
    """Macro-F1 over LABELS. Unreadable predictions are already excluded before this."""
    tp = {l: 0 for l in LABELS}
    fp = {l: 0 for l in LABELS}
    fn = {l: 0 for l in LABELS}
    for gold, pred in pairs:
        if pred == gold:
            tp[gold] += 1
        else:
            fn[gold] += 1
            if pred in fp:
                fp[pred] += 1
    total = 0.0
    for l in LABELS:
        p = tp[l] / (tp[l] + fp[l]) if (tp[l] + fp[l]) else 0.0
        r = tp[l] / (tp[l] + fn[l]) if (tp[l] + fn[l]) else 0.0
        total += (2 * p * r / (p + r)) if (p + r) else 0.0
    return total / len(LABELS)


def score(items, answers):
    """Three outcomes — MEASURED, MEASURED with UNPARSEABLE answers shown, or
    UNMEASURED — never a wrong-answer zero for a lane failure. Quotability is
    computed separately in board() from the spread across runs, not here."""
    errored = sum(1 for a in answers if a.get("instrument_error"))
    if answers and errored / len(answers) > INSTRUMENT_ERROR_THRESHOLD:
        # The instrument failed, so there is nothing to say about the model.
        return {"status": "UNMEASURED",
                "reason": f"instrument error {errored}/{len(answers)} exceeds threshold"}

    gold = {it["id"]: it["gold"] for it in items}
    pairs, unparseable = [], 0
    for a in answers:
        if a.get("instrument_error"):
            continue                       # a dropped transport is not a wrong answer
        pred = extract(a.get("text"))
        if pred is None:
            unparseable += 1                # UNPARSEABLE: excluded, never scored as wrong
            continue
        pairs.append((gold[a["id"]], pred))

    n = len(pairs)
    return {"status": "MEASURED", "n": n, "unparseable": unparseable,
            "macro_f1": round(macro_f1(pairs), 4) if n else None}


def board(runs):
    """A board is quotable only if it clears BOTH gates: usable_n on every run AND a
    separation between the best and worst run above the discrimination floor. n=35 clears
    the first; a spread this narrow does not clear the second, so the axis is held."""
    scored = [r for r in runs if r.get("status") == "MEASURED" and r.get("macro_f1") is not None]
    if not scored:
        return {"quotable": False, "reason": "no scored run"}
    f1s = [r["macro_f1"] for r in scored]
    spread = max(f1s) - min(f1s)
    n_ok = all(r["n"] >= USABLE_N for r in scored)
    quotable = n_ok and spread >= DISCRIMINATION_FLOOR
    return {"quotable": quotable, "n_ok": n_ok, "discrimination": round(spread, 4),
            "reason": ("quotable" if quotable
                       else f"discrimination {spread:.3f} below floor {DISCRIMINATION_FLOOR}")}


if __name__ == "__main__":
    items   = [json.loads(l) for l in open(sys.argv[1]) if l.strip()]
    answers = [json.loads(l) for l in open(sys.argv[2]) if l.strip()]
    run = score(items, answers)
    print(json.dumps(run, indent=2))

Deterministic means the gold is computed, not opinioned. Each item pairs a captured exchange with the contract the server declared, and the checker decides CONFORMS or VIOLATES by comparison: was initialize completed and the capability negotiated before the tool was used, did every response carry "jsonrpc":"2.0" and correlate its id, did the tool or resource result match the declared schema. A model is then scored against that machine-decided label. No model judges another model.

The chain

The estate measures each measure along one chain of artefacts — items, a licensed card, a Space, a runnable Space, a Kaggle mirror, a page, a runnable page, an lm-eval task, an Inspect task, and finally a measurement against a named model. MCPBench has cleared the hard part — a bank exists and models have been scored on it — but the decisive quotability link is open:

  • ● this page exists on the site
  • ● the scorer above is written and deterministic
  • ● labelled bank published and loadable (csoai/gspc-mcp, n=35)
  • ● measured against models — MEASURED
  • ○ a clean discriminating board (separation ≥ floor)
  • ○ a quotable result — a defended number with its interval

A bank that has been measured but cannot separate the models is a measurement without a ranking. The final link — a board whose spread clears the discrimination floor cleanly — is the one that turns MEASURED into a quotable figure, and it is open. Until it closes, this bench reads MEASURED and carries no score and no interval.

Provenance and discipline

Chain of custody: frozen bank revision → transcript hash → declared contract → scorer version → per-item verdict → aggregate, each step signed so the observation can be reproduced. The signed artefact is the route and the observation — the transcript that was seen, the contract it was measured against, and the label the checker read from the two. It is never a verdict about the third party whose implementation produced the transcript.

Measurement, not certification. A conformance verdict here is a statement about one captured exchange under one named specification revision — that this transcript did or did not honour the contract the server declared. It is not a statement that a server, a client, or a model conforms in general, and it is not a statement of conformity with any standard. It is an observation, signed so it can be checked, and it stops there. A signed route is not a verdict.
