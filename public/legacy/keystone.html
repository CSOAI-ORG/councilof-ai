Keystone

One sovereign source of truth for secrets. Built to end the recurring key leak / re-paste blocker.

What It Is

Keystone is a CLI that reads all secrets from GCP Secret Manager and mirrors them to macOS Keychain for offline sovereignty. Secrets never touch disk, git, argv, or shell history. One canonical store, injected as environment variables at runtime. No more 53 scattered .env files.

8 Commands

keystone list

List every secret (GCP) + offline-mirror status

keystone get NAME

Print a secret to stdout (Keychain first, GCP fallback). Shows length only, never value.

keystone set NAME

Read value from STDIN → store in GCP + Keychain. Usage: pbpaste | keystone set STRIPE_SECRET_KEY

keystone run [N1,N2,..] -- CMD

Run CMD with secrets injected as env vars. Replaces .env files entirely.

keystone sync-vercel PROJ N1 N2..

Push named secrets to a Vercel project's prod env. Kills the manual re-paste blocker.

keystone mirror

Pull ALL GCP secrets into macOS Keychain (offline/sovereign mode).

keystone rotate NAME

Set a new value (stdin) + re-sync everywhere.

keystone install-guard

Install a global git pre-commit secret-scanner. Prevents the next public-key leak.

Sovereign Architecture

GCP Secret Manager (canonical) ↔ macOS Keychain (offline mirror) → Runtime injection (env, never disk). A global pre-commit hook scans every commit for real-length API keys and blocks the commit if detected. The incident that exposed 5 keys on GitHub cannot happen again.
