Claim Maintenance v0.2 conformance corpus

This is a deterministic interoperability corpus for the published v0.2 verifier rules. It is not certification, a badge, score, ranking or mark of approval.

The corpus pins the v0.2 document and reference implementation by SHA-256. Each fixture also carries its own SHA-256 in manifest.json.

Run it

node runner.mjs

The runner verifies fixture bytes and reproduces the expected PASS/FAIL result with the published v0.2 reference verifier.
