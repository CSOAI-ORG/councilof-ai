A dated reading of the claim-maintenance register. Every number on this page is read from the exact register bytes named below — nothing is derived, interpolated or estimated.

What this is

A dated reading of the claim-maintenance register, published so the register's own state can be read without running the register and without trusting this page. It is reproducible: the sha256 of the register bytes is given, and the report's JSON carries it too.

What this is not

  • Not a certification, a rank, a grade or a score.
  • Not a statement that the claim-maintenance axis is MEASURED. The axis carries its own status; this report neither moves it nor pre-empts the decision that moves it.
  • Not a claim that any individual captured claim is true. It reports how many claims the register holds and in which states the register places them.
  • Not a measurement of any model, system or vendor.
