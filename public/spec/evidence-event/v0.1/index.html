Evidence event v0.1

csoai.evidence-event/0.1 records an observation derived from an existing record: what was declared, what was observed, the resulting evidence state and the limits of the read.

Download the JSON Schema · Read the source and usage guide

Contract and validation

The schema describes the event fields. Use the existing event validator for additional rules, including event-ID recomputation and negative-control agreement. Schema validation alone does not perform those checks.
