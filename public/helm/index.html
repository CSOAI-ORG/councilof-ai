Helm chart repository

Charts for running GSPC evidence verification in Kubernetes and OpenShift. Apache-2.0. The machine-readable index is index.yaml; each chart's sha256 digest is recorded there.

helm repo add csoai https://councilof.ai/helm/
helm repo update
helm search repo csoai

llama-stack-csoai-eval 0.1.0A Llama Stack server with the remote::csoai eval provider (llama-stack-provider-csoai). It verifies signed evidence batches offline against a pinned DID document and returns each event's state, never a score.
 
helm install csoai-evidence csoai/llama-stack-csoai-eval --set bundles.existingClaim=<pvc>

What has and has not been checked

Each chart is linted with helm lint --strict and rendered before it is published, and its container start command was run outside Kubernetes. No chart has been installed on a live cluster by us yet; that install is unmeasured. Charts are not signed with Helm provenance files yet. No official marketplace lists these charts.
