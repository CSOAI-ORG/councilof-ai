GSPC Benchmarks

A GSPC benchmark is a frozen bank plus one published grading rule. Every bank below is public, every hash is stated, and every one can be run on your own model with a single command. What you get back is a receipt you can check — never a rank, and never a certificate.

12 runnable banks

Banks with a sound answer menu. The rest are listed and refused, with the reason, rather than silently dropped.

23 measured axes

Of 33 declared slots. The gap is published, because a slot count alone would claim measurements that do not exist.

1 grading rule

Every bank is graded by the same deterministic function. No model judges another model.

Run a benchmark

git clone https://github.com/CSOAI-ORG/councilof-ai
cd councilof-ai
python3 harness/bench/run_bench.py --axis safety --model YOUR_MODEL --base-url YOUR_ENDPOINT --out my-result.json

The runner fetches the frozen bank, hashes it, builds the prompt from the bank's own label menu, grades every answer with the published rule, and writes a receipt carrying the bank sha256, every prompt sha256, and every raw answer. It produces a number for one model on one bank. It does not compare models and it does not rank.

Nothing here needs an account, a key, or our permission. The banks are on Hugging Face, the runner is MIT-licensed source, and the grading rule is imported from the same module the board uses. A third party can re-derive every number on this page from the published bytes.

Why some banks are refused. A bank whose answers reduce to one option produces a prompt that cannot be answered wrongly, so it measures format compliance rather than the axis. 26 cards were once signed MEASURED against exactly such a prompt. Those banks are listed here and refused, with the reason — the refusal is the result, not a failure.

Machine-readable

  • axes.json — one task spec per axis: bank URL, bank sha256, label menu, prompt template, grader, and how to run it.
  • leaderboard.json — the model×axis matrix with per-cell n and separation, including every UNMEASURED axis.
  • openai-eval.yaml — an OpenAI Evals task per axis, for a third party who wants to run a bank in a few lines.
  • submit.md — how to submit a run so it can be verified and published.

What this is not

GSPC measures; it does not certify, and it is not a notified body. A card is evidence of a run at a time, not a grade of a model, and not an endorsement of anything. The board states TIE where the test did not separate a leader, because a tie that is not a win is the honest answer. Read the methodology, and /api/gspc for the live board.
