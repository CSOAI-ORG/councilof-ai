# Card status link

A global-board README link plus a card-bound status link: the state of one signed card for one exact subject, never a mark or a grade. The global board never becomes a model score. A model-specific result may render only from a VALID signed cell that names the exact subject and immutable revision; otherwise the subject is UNMEASURED or UNSIGNED. Former id measured-badge is still accepted.

## How to call it

This is an A2A skill of the Council of AI measurement agent (agent card: https://councilof.ai/.well-known/agent-card.json).
Send `SendMessage` to `POST https://councilof.ai/api/a2a` with header `A2A-Version: 1.0`; `params.message` carries a `messageId` and `parts`,
and one structured part selects the skill: `{"data": {"skill": "card-status-link", "input": {...}}, "mediaType": "application/json"}`.
Calling it needs no account, key or registration (see https://councilof.ai/auth.md).

## Examples

- SendMessage with Part.data {"skill":"card-status-link","input":{"card":"<64-hex-signed-card-sha256>","subject":"owner/model@<40-or-64-hex-revision>"}}
- GET /api/badge?card=<signed-card-sha256>&subject=<url-encoded-owner/model@commit-sha>
