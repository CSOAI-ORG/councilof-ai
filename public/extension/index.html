GSPC Verify extension

Reads the living GSPC board and verifies supported signed-card bytes locally. Measurement, not certification.

Download gspc-verify-0.1.1.zip

This is a developer-mode ZIP, not a Chrome Web Store listing or an install count.

Install locally

  1. Download and unzip the file.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Choose Load unpacked and select the unzipped folder.
