PQCBench

post-quantum status of a crypto assumption · seat of the instrument: Gaithersburg · NIST FIPS 203/204/205 · RFC 8391/8554

The task: read a described cryptographic assumption and classify its post-quantum status — is the thing it relies on broken by a quantum adversary, safe against one, or not in scope. Graded deterministically: a regex extracts one label and the run is scored by macro-F1, with no model judging another model. This axis has been measured. The bank is published, the split is frozen, and named models have been scored against it on a named harness.

Standards anchor

The status classes are anchored to the finalised NIST post-quantum standards suite and to the two hash-based signature RFCs it references:

instrumentalgorithmrole
FIPS 203ML-KEM (Module-Lattice-Based Key-Encapsulation Mechanism)key establishment
FIPS 204ML-DSA (Module-Lattice-Based Digital Signature Algorithm)digital signature
FIPS 205SLH-DSA (Stateless Hash-Based Digital Signature Algorithm)digital signature
RFC 8391XMSS (eXtended Merkle Signature Scheme)stateful hash-based signature
RFC 8554LMS (Leighton–Micali Signatures)stateful hash-based signature

These five instruments and their algorithm mappings are cited as published. An assumption is scored against what these standards do and do not cover — a lattice or hash-based construction on the list is a different status from an RSA, ECC, or discrete-log assumption a quantum adversary breaks.

The label set

labelmeaning
QUANTUM_VULNERABLEthe assumption is broken by a quantum adversary — a Shor-breakable public-key assumption (RSA, ECC, ECDH, DH, DSA), or a symmetric/hash parameter reduced below adequate strength by a quantum search
QUANTUM_SAFEthe assumption is believed to hold against a quantum adversary — a lattice construction under FIPS 203/204, a hash-based signature under FIPS 205 / RFC 8391 / RFC 8554, or symmetric strength that remains adequate
NOT_APPLICABLEthe described asset makes no cryptographic assumption whose post-quantum status is in scope, so no status is asserted

The scorer — how this field is graded

This is the real grading rule, not pseudocode. It reads a frozen JSONL corpus and a model's answers, extracts one post-quantum status label per item, and returns one of three outcomes per item and for the run as a whole. It never folds a lane error into a zero.

#!/usr/bin/env python3
# pqcbench_score.py — deterministic grader for post-quantum status classification.
# Three outcomes, never two: MEASURED, UNPARSEABLE (per item), UNMEASURED (the lane).
# An answer that cannot be read into a label is excluded, never scored as wrong.
import json, re, sys
from math import sqrt

USABLE_N = 30
LABELS = ["QUANTUM_VULNERABLE",   # Shor-breakable public-key assumption, or symmetric strength cut below adequate
          "QUANTUM_SAFE",         # FIPS 203/204/205 or RFC 8391/8554 construction, or adequate symmetric strength
          "NOT_APPLICABLE"]        # no cryptographic assumption whose post-quantum status is in scope

# Corpus line:  {"id": "...", "prompt": "<described assumption>", "gold": "QUANTUM_VULNERABLE"}
# Answers line: {"id": "...", "answer": "<free-text model output>"}
# Longest-first alternation so QUANTUM_VULNERABLE cannot be swallowed by a shorter prefix.
TOKEN = re.compile(
    r"\b(QUANTUM[ _-]VULNERABLE|NOT[ _-]APPLICABLE|QUANTUM[ _-]SAFE)\b",
    re.I)

def extract(text):
    """One label, or None. None means UNPARSEABLE — it is not a wrong answer."""
    if not text: return None
    m = TOKEN.search(text)
    if not m: return None
    lab = m.group(1).upper().replace("-", "_").replace(" ", "_")
    return lab if lab in LABELS else None

def wilson(k, n, z=1.959963985):
    if not n: return None
    p, d = k / n, 1 + z*z/n
    c = (p + z*z/(2*n)) / d
    h = z * sqrt(p*(1-p)/n + z*z/(4*n*n)) / d
    return [round(max(0.0, c-h), 4), round(min(1.0, c+h), 4)]

def macro_f1(pairs):
    """pairs = [(gold, pred_or_None), ...]. Macro-F1, not accuracy: always guessing the
    commonest class must lose, so the metric is averaged over classes, not items."""
    tp = {l: 0 for l in LABELS}; fp = dict(tp); fn = dict(tp)
    for gold, pred in pairs:
        if pred is None: continue          # UNPARSEABLE: excluded, not counted against any class
        if pred == gold: tp[gold] += 1
        else: fn[gold] += 1; fp[pred] += 1
    tot = 0.0
    for l in LABELS:
        pr = tp[l]/(tp[l]+fp[l]) if tp[l]+fp[l] else 0.0
        rc = tp[l]/(tp[l]+fn[l]) if tp[l]+fn[l] else 0.0
        tot += (2*pr*rc/(pr+rc)) if pr+rc else 0.0
    return tot / len(LABELS)

def score(corpus_path, answers_path, model, harness):
    corpus = [json.loads(x) for x in open(corpus_path) if x.strip()]
    ans = {json.loads(x)["id"]: json.loads(x) for x in open(answers_path) if x.strip()}

    # INSTRUMENT ERROR is separated from model error before anything is scored.
    # A missing/errored answer row is a lane failure, never a wrong label.
    scorable, instrument_errors = [], 0
    for it in corpus:
        row = ans.get(it["id"])
        if row is None or row.get("error"): instrument_errors += 1; continue
        scorable.append((it["gold"], extract(row.get("answer"))))

    n = len(scorable)
    err_rate = instrument_errors / len(corpus) if corpus else 1.0

    # OUTCOME 1 — UNMEASURED: no corpus, too few items, or the instrument mostly failed.
    # Return a status, not a number. Do NOT emit macro-F1 = 0.0 here.
    if n == 0:
        return {"status": "UNMEASURED", "reason": "no scorable items", "n": 0}
    if err_rate > 0.5:
        return {"status": "UNMEASURED", "reason": "instrument error %.0f%% > threshold" % (err_rate*100),
                "n": n, "instrument_error_rate": round(err_rate, 4)}

    unparseable = sum(1 for _, p in scorable if p is None)
    correct = sum(1 for g, p in scorable if p == g)
    result = {
        "status": "MEASURED", "model": model, "harness": harness, "n": n,
        "macro_f1": round(macro_f1(scorable), 4),
        "accuracy": round(correct / n, 4),
        "unparseable": unparseable,                 # reported, excluded from the score
        "instrument_error_rate": round(err_rate, 4),  # reported alongside, not folded in
    }
    # OUTCOME 2 — quotable only at or above usable_n. An interval on accuracy is MANDATORY
    # at n >= 30 and FORBIDDEN below it: a bare figure at usable n is not shippable.
    result["quotable"] = n >= USABLE_N
    result["accuracy_ci95"] = wilson(correct, n) if n >= USABLE_N else None
    return result

if __name__ == "__main__":
    # python3 pqcbench_score.py corpus.jsonl answers.jsonl MODEL_NAME HARNESS_NAME
    print(json.dumps(score(sys.argv[1], sys.argv[2], sys.argv[3], sys.argv[4]), indent=2))
UNPARSEABLE is the third outcome, and it is not a zero. If a model's answer holds no readable label, extract returns None, the item is dropped from scoring, and the count is reported. If the instrument itself failed on more than half the corpus, the run returns UNMEASURED with its error rate — never a macro-F1 of 0.0. On this axis the measured runs report 0% unreadable at the axis level and n = 33 scorable items, which is why the axis is MEASURED and quotable rather than held. A dropped connection is not a wrong answer, and an unreadable answer is not a wrong answer.

Provenance and discipline

The chain of custody for this field is: a frozen corpus → a named model's per-item answers → the deterministic scorer above → a signed observation of what happened. The signed artefact is the route and the observation — this corpus, this model, this harness, this run — and never a verdict about the third party whose assumption was described. PQCBench records that a described assumption was classified a certain way under a stated rule, and it publishes the board with its interval on the bank so the number can be checked rather than taken on faith. It does not pronounce that any real system is safe, broken, or compliant. A signed route is not a verdict; a measurement is not a certification.
