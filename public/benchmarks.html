What we do NOT claim

Stated plainly, so you don't have to dig

  • The governance gate is not unbeatable — 1.000 is on our scenario set, and the set is published so you can try to break it.
  • The latent-reasoning number is a prototype on tiny data — it is not a capability result, and we don't report it as one.
  • Live full-stack measurements at n≥200 and a served-endpoint arena entry have not run yet — a repo is not a measurement.
  • A signed record proves what happened, not that it was right. Provenance is not truth.
