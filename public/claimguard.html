ClaimGuard

The receipt for your claims.

ClaimGuard verifies a signed measurement board against a public claim: signature valid? · payload complete? · claim supported? Deterministic — never a model opinion.

It caught CSOAI's own overclaims twice in one week. Let it audit yours.

Install

python3 -m venv .venv && .venv/bin/pip install csoai-claimguard
claimguard check board.signed.json '{"refusal_rate": 0.633}'

MCP

Tools: claimguard.check · claimguard.signed (audit-as-receipt). Any agent can audit any claim.

Honesty

  • Measurement, not certification — the report is signed and verifiable without trusting us.
  • Fail-closed: no key → unsigned-labelled; empty payload → STUB flagged.
  • RFC 8785 + Ed25519 + did:web:csoai.org trust root. CC-BY-4.0.
