MachBench

machinery safety · seat of the instrument: Brussels · EU Machinery Regulation 2023/1230, Annex I

Does an AI component count as a safety component under the EU Machinery Regulation? Each item describes an AI function inside a machinery product, and the task is to place it in one of three classes — PART_A, OUT_OF_SCOPE, or NOT_SAFETY_FUNCTION. Grading is deterministic: a regex reads the label and the run is scored by macro-F1. No model judges another model. The bank has been measured at n = 33 and is published on Hugging Face — but it is not yet quotable, and this page shows no score and no interval.

What moves this axis from measured to quotable.
1 · n stays at or above usable_n = 30 — cleared at n = 33, so the interval rule is already in force.
2 · the board must discriminate: at least one model must separate from the field by more than the 0.15 macro-F1 floor, so the number is a ranking and not noise.
3 · separation is computed, not asserted — overlapping results mean "leads", never "beats", and a lead is not a separation.
Until a clean discriminating board exists, the honest report is: measured, not yet quotable.

What the labels mean

labelthe AI component is…
PART_Aa safety function of a machinery category listed in Annex I Part A — the high-consequence safety components the Regulation treats as such.
NOT_SAFETY_FUNCTIONpresent in a machinery product but performing no safety function — optimisation, logging, comfort or convenience, where a failure does not create a hazard.
OUT_OF_SCOPEoutside the Machinery Regulation entirely — not a machinery product, or governed by a different instrument.

The three labels are exhaustive and mutually exclusive, which is what lets a regex read one label per answer and lets macro-F1 punish a model that simply guesses the commonest class. The distinction that carries the risk is Part A versus not-a-safety-function: the same AI in the same machine can fall either side of it depending on whether its failure is a hazard.

Statutory / standards anchor

EU Machinery Regulation (EU) 2023/1230, Annex I. The Regulation lists the categories of machinery, and of safety components, treated as higher-risk. This axis measures a classification against that anchor — whether a described AI function is a safety component of a listed category, is in a machinery product without being a safety function, or is out of scope. The anchor names the domain and the Annex; no article-level conformity claim is made on this page, and nothing here is a statement that any product does or does not comply.

The scorer — deterministic, three-outcome

A genuine skeleton, not pseudocode. It reads one JSONL record per item, extracts the chosen label with a longest-first regex, and scores macro-F1. It returns one of three outcomes — MEASURED, UNPARSEABLE, UNMEASURED — and never collapses a lane error into a wrong answer. At n ≥ 30 it computes a score, but it only reports the board as quotable when that board separates above the discrimination floor — which is why n = 33 here still yields no published number.

# machbench_score.py — CSOAI GSPC machinery-safety lane (gspc-mach)
# Input: JSONL, one item per line:
#   {"id": "mach-0001", "answer": "PART_A", "completion": "... this is PART_A ..."}
#   'answer' is the frozen gold label; 'completion' is the model's raw text.
import json, re, sys, math

USABLE_N = 30
DISCRIMINATION_FLOOR = 0.15   # a board that separates no models is not quotable
LABELS = ("PART_A", "OUT_OF_SCOPE", "NOT_SAFETY_FUNCTION")
# Longest-first so NOT_SAFETY_FUNCTION is never swallowed by a shorter prefix match.
TOKEN = re.compile(r"\b(NOT[ _-]SAFETY[ _-]FUNCTION|OUT[ _-]OF[ _-]SCOPE|PART[ _-]A)\b", re.I)

def extract(text):
    # Returns the label, or None if none can be read at all.
    if not text: return None
    m = TOKEN.search(text)
    if not m: return None
    return m.group(1).upper().replace("-", "_").replace(" ", "_")

def macro_f1(pairs):
    # macro-F1 across the three labels; guessing the commonest class must lose.
    tp = {l: 0 for l in LABELS}; fp = dict(tp); fn = dict(tp)
    for gold, pred in pairs:
        if pred == gold: tp[gold] += 1
        else:
            fn[gold] += 1
            if pred in fp: fp[pred] += 1
    total = 0.0
    for l in LABELS:
        p = tp[l] / (tp[l] + fp[l]) if tp[l] + fp[l] else 0.0
        r = tp[l] / (tp[l] + fn[l]) if tp[l] + fn[l] else 0.0
        total += 2*p*r / (p + r) if p + r else 0.0
    return total / len(LABELS)

def score(path):
    items = [json.loads(l) for l in open(path, encoding="utf-8") if l.strip()]

    # OUTCOME 1 — UNMEASURED: no bank present. Not a zero, not a failure. Empty.
    if not items:
        return {"outcome": "UNMEASURED",
                "reason": "no gspc-mach bank present"}

    pairs, unparseable = [], 0
    for it in items:
        pred = extract(it.get("completion"))
        if pred is None:
            unparseable += 1          # UNPARSEABLE tallied on its own line…
            continue                # …and never counted as a wrong answer.
        pairs.append((str(it["answer"]).upper(), pred))

    if not pairs:
        # OUTCOME 2 — UNPARSEABLE: the run happened but nothing could be read.
        return {"outcome": "UNPARSEABLE", "n": len(items),
                "unparseable": unparseable,
                "reason": "no answer in the run could be parsed to a label"}

    n = len(pairs)
    f1 = macro_f1(pairs)
    # OUTCOME 3 — MEASURED. 'quotable' needs BOTH: n at/above usable_n AND a board that
    # separates above the discrimination floor. board_spread is computed by the caller
    # across every model's macro-F1; a single run cannot vouch for its own separation.
    def quotable(board_spread):
        return n >= USABLE_N and board_spread >= DISCRIMINATION_FLOOR

    return {"outcome": "MEASURED", "n": n, "unparseable": unparseable,
            "macro_f1": round(f1, 4), "usable_n": USABLE_N,
            "discrimination_floor": DISCRIMINATION_FLOOR,
            # quotable is a function of the whole board, resolved once every
            # model has run — not asserted from one row. At n=33 with the current
            # board spread below 0.15, this resolves to False, and no score ships.
            "quotable": quotable}

if __name__ == "__main__":
    out = score(sys.argv[1])
    print(json.dumps({k: v for k, v in out.items() if not callable(v)}, indent=2))
The metric is macro-F1, not accuracy: two of the three labels are rarer than NOT_SAFETY_FUNCTION, and a model that answered the common class every time would score well on accuracy while measuring nothing. Macro-F1 at or above n = 30 always ships with its interval; below it the axis is unquotable and prints no interval — and here a second gate applies, the 0.15 discrimination floor, so even at n = 33 no number is published until the board separates.

Provenance and discipline

Chain of custody. item schema → frozen held-out bank → deterministic scorer (above) → per-item run → signed artefact. The signed artefact is the observation itself — the items, the raw completions, the parsed labels and the scorer's output — routed and signed so it cannot be altered after the fact. A signed route only fixes that the record is the record; it is not a verdict about the model that produced it.
This is measurement, not certification. A MachBench score, once the board discriminates and one is published, will be a statement about how many of these items a named model classified under this scorer. It is not a qualification, not an attestation about any third party, and not a claim that any machinery product does or does not comply with the Regulation.
Measurement, not certification. CSOAI is not a certification body, does not certify, and is neither accredited nor applying for accreditation.
