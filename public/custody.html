The custody model

Two keys sign everything this estate publishes. Both live inside CI infrastructure — never on a laptop, never in a browser wallet, never in a chat transcript:

#board-attestation-1 signs the public-root envelope (root.json). The PKCS8 lives as encrypted CI configuration, reached only by the single publisher workflow over OIDC. No local shell has ever held it. A card that cannot be signed inside that pipeline ships unsigned or does not ship — the NO_LAPTOP_SIGN tag exists so an unsigned card can never masquerade as signed.

#card-attestation-1 signs measurement cards. Same rule: the GHA publisher, nowhere else.

One writer law: only the publisher workflow writes the board, the root, or cards. Agent lanes produce unsigned artifacts and pull requests — signing happens nowhere else, including this page's authors.

Rotation & retirement

Keys rotate by DID-document update. Signatures name their key id, so historical artefacts stay verifiable against the key that signed them. A key id absent from did.json after a disclosed rotation is retired — never silently compromised. Rotation events are disclosed in the public corrections ledger.
