DetBench

cross-detector provenance interoperability · seat of the instrument: Brussels · EU AI Act (Reg. 2024/1689)

Can a machine-readable provenance mark applied under one scheme be read consistently by a detector built independently by someone else? That is an interoperability question, and it is measurable. A frozen bank now exists, has been measured at n = 33, and is published as csoai/gspc-det. The axis is MEASURED — but not yet quotable: the board it produced does not separate one detector from another above the estate's discrimination floor, so this page shows no score and no interval. A measured bank that does not discriminate is still a fact; a leaderboard drawn from it would be a fiction.

The anchor

Regulation (EU) 2024/1689 (EU AI Act), Article 50 — Transparency obligations for providers and deployers of certain AI systems. Article 50(2) requires that outputs of AI systems generating synthetic audio, image, video or text be marked in a machine-readable format and made detectable as artificially generated or manipulated, and that the technical solutions be "effective, interoperable, robust and reliable." Article 50(7) tasks the AI Office with facilitating codes of practice for detection and labelling. These obligations apply from 2 August 2026 — the regulatory clock on this axis is already running.

The word this bench turns on is interoperable. Two real marking families sit either side of it: C2PA — a signed, manifest-based provenance record attached to a file — and SynthID — a watermark embedded in the pixels or tokens themselves. A mark only its own vendor's detector can read satisfies the letter of "machine-readable" while defeating the purpose. DetBench measures exactly the gap between one scheme's mark and another party's detector — cross-detector reading — and nothing beyond it. It records an observed detection outcome; it is not a ruling on whether any named provider has met Article 50.

What the bank measures

Each item pairs a marked artefact with a detector built by a different party, and the deterministic scorer reads the detector's verdict into one of two labels:

labelmeaning on this axis
INTEROPERABLEthe independent detector reads the cross-scheme mark and agrees with the artefact's true provenance — the mark survived the vendor boundary
DIVERGENTthe independent detector cannot read, or disagrees about, a mark another party's detector would read — the mark is legible only inside its own silo

Statutory anchor: EU AI Act Art 50. Technical anchor: C2PA manifests and SynthID watermarks read across the vendor line. Bank: csoai/gspc-det, published on Hugging Face.

What has been measured

A bank at n = 33 — measured, held, not quotable. This is not the empty case, and it is not a quotable one either. Five of the preconditions a number needs are met; the sixth — a board that actually separates detectors — is not, and that sixth is the one this page will not fake.

Why n = 33 is not enough here. The usual gate is n: below 30 an axis carries no interval. This bank clears that — it sits at 33. It is held for a different, stricter reason. When the detectors were scored, the whole board landed inside a band narrower than the 0.15 discrimination floor: nothing separated from anything. Quoting a leaderboard from that would assert a ranking the measurement does not support — the exact move rule 3 of the estate's own validator exists to stop. So no macro-F1, no accuracy, no interval and no "best detector" appears anywhere on this page. The bank is real; the separation is not there yet. Both statements are published, and neither is dressed up as the other.

The scorer — how the bank is graded

This is the real deterministic scorer that grades the csoai/gspc-det bank. It is a skeleton in one place only — the external detector call, which is site-specific by nature. Everything that produces the number is complete. It enforces the three outcomes that keep the number honest — MEASURED, UNPARSEABLE and UNMEASURED — and it refuses to emit a board that does not clear the discrimination floor, which is exactly why this page currently shows none.

#!/usr/bin/env python3
# detbench_score.py — CROSS-DETECTOR PROVENANCE INTEROPERABILITY.
# Anchor: EU AI Act (Reg. 2024/1689) Art 50 — provenance marks must be machine-
# readable AND "effective, interoperable, robust and reliable". Marking schemes
# under test: C2PA manifests and SynthID watermarks, read across the vendor line.
#
# Input: JSONL, one artefact per line, from a FROZEN held-out split (csoai/gspc-det):
#   {"item_id": "det0007",
#    "artefact_ref": "sha256:...",           # the content under test, by hash
#    "marking_scheme": "C2PA" | "SynthID",    # the scheme the mark was applied under
#    "gold": "INTEROPERABLE" | "DIVERGENT",   # ground truth: does the mark cross the line
#    "detector": "party-B-detector-v3"}       # a DIFFERENT party's detector
#
# Metric: macro-F1 over the two labels (so "call everything INTEROPERABLE" cannot win).
# A board is emitted ONLY when it also clears a discrimination floor: if no detector
# separates from another, the axis is MEASURED but not quotable, and no score is shown.
import json, re, sys, pathlib

LABELS      = ["INTEROPERABLE", "DIVERGENT"]
USABLE_N    = 30
DISCRIM_FLOOR = 0.15   # spread between best and worst detector; below it, no board is quoted
TOKEN       = re.compile(r"\b(INTEROPERABLE|DIVERGENT)\b", re.I)

def extract(raw):
    """Read a detector's free-text verdict into exactly one label, or None.
    None is 'the output could not be parsed', NOT 'wrong'. The two are kept apart
    everywhere below."""
    if raw is None:
        return None
    m = TOKEN.search(raw)
    if not m:
        return None
    return m.group(1).upper()

def run_detector(item):
    """Return (raw_text, errored). SITE-SPECIFIC: call the named independent detector
    on the artefact. On a time-out / transport error / crash return ("", True) — that
    item is UNMEASURED (an instrument fault) and MUST NOT be scored as a wrong answer.
    This is the one gap a deployer fills; the scoring around it is fixed."""
    raise NotImplementedError("wire in the detector under test")

def macro_f1(pairs):
    # pairs: list of (gold_label, predicted_label), parseable items only.
    tp = {l:0 for l in LABELS}; fp = dict(tp); fn = dict(tp)
    for g, pr in pairs:
        if pr == g: tp[g] += 1
        else:
            fn[g] += 1
            if pr in fp: fp[pr] += 1
    f1s = []
    for l in LABELS:
        prec = tp[l]/(tp[l]+fp[l]) if tp[l]+fp[l] else 0.0
        rec  = tp[l]/(tp[l]+fn[l]) if tp[l]+fn[l] else 0.0
        f1s.append(2*prec*rec/(prec+rec) if prec+rec else 0.0)
    return sum(f1s)/len(LABELS)

def score(path):
    items = [json.loads(l) for l in pathlib.Path(path).read_text().splitlines() if l.strip()]
    if not items:
        return {"status": "UNMEASURED", "reason": "no bank"}   # the empty lane

    # one board per detector: {detector: [(gold, pred), ...]}
    boards, unparseable, unmeasured = {}, 0, 0
    for it in items:
        raw, errored = run_detector(it)
        if errored:
            unmeasured += 1                      # instrument fault — NOT a wrong answer
            continue
        pred = extract(raw)
        if pred is None:
            unparseable += 1                     # excluded from F1, reported openly
            continue
        boards.setdefault(it["detector"], []).append((it["gold"], pred))

    n = sum(len(v) for v in boards.values())
    if n < USABLE_N:
        # A frozen split too small to defend an interval is not quotable — including for us.
        return {"status": "MEASURED_NOT_QUOTABLE", "n": n,
                "unparseable": unparseable, "unmeasured": unmeasured,
                "reason": f"n={n} below usable_n={USABLE_N}"}

    per_detector = {d: macro_f1(p) for d, p in boards.items()}
    spread = max(per_detector.values()) - min(per_detector.values()) if per_detector else 0.0
    if spread < DISCRIM_FLOOR:
        # The bank is real and n clears the gate, but nothing separates. Publishing a
        # board here would assert a ranking the measurement does not support, so the
        # scores are WITHHELD, not shown as a leaderboard. This is DetBench today.
        return {"status": "MEASURED_NOT_QUOTABLE", "n": n,
                "detectors": len(boards),
                "unparseable": unparseable, "unmeasured": unmeasured,
                "reason": f"board spread {spread:.3f} below discrimination floor {DISCRIM_FLOOR}"}
                # note: no macro_f1 field is returned — a non-discriminating board is not a score.

    # Only a bank that clears BOTH gates emits a board.
    return {
        "status": "MEASURED",
        "n": n,
        "board": {d: round(f, 4) for d, f in sorted(per_detector.items(), key=lambda kv: -kv[1])},
        "discrimination": round(spread, 4),
        "unparseable": unparseable,      # output existed, no label read — excluded
        "unmeasured": unmeasured,        # detector errored — excluded, reported
    }

if __name__ == "__main__":
    print(json.dumps(score(sys.argv[1] if len(sys.argv) > 1 else "detbench_frozen.jsonl"), indent=2))
Read the three exits, then the fourth gate. An item where the detector crashes is UNMEASURED and dropped. An item where the detector answers but the answer holds no readable label is UNPARSEABLE and dropped, counted openly. Only an item that produces a real label is MEASURED. A dropped connection is not a wrong answer, and an unreadable verdict is not a wrong answer — collapsing either into a zero would flatter or damage a detector for a fault that is not its verdict. Beyond those three exits sits the discrimination floor: even at n = 33, a board whose spread falls below 0.15 is MEASURED_NOT_QUOTABLE, and the scorer returns no macro-F1 at all. That is the branch this bank is on today.

When a discriminating board exists, the signed artefact will be the route and the observation — which frozen split, which detectors, which per-item outcomes — and never a verdict about a third party. DetBench records that a named detector read, or failed to read, a named mark on a fixed set of artefacts. A signed route is not a verdict: it does not rule on whether any provider or deployer has satisfied Article 50; that is for a regulator, not an instrument. This is measurement, not certification.
